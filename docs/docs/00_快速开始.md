# 快速开始

## 1. 设置服务地址

USB 或 Wi‑Fi 局域网调用都使用设备固定 HTTP 端口 `65322`：

```bash
export USB_BASE="http://127.0.0.1:65322"
export WIFI_BASE="http://192.168.0.1:65322"

# USB 调用
export BASE="$USB_BASE"

# Wi‑Fi 局域网调用时改用这一行
# export BASE="$WIFI_BASE"
```

可分别使用 `http://127.0.0.1:65322/status` 和 `http://192.168.0.1:65322/status` 检查 USB、Wi‑Fi 连接。`192.168.0.1` 是示例设备 IP；设备地址不同时，请替换成远控Pro显示的实际局域网 IP。

通过远控Pro“远程调试”页面从公网调用时，使用页面当前显示的服务器地址和动态远程端口：

```bash
export BASE="http://公网服务器IP:页面显示的远程端口"
export REMOTE_AUTH="远程调试页面中的授权码"
```

例如页面显示服务器地址 `203.0.113.10`、远程端口 `1694`：

```bash
export BASE="http://203.0.113.10:1694"
```

> 上面的地址只用于说明格式。**不要把公网地址写成 `http://公网服务器IP:65322`。** `65322` 是设备的 USB/局域网端口，不是服务端分配的公网远程端口。远程端口由服务端动态分配，关闭并重新开启远程调试后可能变化，每次都以远控Pro页面当前显示值为准。完整步骤见 [公网远程访问](02_公网远程访问.md)。

## 2. 检查服务是否可用

```bash
curl -sS "$BASE/status"
```

公网远程访问时，连 `/status` 也必须携带授权码：

```bash
curl -sS "$BASE/status" \
  -H "X-YK-Remote-Authorization: $REMOTE_AUTH"
```

看到 `ready=true` 就可以继续。

## 3. 创建 SessionID

SessionID 表示“这一次自动化任务”。点击、滑动、输入、截图、文件读写、元素查找等普通自动化操作都必须带 SessionID。录制与回放等设备级任务接口不需要 SessionID，按各自模块文档直接调用。

```bash
SESSION_ID=$(curl -sS -X POST "$BASE/session/create" \
  -H "Content-Type: application/json" \
  -d '{"name":"demo"}' | python3 -c 'import sys,json; print(json.load(sys.stdin)["value"]["sessionId"])')
echo "$SESSION_ID"
```

通过“远程调试”页面提供的公网入口创建 Session 时，需要额外携带授权码：

```bash
SESSION_ID=$(curl -sS -X POST "$BASE/session/create" \
  -H "X-YK-Remote-Authorization: $REMOTE_AUTH" \
  -H "Content-Type: application/json" \
  -d '{"name":"remote-demo"}' | python3 -c 'import sys,json; print(json.load(sys.stdin)["value"]["sessionId"])')
```

通过该公网地址发送后续请求时，每个业务请求都继续携带 `X-YK-Remote-Authorization`；需要 Session 的接口再同时携带 `X-YK-Session-Id`。

调试结束后请关闭远程调试；授权码曾提供给他人时，还要在页面主动点击刷新换新。关闭远程调试本身不会改变授权码。

不传 `ttlSeconds` 时，SessionID 默认不按自身有效期过期；任务是否继续可用由设备任务心跳统一决定。只有你明确传入 `ttlSeconds > 0` 时，SessionID 才会按指定秒数自动过期。

## 4. 调用一个接口

```bash
curl -sS -X POST "$BASE/touch/home" \
  -H "X-YK-Session-Id: $SESSION_ID" \
  -H "Content-Type: application/json" \
  -d '{"count":1}'
```

如果 `BASE` 是“远程调试”页面显示的公网地址，请在上述请求额外增加 `-H "X-YK-Remote-Authorization: $REMOTE_AUTH"`。

## 5. 任务结束后释放 SessionID

```bash
curl -sS -X DELETE "$BASE/session" -H "X-YK-Session-Id: $SESSION_ID"
```

通过公网地址释放 Session 时，同样需要携带 `X-YK-Remote-Authorization`。

## 最小建议

- 每个脚本开始先创建 SessionID
- 脚本结束一定释放 SessionID
- 只读接口和设备级任务接口不需要 SessionID；其它会操作设备、读取隐私、占用资源的普通自动化接口都必须带
- 坐标统一使用屏幕物理像素。元素接口返回的中心点可以直接传给触控接口。
