# 02. 屏幕信息

屏幕信息模块返回设备当前显示尺寸、屏幕方向、缩放倍率和 DPI。坐标口径与触控、元素 bounds、截图保持一致，均按物理像素理解。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`GET /screen/info`](#get-screen-info) | 一次返回屏幕宽高、方向、scale、dpi 等信息 |
| [`GET /screen/size`](#get-screen-size) | 获取屏幕宽高 |
| [`GET /screen/width`](#get-screen-width) | 获取屏幕宽度 |
| [`GET /screen/height`](#get-screen-height) | 获取屏幕高度 |
| [`GET /screen/scale`](#get-screen-scale) | 获取屏幕缩放倍率 |
| [`GET /screen/dpi`](#get-screen-dpi) | 获取屏幕 DPI |

<a id="get-screen-info"></a>

## `GET /screen/info`

### 接口说明

一次返回屏幕宽高、方向、scale、dpi 等信息。

`width`、`height`、`size` 会按当前屏幕方向返回：竖屏时通常为窄宽高高，横屏时通常为宽宽高矮。

### 请求参数（Query）

无请求参数

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | any | 接口返回的核心数据。具体结构见本接口说明。 |
| `value.width` | number | 当前方向下的屏幕宽度，单位为物理像素 |
| `value.height` | number | 当前方向下的屏幕高度，单位为物理像素 |
| `value.size` | object | 当前方向下的屏幕尺寸 |
| `value.size.width` | number | 当前方向下的屏幕宽度，单位为物理像素 |
| `value.size.height` | number | 当前方向下的屏幕高度，单位为物理像素 |
| `value.orientation` | number | 当前屏幕方向值，对应系统 `UIInterfaceOrientation` |
| `value.orientationName` | string | 当前屏幕方向名称，可能为 `portrait`、`portraitUpsideDown`、`landscapeLeft`、`landscapeRight`、`unknown` |
| `value.scale` | number | 缩放倍率 |
| `value.dpi` | number | DPI |

### 示例

```javascript
const res = await http.get("/screen/info");
console.log(res.value);
// {
//   width: 2532,
//   height: 1170,
//   size: { width: 2532, height: 1170 },
//   orientation: 3,
//   orientationName: "landscapeRight",
//   scale: 3,
//   dpi: 489
// }
```
