# 21. 静态UI

静态 UI 是项目自带的配置网页：在项目根目录放置 `ui.html`，用户在设置页改完选项后写入设备；脚本启动后再读出这些值使用。

底层存储走 [用户配置数据](19_用户配置数据.md)（`/prefs/*`）。页面写入与脚本读取必须使用同一个 `namespace`，否则互相读不到。建议与 `.remotepro/project.json` 的 `projectName` 保持一致；字符规则见用户配置数据文档。

| 你想做的事 | 用哪个 |
| --- | --- |
| 给用户一个设置页，改完保存，脚本稍后读取 | **静态 UI**（本文） |
| 脚本运行中弹出原生窗口、按钮、列表，并处理点击等事件 | [动态UI](16_动态UI.md) |
| 只关心配置怎么存、有哪些接口 | [用户配置数据](19_用户配置数据.md) |

## 它怎么工作

1. `ui.html`页面创建短生命周期 Session（规则见 [服务与任务](01_服务与任务.md)、[公共规则](../01_公共规则.md)）
2. 用 `GET /prefs/getMany` 把已有配置填进表单
3. 用户编辑后用 `POST /prefs/setMany` 保存
4. 释放 Session
5. 脚本用同一 `namespace` 读取 prefs

页面只负责配置的展示与持久化；运行中的提示、弹窗与控件事件用 [动态UI](16_动态UI.md)。

读写 prefs 时的服务地址、请求头与 Session 约定，分别见 [公共规则](../01_公共规则.md) 与 [服务与任务](01_服务与任务.md)。配置页在读写前后自行创建并释放短生命周期 Session 即可。接口字段以 [用户配置数据](19_用户配置数据.md) 为准。

## 文件与入口

| 项 | 说明 |
| --- | --- |
| 文件位置 | 项目根目录 `ui.html` |
| 手机端 | [悬浮球](22_悬浮球.md)「设置」打开 |
| 电脑端 | 设备列表「设置」按参考设备分辨率打开 |

USB 连接使用 `http://127.0.0.1:65322`，Wi‑Fi 局域网连接可使用 `http://192.168.0.1:65322`（与 [公共规则](../01_公共规则.md) 一致；设备 IP 不同时请替换为实际局域网 IP）。电脑端预览时，扩展会在页面最前注入引导脚本：

- 把发往任意主机 **端口 `65322`** 的 `fetch`、`XMLHttpRequest` 转到当前设备（含本机、局域网 IP 等写法）
- 公网调试时自动带上远程授权头
- 同时暴露 `window.__REMOTEPRO__.base`（仅电脑预览存在；手机端无此对象，继续用本机地址即可）

不覆盖：非 `fetch`/`XHR`、非 `65322` 端口的硬编码地址。

## 常见问题

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 设置里打不开页面 | 根目录没有 `ui.html`，或文件名不对 | 确认项目根目录存在 `ui.html` |
| 保存成功但脚本读不到 | 页面和脚本的 `namespace` 不一致 | 两边改成同一个，建议用 `projectName` |
| 电脑端打不开或保存失败 | 设备未连接，或请求未走 `:65322` / `fetch`·`XHR` | 确认设备可用；页面用 `:65322` 的服务地址，或读 `window.__REMOTEPRO__.base` |
| 保存了但像没生效 | 脚本用了旧默认值，或读错了 key | 核对读取的 key / 字段名 |
| 想做运行中弹窗、按钮 | 用错了模块 | 改用 [动态UI](16_动态UI.md) |
