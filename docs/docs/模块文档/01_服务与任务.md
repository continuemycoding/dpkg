# 01. 服务、Session 与任务控制

服务、Session 与任务控制模块用于检查 HTTP 服务状态、查看接口列表，以及创建和管理 Session。

Session 表示“一次脚本任务”。悬浮球相关参数和接口统一见 [悬浮球](22_悬浮球.md)。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`GET /status`](#get-status) | 读取服务运行状态 |
| [`GET /health`](#get-health) | 读取服务健康状态，适合探活 |
| [`GET /routes`](#get-routes) | 返回接口列表 |
| [`OPTIONS /*`](#options-all) | 统一 CORS preflight 处理 |
| [`POST /session/create`](#post-session-create) | 创建一个新的 Session |
| [`GET /session/list`](#get-session-list) | 列出当前活跃 Session |
| [`GET /session/status`](#get-session-status) | 查询指定 Session 状态 |
| [`GET /session/current`](#get-session-current) | 查询当前请求头绑定的 Session 状态 |
| [`GET /session/requests`](#get-session-requests) | 查询指定 Session 接口请求记录 |
| [`POST /session/pause`](#post-session-pause) | 暂停指定 Session 的后续动作类请求 |
| [`POST /session/resume`](#post-session-resume) | 恢复指定 Session |
| [`DELETE /session`](#delete-session) | 删除指定 Session 并释放其资源 |
| [`DELETE /session/all`](#delete-session-all) | 删除全部 Session 并释放资源 |

## 通用响应格式

### 成功响应

成功时返回：

```json
{
  "value": {}
}
```

### 失败响应

失败时返回：

```json
{
  "value": {
    "error": "unauthorized",
    "message": "Session 不存在或已过期"
  }

```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.error` | string | 错误类型 |
| `value.message` | string | 中文错误说明 |

### 接口说明

读取服务运行状态。常用于脚本启动前判断服务是否可用。

### 请求参数（Query）

| `value.message` | string | 状态说明 |
| `value.server` | string | 服务标识 |

| `value.wifiIP` | string | 当前 Wi-Fi IP，可能为空 |
| `value.timestamp` | number | 当前时间戳 |
| `value.routeCount` | number | 当前注册接口数量 |
| `value.limits.maxJSONBodyBytes` | number | JSON 请求体最大字节数 |
| `value.portStrategy.defaultPort` | number | 默认端口 |
| `value.portStrategy.configuredPort` | number | 配置端口 |
| `value.portStrategy.listeningPort` | number | 实际监听端口 |
| `value.portStrategy.dynamic` | number | 是否动态端口，`0` 表示否 |
| `value.portStrategy.source` | string | 端口来源 |
| `value.sessions.activeCount` | number | 当前活跃 Session 数量 |
| `value.sessions.activeRequestCount` | number | 当前执行中的请求数量 |
| `value.sessions.queuedRequestCount` | number | 当前排队请求数量 |
| `value.sessions.maxSessions` | number | 最大 Session 数，`0` 表示不限制 |
| `value.sessions.sessions` | array | Session 状态列表 |
| `value.execution.routeQueue` | string | 路由执行队列说明 |
| `value.execution.shortReadLane` | string | 短读请求执行通道 |
| `value.execution.commandActionLane` | string | 操作类请求执行通道 |
| `value.execution.longRunningLane` | string | 长耗时请求执行通道 |
| `value.execution.longRunningMaxConcurrent` | number | 长耗时请求最大并发数 |
| `value.execution.longRunning.running` | number | 当前长耗时执行数 |
| `value.execution.longRunning.queued` | number | 当前长耗时排队数 |
| `value.execution.longRunning.completed` | number | 已完成长耗时请求数 |
| `value.execution.longRunning.rejected` | number | 被拒绝的长耗时请求数 |
| `value.execution.longRunning.availableSlots` | number | 长耗时剩余并发槽位 |
| `value.execution.longRunning.maxQueued` | number | 长耗时最大排队数 |
| `value.execution.longRunning.queuePolicy` | string | 长耗时排队策略 |
| `value.observability.mode` | string | 当前观测模式 |
| `value.observability.pending` | number | 审计队列待处理数量 |
| `value.observability.dropped` | number | 被丢弃的审计数量 |
| `value.observability.queueLimit` | number | 审计队列上限 |
| `value.observability.totalErrors` | number | 累计错误数量 |
| `value.observability.recentErrorLimit` | number | 最近错误保留上限 |
| `value.observability.recentErrors` | array | 最近错误列表 |

### 示例

```javascript
const res = await http.get("/status");

if (res.value.ready) {
  console.log("服务可用");
}
```

## `OPTIONS /*`

### 接口说明

统一 CORS preflight 处理。该接口由 HTTP 入口统一处理，主要给浏览器或跨域工具探测允许的请求方法和请求头。

### 请求参数（Header）

无业务参数。

### 响应字段

返回 CORS 相关响应头，不依赖 JSON body。

### 示例

```javascript
await http.options("/screen/info");
```

<a id="post-session-create"></a>

## `POST /session/create`

### 接口说明

创建一个新的 Session。Session 表示“一次脚本任务”，其他模块接口通过请求头 `X-YK-Session-Id` 归属到这个任务。

本机或局域网访问设备 `65322` 时无需远程授权码。通过“远程调试”页面显示的公网地址调用时，本接口和后续每个业务请求都必须携带请求头 `X-YK-Remote-Authorization`，其值为页面中设置的授权码。

公网地址必须使用 App 当前显示的动态远程端口，例如 `http://47.107.154.171:1694`，不能写成 `http://47.107.154.171:65322`。`65322` 是设备的本机/局域网端口；远程调试关闭并重新开启后，应重新读取页面显示的最新公网地址。

授权码只有用户点击刷新时才会换新；关闭远程调试不会改变授权码。授权码曾提供给他人时，调试结束后应关闭远程调试并主动刷新。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `name` | string | 否 | 便于调试的 Session 名称 | `"demo"` |
| `ttlSeconds` | number | 否 | Session 自身过期秒数。不传或传 `0` 表示不按 Session 自身过期。 | `3600` |
| `debugRequestLog` | boolean | 否 | 是否记录当前 Session 生命周期内的模块请求摘要，默认 `false`。开启后可用 `/session/requests` 查询。 | `true` |

### 响应字段

返回一个 Session 状态对象，字段见 [Session 状态对象](#session-object)。

### 示例

```javascript
const res = await http.post("/session/create", {
  name: "demo",
  debugRequestLog: true
});

const sessionId = res.value.sessionId;
console.log(sessionId);
```

通过公网地址创建 Session 的 curl 示例：

```bash
curl -sS -X POST "$BASE/session/create" \
  -H "X-YK-Remote-Authorization: $REMOTE_AUTH" \
  -H "Content-Type: application/json" \
  -d '{"name":"remote-demo"}'
```

## Session 状态对象

`POST /session/create`、`GET /session/list`、`GET /session/status`、`GET /session/current` 会返回 Session 状态对象。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `sessionId` | string | SessionID |
| `name` | string | Session 名称 |
| `state` | string | Session 状态，正常为 `active` |
| `createdAt` | number | 创建时间戳 |
| `expiresAt` | number/null | 过期时间戳；不按自身过期时为 `null` |
| `ttlSeconds` | number | Session 自身有效期秒数，`0` 表示不按自身过期 |
| `remainingSeconds` | number/null | 剩余秒数；不按自身过期时为 `null` |
| `neverExpires` | boolean | 是否不按 Session 自身过期 |
| `activeRequests` | number | 当前执行中的请求数量 |
| `queuedRequests` | number | 当前排队请求数量 |
| `totalRequests` | number | 此 Session 累计请求数量 |
| `lastRequestId` | string | 最近一次请求 ID |
| `paused` | boolean | 是否处于暂停状态 |
| `pausedAt` | number/null | 暂停时间戳；未暂停时为 `null` |
| `pauseCount` | number | 累计暂停次数 |
| `resumeCount` | number | 累计恢复次数 |
| `controlState` | string | 本地任务控制状态，常见为 `running`、`paused` |
| `lastControlChangedAt` | number | 最近一次控制状态变化时间戳 |
| `debugRequestLogEnabled` | boolean | 是否开启请求记录 |
| `debugRequestLogLimit` | number | 请求记录最多返回条数，当前为最近 `100` 条 |
| `resources` | object | 此 Session 关联资源摘要 |

### `resources` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `resources.images` | number | 当前 Session 持有的图片数量 |
| `resources.ui` | object | UI 资源摘要 |
| `resources.ocr` | object | OCR 资源摘要 |
| `resources.yolo` | object | Yolo 资源摘要 |
| `resources.yoloModels` | number | 已加载模型数量 |
| `resources.network` | object | Network 资源摘要 |
| `resources.jobs` | number | 任务数量 |

## `GET /session/current`

### 接口说明

查询当前请求头 `X-YK-Session-Id` 绑定的 Session 状态。没有请求头或当前没有活跃 Session 时，会返回 Session 不可用错误。

### 请求参数（Header）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `X-YK-Session-Id` | string | 是 | 要查询的 SessionID。 | `"sess_xxx"` |

### 响应字段

返回一个 Session 状态对象，字段见 [Session 状态对象](#session-object)。

### 示例

```javascript
const res = await http.get("/session/current", {
  headers: { "X-YK-Session-Id": sessionId }
});
console.log(res.value.state);
```

<a id="get-session-requests"></a>

## `GET /session/requests`

### 接口说明

查询指定 Session 接口请求记录。只有创建 Session 时传入 `debugRequestLog: true`，这里才会返回当前 Session 的模块请求摘要；默认关闭时返回空列表。请求记录仅保存在当前 Session 的内存中，最多保留最近 `100` 条；Session 删除或引擎重启后不再保留。

这个接口只返回 HTTP Session 自己的接口调用记录，不包含脚本任务的 stdout/stderr 运行日志。

### 请求参数（Query 或 Header）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `sessionId` | string | 是 | 要查询的 SessionID。可以放在 query，也可以放在请求头 `X-YK-Session-Id`。 | `"sess_xxx"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.sessionId` | string | SessionID |
| `value.name` | string | Session 名称 |
| `value.debugRequestLogEnabled` | boolean | 是否开启请求记录 |
| `value.limit` | number | 内存记录条数上限，当前为 `100` |
| `value.count` | number | 当前 Session 生命周期内累计记录数量，可大于当前返回条数 |
| `value.loadedCount` | number | 当前响应实际返回的请求记录数量，最多 `100` 条 |
| `value.storage` | string | 存储状态；开启时为 `memory`，关闭时为 `disabled` |
| `value.requests` | array | 当前返回的请求记录，最多最近 `100` 条 |

### `value.requests[]` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `time` | number | 请求记录时间戳 |
| `requestId` | string | 请求 ID |
| `method` | string | HTTP 方法 |
| `path` | string | 请求路径 |
| `module` | string | 模块名 |
| `message` | string | 简短说明 |

### 示例

```javascript
const created = await http.post("/session/create", {
  name: "debug-demo",
  debugRequestLog: true
});

const sessionId = created.value.sessionId;

await http.get("/screen/info", {
  headers: { "X-YK-Session-Id": sessionId }
});

const res = await http.get(`/session/requests?sessionId=${encodeURIComponent(sessionId)}`);
console.log(res.value.requests);
```

<a id="post-session-pause"></a>

## `POST /session/pause`

### 接口说明

暂停指定 Session。暂停后，新的动作类请求会被拒绝；已经进入执行中的请求会自然结束。

只读查询、Session 状态查询、请求记录查询等控制类接口仍可调用，方便你查看状态或恢复任务。

### 请求参数（Query、Header 或 JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `sessionId` | string | 是 | 要暂停的 SessionID。可以放在 query、请求头 `X-YK-Session-Id`，也可以放在 JSON body。 | `"sess_xxx"` |

### 响应字段

返回一个 Session 状态对象，字段见 [Session 状态对象](#session-object)。

### 示例

```javascript
await http.post("/session/pause", {}, {
  headers: { "X-YK-Session-Id": sessionId }
});
```

## `DELETE /session`

### 接口说明

删除指定 Session，并释放这个 Session 关联的图片、UI、OCR、Yolo、Network 等资源。

### 请求参数（Query 或 Header）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `sessionId` | string | 是 | 要删除的 SessionID。可以放在 query，也可以放在请求头 `X-YK-Session-Id`。 | `"sess_xxx"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.deleted` | boolean | 是否删除成功 |
| `value.sessionId` | string | 被删除的 SessionID |
| `value.name` | string | 被删除的 Session 名称 |

### 示例

```javascript
const res = await http.delete(`/session?sessionId=${encodeURIComponent(sessionId)}`);
console.log(res.value.deleted);
```

### 请求参数（Query）

无请求参数

| 字段 | 类型 | 说明 |

### 示例

```javascript
const res = await http.delete("/session/all");
```

## 推荐工作流

```javascript
const created = await http.post("/session/create", {
  name: "demo-task",
  debugRequestLog: true,
});

const sessionId = created.value.sessionId;

await http.get("/screen/info", {
  headers: { "X-YK-Session-Id": sessionId }
});

const logs = await http.get(`/session/requests?sessionId=${encodeURIComponent(sessionId)}`);
console.log(logs.value.requests);

await http.delete(`/session?sessionId=${encodeURIComponent(sessionId)}`);
```
