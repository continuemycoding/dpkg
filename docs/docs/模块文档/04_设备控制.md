# 04. 设备控制

设备控制模块用于读取设备信息、读取/设置系统状态、控制网络开关、锁屏、震动、闪光灯等。

读取类接口都是 `GET`，设置类接口通常是 `POST`。设置类接口建议先读取当前状态，再决定是否写入。

<a id="get-device-info"></a>

## `GET /device/info`

### 接口说明

一次返回设备完整只读信息，适合脚本启动时读取设备基础状态。

### 请求参数（Query）

无请求参数。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.identity` | object | 设备标识信息 |
| `value.identity.name` | string | 设备名称 |
| `value.identity.model` | string | 设备机型 |
| `value.identity.modelNumber` | string | 型号号码 |
| `value.identity.uuid` | string | 设备 UDID |
| `value.identity.serialNumber` | string | 设备序列号 |
| `value.identity.cpuArchitecture` | string | CPU 架构 |
| `value.identity.language` | string | 系统设置中的第一优先级真实语言 |
| `value.identity.wifiMac` | string | Wi-Fi MAC 地址 |
| `value.identity.bluetoothAddress` | string | 蓝牙物理地址 |
| `value.identity.telephonyInfo` | object | 移动通讯硬件标识 |
| `value.state` | object | 设备状态信息 |
| `value.state.isScreenLocked` | boolean | 屏幕是否锁定 |
| `value.state.brightness` | number | 屏幕亮度，范围 `0` 到 `1` |
| `value.state.volume` | number | 系统音量，范围 `0` 到 `1` |
| `value.state.mute` | boolean | 是否静音 |
| `value.state.frontOrientation` | number | 当前前台页面方向值 |
| `value.state.orientationLocked` | boolean | 是否锁定屏幕方向 |
| `value.state.ip` | object | 网络 IP 信息 |
| `value.state.connectivity` | object | 网络与连接状态 |
| `value.state.battery` | object | 电池信息 |
| `value.state.autoLockTime` | number | 自动锁定时间，单位秒；`-1` 表示永不锁定 |
| `value.state.flash` | boolean | 闪光灯是否开启 |
| `value.state.safariRemoteInspector` | boolean | Safari 远程调试是否开启 |

### 示例

```javascript
const res = await http.get("/device/info");
console.log(res.value.identity.model);
console.log(res.value.state.battery.level);
```

<a id="get-device-jbtype"></a>

## `GET /device/jbType`

### 接口说明

获取当前设备正在使用的越狱运行环境，以及与该环境兼容的 deb `Architecture`。

接口读取当前运行的 YK 二进制构建环境，不通过 CPU 架构或文件路径猜测。调用方可在上传更新包前读取此接口，选择与设备当前环境一致的 deb。

### 请求参数（Query）

无请求参数。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.type` | number | 环境编号：`1` 有根、`2` 无根、`3` 隐根 |
| `value.name` | string | 环境标识：`rootful`、`rootless` 或 `roothide` |
| `value.displayName` | string | 中文环境名称：`有根`、`无根` 或 `隐根` |
| `value.packageArchitecture` | string | 对应 deb 架构：`iphoneos-arm`、`iphoneos-arm64` 或 `iphoneos-arm64e` |

### 环境对应关系

| `type` | `name` | `displayName` | `packageArchitecture` |
| --- | --- | --- | --- |
| `1` | `rootful` | `有根` | `iphoneos-arm` |
| `2` | `rootless` | `无根` | `iphoneos-arm64` |
| `3` | `roothide` | `隐根` | `iphoneos-arm64e` |

### 示例

```javascript
const res = await http.get("/device/jbType");
console.log(res.value.name);
console.log(res.value.packageArchitecture);
```

<a id="get-device-language"></a>

## `GET /device/language`

### 接口说明

获取系统设置中的真实语言，返回系统语言列表的第一优先级语言。

该接口返回系统设置中的语言偏好，不受单独 App Language 设置影响。

系统语言切换期间连接可能短暂中断，服务恢复后可重新调用本接口确认。

常见返回值示例：

| 返回值 | 说明 |
| --- | --- |
| `zh-Hans-CN` | 简体中文（中国大陆） |
| `zh-Hant-TW` | 繁体中文（台湾） |
| `en-US` | 英语（美国） |
| `ja-JP` | 日语（日本） |

### 请求参数（Query）

无请求参数。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | string | 系统设置中的第一优先级真实语言 |

### 示例

```javascript
const res = await http.get("/device/language");
console.log(res.value);
```

<a id="post-device-language"></a>

## `POST /device/language`

### 接口说明

设置系统首选语言。支持所有 iOS 系统语言，使用标准语言标识，例如 `zh-Hans-CN`、`en-US`、`ja-JP`、`fr-FR`、`de-DE`。

接口会先规范化语言标识，再确认当前系统具备对应的语言资源。格式不正确，或当前 iOS 版本未提供该语言时，请求会返回失败且不会修改系统设置。

可以同时传入 `region` 设置地区；不传时保留当前地区。需要同时修改语言和地区时，建议在一次请求中同时传入两个参数。

接口仅在设置结果与目标一致时返回成功。返回成功后，建议调用 `GET /device/locale` 对语言、地区和区域标识做完整确认。

当 `requiresReconnect` 为 `true` 时，系统界面会短暂重新加载，当前 SessionID 已失效。请重新创建 SessionID，再调用 `GET /device/locale`；如果连接正处于切换过程，可直接重试读取。`requiresReconnect` 为 `false` 时，当前 SessionID 可继续使用。

目标值与当前设置一致时，`changed` 为 `false`，`requiresReconnect` 为 `false`。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `language` | string | 是 | 任意 iOS 系统语言的标准语言标识 | `"ja-JP"` |
| `region` | string | 否 | 任意 iOS 系统地区的标准两位地区代码；不传时保留当前地区，传入时不能为 `null` 或空字符串 | `"JP"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.language` | string | 设置后的系统首选语言 |
| `value.region` | string | 设置后的系统地区 |
| `value.localeIdentifier` | string | 设置后的系统区域标识 |
| `value.changed` | boolean | 本次请求是否实际改变了系统设置 |
| `value.requiresReconnect` | boolean | 当前 SessionID 是否已失效；为 `true` 时需重新创建 SessionID |

### 示例

```javascript
const res = await http.post("/device/language", {
  language: "ja-JP"
});
console.log(res.value);
```

<a id="get-device-telephonyinfo"></a>

## `GET /device/telephonyInfo`

### 接口说明

获取移动通讯硬件标识。可一次返回全部信息，也可以按 `key` 和 `slot` 读取单个字段。

### 请求参数（Query）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `key` | string | 否 | 指定要读取的字段名。不传时返回完整对象 | `"IMEI"` |
| `slot` | number | 否 | 卡槽序号，从 `1` 开始，默认 `1` | `1` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | object/string | 不传 `key` 时返回对象；传 `key` 时返回字符串 |

### 示例

```javascript
const all = await http.get("/device/telephonyInfo");
console.log(all.value);

const imei = await http.get("/device/telephonyInfo?key=IMEI&slot=1");
console.log(imei.value);
```
