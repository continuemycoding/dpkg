# 图片能力

图片模块用于截图、加载手机本地图片、裁剪、缩放、保存到文件、保存到系统相册、读取像素、找色、找图，以及把图片导出为 Base64 或 JPG/PNG 二进制。

图片模块的核心概念是 `imageId`：截图、加载、裁剪、缩放都会返回一个 `imageId`，后续操作都通过 `imageId` 引用这张图片。

## 第一版命名约束

第一版 API 只接受本文档列出的标准命名，同一个概念只保留一种公开写法。

| 概念 | 标准命名 |
|------|----------|
| 图片缓存 ID | `imageId` |
| 模板图片 ID | `templateImageId` |
| 模板路径 | `templatePath` |
| 模板缩放 | `scale` |
| 查找区域 | `options.region` |
| 颜色容差 | `tolerance` |
| 匹配阈值 | `threshold` |
| 忽略透明像素 | `options.ignoreTransparent` |
| 透明阈值 | `options.alphaThreshold` |
| 灰度匹配 | `options.gray` |
| Turbo 锚点数量 | `options.turboAnchors` |
| Turbo 候选上限 | `options.turboMaxCandidates` |
| Turbo 回退开关 | `options.turboFallback` |
| 单个颜色 | `color` |
| 候选颜色数组 | `colors` |
| 最大结果数 | `maxResults` |

普通多点找色的 `offsets` 只接受对象数组：`[{dx, dy, color}]`。
高级多点找色的 `offsets` 只接受对象数组：`[{dx, dy, colors}]`。
两者都不接受 `[dx, dy, color]` 这种数组简写。

截图只通过 `/image/capture` 返回 `imageId`，后续图片操作都显式使用该 `imageId`；缓存释放和淘汰由 `/image/release`、`/image/releaseAll` 与内部 LRU 管理。
`maxResults` 只用于返回多个结果的接口，例如 `findColorAll/findMultiColorExAll/findImageBatchAll/findImageScaleAll`；单结果接口不提供 `maxResults`。
`tolerance/maxResults/threshold/scale` 只接受顶层参数，不接受 `options.tolerance/options.maxResults/options.threshold/options.scale`。
`ignoreTransparent/alphaThreshold/gray/turboAnchors/turboMaxCandidates/turboFallback` 只接受 `options.*`，不接受顶层同名参数。

## 受保护内容截图

`allowProtectedContent` 只在 `/image/capture` 这类屏幕截图入口生效，默认 `false`。找图、找色、读像素等接口只处理传入的 `imageId`，不会重新截图；如果要在受保护/加密屏幕内容上找图找色，先调用 `/image/capture` 并传 `allowProtectedContent: true` 生成 `imageId`，再把这个 `imageId` 传给后续图片接口。

## 图片元数据

截图、加载、创建、复制、裁剪、缩放、二值化、旋转、绘制等生成图片的接口会返回图片元数据：

```json
{
  "imageId": "img_xxx",
  "width": 1170,
  "height": 2532,
  "bytesPerRow": 4680,
  "size": 11849760,
  "orientation": 1,
  "createdAt": 123456.7,
  "lastAccessAt": 123456.7
}
```

| 字段 | 类型 | 中文说明 |
|------|------|----------|
| `imageId` | string | 图片缓存 ID，后续接口都用它引用图片 |
| `width` | number | 图片宽度，单位像素 |
| `height` | number | 图片高度，单位像素 |
| `bytesPerRow` | number | 每行像素占用字节数 |
| `size` | number | 图片像素缓存占用字节数 |
| `orientation` | number | 图片来源/采集方向 metadata。像素本身已经按当前语义正向存放，普通脚本一般不需要处理。 |
| `createdAt` | number | 创建时间戳 |
| `lastAccessAt` | number | 最后访问时间戳 |

## 颜色写法

找色接口的颜色参数支持三种写法：

```javascript
// 十六进制数字，0xRRGGBB
{ color: 0xff0000 }

// RGB 数组
{ color: [255, 0, 0] }

// RGBA 对象
{ color: { r: 255, g: 0, b: 0, a: 255 } }
```

## 查找区域 options.region

找色、找图都可以传 `options.region` 限制查找区域，坐标单位是图片像素：

```javascript
{
  imageId,
  color: 0xff0000,
  options: {
    region: { left: 0, top: 0, right: 500, bottom: 500 }
  }
}
```

## 编码参数

`/image/toBase64`、`/image/download`、`/image/writeBase64` 支持：

| 参数 | 类型 | 是否必选 | 中文说明 | 示例 |
|------|------|----------|----------|------|
| `format` | string | 否 | 输出格式，支持 `jpg`、`jpeg`、`png`。默认 `jpg`。 | `"jpg"` |
| `quality` | number | 否 | JPG 质量，只接受 `1` 到 `100` 的整数。默认 `80`。 | `90` |
| `maxBytes` | number | 否 | 最大输出字节数。`toBase64` 和 `download` 默认/最大都是 `20971520`，即 20MB。 | `20971520` |

<a id="post-image-capture"></a>

## `POST /image/capture`

### 接口说明

截取屏幕并生成 `imageId`。不传区域时截全屏。

### 请求参数

| 参数 | 类型 | 是否必选 | 中文说明 | 示例 |
|------|------|----------|----------|------|
| `x` | number | 否 | XYWH 区域左上角 X。必须和 `y/width/height` 一起传。 | `0` |
| `y` | number | 否 | XYWH 区域左上角 Y | `0` |
| `width` | number | 否 | XYWH 区域宽度 | `300` |
| `height` | number | 否 | XYWH 区域高度 | `300` |
| `left` | number | 否 | LTRB 区域左边界。必须和 `top/right/bottom` 一起传。 | `0` |
| `top` | number | 否 | LTRB 区域上边界 | `0` |
| `right` | number | 否 | LTRB 区域右边界 | `300` |
| `bottom` | number | 否 | LTRB 区域下边界 | `300` |
| `allowProtectedContent` | boolean | 否 | 是否允许截图受保护/加密内容。默认 `false`，表示受保护内容不会被截到；传 `true` 时会尝试从屏幕数据流截图。 | `false` |

不能同时传 XYWH 和 LTRB。`0,0,0,0` 表示全屏。

### 响应字段

返回图片元数据，见「图片元数据」

### 示例

```javascript
const shot = await http.post("/image/capture", {});
console.log(shot.value.imageId);
```

局部截图：

```javascript
const part = await http.post("/image/capture", {
  left: 0,
  top: 0,
  right: 500,
  bottom: 500
});
```

允许截图受保护内容：

```javascript
const shot = await http.post("/image/capture", {
  allowProtectedContent: true
});
```

## `POST /image/findColorEx`

### 接口说明

第一版只接受本节列出的结构化 `colors` 参数。`tolerance` 和 `scanOrder` 只放顶层，`options` 只接受 `region`。

| `options.region` | object | 否 | 查找区域 | `{"left":0,"top":0,"right":500,"bottom":500}` |

## 使用提醒

- 图片缓存绑定当前 `SessionID`。不同任务之间不能混用 `imageId`。
- 截图、裁剪、缩放、加载都会产生新的图片缓存。循环脚本里记得调用 `/image/release` 或 `/image/releaseAll`。
- 获取图片内容时优先使用 `jpg + quality: 80~90`，能明显减少传输体积
- 如果脚本 HTTP 客户端支持二进制响应，优先用 `/image/download`；如果只能处理字符串，再用 `/image/toBase64`。
- Base64 和二进制直接返回默认最大 20MB，超过时请裁剪、降低质量，或保存到手机文件。
- 坐标单位都是图片像素。截图是屏幕物理像素，和触控坐标口径一致。
