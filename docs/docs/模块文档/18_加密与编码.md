# 18. 加密与编码

加密与编码模块提供常用的编码、摘要、HMAC、对称加解密、密钥派生、AES-GCM、RSA、签名和验签能力。

## 通用说明

### 二进制编码参数

| 参数值 | 说明 |
| --- | --- |
| `utf8` | 普通 UTF-8 文本 |
| `base64` | Base64 字符串 |
| `hex` | 小写十六进制字符串 |
| `hex_upper` | 大写十六进制字符串 |

### 二进制编码包

部分接口返回二进制编码包：

```json
{
  "data": "aGVsbG8=",
  "encoding": "base64",
  "size": 5
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data` | string | 编码后的数据 |
| `encoding` | string | `utf8`、`base64`、`hex` 或 `hex_upper` |
| `size` | number | 原始字节数 |

### 支持的算法名

| 类型 | 可选值 |
| --- | --- |
| 摘要/HMAC | `MD5`、`SHA1`、`SHA224`、`SHA256`、`SHA384`、`SHA512`、`SHA3_224`、`SHA3_256`、`SHA3_384`、`SHA3_512` |
| 对称加密算法 | `AES`、`DES`、`3DES` |
| 分组模式 | `ECB`、`CBC`、`CFB`、`CTR`、`OFB` |
| 填充方式 | `None`、`PKCS7` |
| RSA 加解密 | `PKCS1`、`OAEP`、`OAEP_SHA1`、`OAEP_SHA224`、`OAEP_SHA256`、`OAEP_SHA384`、`OAEP_SHA512` |
| 签名验签 | `RSASHA1`、`RSASHA256`、`RSASHA384`、`RSASHA512`、`RSAPSSSHA256`、`RSAPSSSHA384`、`RSAPSSSHA512`、`ECDSASHA256`、`ECDSASHA384`、`ECDSASHA512` |

## `POST /crypto/randomBytes`

生成指定长度的随机字节。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `length` | number | 是 | 随机字节长度 | `16` |
| `outputEncoding` | string | 否 | 输出编码，默认 `base64` | `"hex"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | object | 二进制编码包 |

### 调用示例

```javascript
const res = await http.post("/crypto/randomBytes", {
  length: 16,
  outputEncoding: "hex"
});

console.log(res.value.data);
```

## `POST /crypto/gcm/encrypt`

使用 AES-GCM 进行认证加密。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `plainData` | string | 是 | 明文数据 | `"hello"` |
| `inputEncoding` | string | 否 | 明文编码，默认 `utf8` | `"utf8"` |
| `key` | string | 是 | AES 密钥 | `"00000000000000000000000000000000"` |
| `keyEncoding` | string | 否 | 密钥编码，默认 `utf8` | `"hex"` |
| `iv` | string | 是 | GCM IV | `"000000000000000000000000"` |
| `ivEncoding` | string | 否 | IV 编码，默认 `utf8` | `"hex"` |

| `tagLength` | number | 否 | Tag 长度，默认 `16`，范围 `1-16` | `16` |
| `outputEncoding` | string | 否 | 密文输出编码，默认 `base64` | `"hex"` |
| `tagEncoding` | string | 否 | Tag 输出编码，默认跟随 `outputEncoding` | `"hex"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |

```javascript

  plainData: "hello",
  key: "00000000000000000000000000000000",
  keyEncoding: "hex",
  iv: "000000000000000000000000",
  ivEncoding: "hex",
  outputEncoding: "hex",
  tagEncoding: "hex"
});
```

## `POST /crypto/verify`

使用 PEM 公钥验签。签名不匹配不是系统错误，会返回 `value=false`。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `data` | string | 是 | 原始数据 | `"hello"` |
| `inputEncoding` | string | 否 | 数据编码，默认 `utf8` | `"utf8"` |
| `signature` | string | 是 | 签名数据 | `"..."` |
| `signatureEncoding` | string | 否 | 签名编码，默认 `base64` | `"base64"` |
| `publicKeyPEM` | string | 是 | PEM 公钥文本 | `"-----BEGIN PUBLIC KEY-----..."` |
| `algorithm` | string | 否 | 签名算法，默认 `RSASHA256` | `"RSASHA256"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 验签是否通过 |

### 调用示例

```javascript
const res = await http.post("/crypto/verify", {
  data: "hello",
  signature: "...",
  publicKeyPEM,
  algorithm: "RSASHA256"
});

  console.log("验签通过");
}
```

## 常见错误

| 情况 | 说明 |
| --- | --- |
| `encoding` 不合法 | 请使用 `utf8`、`base64`、`hex`、`hex_upper` |
| `algorithm` 不支持 | 请检查算法名是否在文档支持列表内 |
| `key` 或 `iv` 长度不对 | 请确认密钥、IV 的编码方式和真实字节长度 |
| GCM 解密失败 | 常见原因是 `tag`、`aad`、`key`、`iv` 任意一项和加密时不一致 |
| PEM 解析失败 | 请确认公钥/私钥文本完整，包含 BEGIN/END 行 |
