# 08. 元素查找

元素模块用于读取当前页面的元素树，并按条件查找、点击、输入元素

> **能力提示：** 安全字段与 WebView 元素识别能力增强。

`value.success`、`value.message`、`value.error` 是元素查找、点击、输入等业务结果字段，不是 HTTP 层响应格式。HTTP 层失败统一见 [公共规则](../01_公共规则.md)。

| 接口 | 用途 |
| --- | --- |
| [`GET /element/runtimeStatus`](#get-element-runtimestatus) | 读取元素服务运行时状态 |

| [`POST /element/activeProbe`](#post-element-activeprobe) | 设置活动目标探测开关 |
| [`POST /element/tree`](#post-element-tree) | 获取当前页面元素树 |
| [`POST /element/find`](#post-element-find) | 查找第一个匹配元素 |

| [`POST /element/click`](#post-element-click) | 查找并点击元素中心点 |

| [`POST /element/input`](#post-element-input) | 查找输入控件并输入文本 |
| [`POST /element/waitFor`](#post-element-waitfor) | 等待元素出现或消失 |

## 元素类型

| 类型 | 说明 |
| --- | --- |
| `Window` | 窗口根节点 |
| `Button` | 按钮、可点击入口、列表项 |
| `StaticText` | 静态文字 |
| `TextField` | 输入框 |
| `Image` | 图片或图标 |
| `Cell` | 列表项 |
| `Other` | 普通容器或无法明确归类的元素 |

## 查询字段

下列字段用于 `POST /element/find`、`findAll`、`click`、`clickRandom`、`input`、`waitFor`、`scrollFind`、`scrollClick`，以及关系接口中的 `anchor`。多个字段同时传入时为 **AND** 关系。

| 字段 | 类型 | 匹配方式 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `id` | string | 精确 | 元素树结构路径 ID，路径数字从 `0` 开始 | `"0/0/1"` |
| `identifier` | string | 精确 | 原生标识符 | `"loginBtn"` |
| 　`identifierContains` | string | 包含 | 原生标识符 | `"login"` |
| 　`identifierMatches` | string | 正则 | 原生标识符 | `".*Btn$"` |
| `text` | string | 精确 | 元素可读文字 | `"登录"` |
| 　`textContains` | string | 包含 | 元素可读文字 | `"成功"` |
| 　`textMatches` | string | 正则 | 元素可读文字；动态文案可用正则，如 `^已下载 \\d+%$` | `"^已下载 \\\\d+%$"` |
| `label` | string | 精确 | 元素标签 | `"返回"` |
| 　`labelContains` | string | 包含 | 元素标签 | `"返"` |
| 　`labelMatches` | string | 正则 | 元素标签 | `".*通知.*"` |
| `name` | string | 精确 | 元素名称，通常对应原生标识符 | `"settings"` |
| 　`nameContains` | string | 包含 | 元素名称 | `"setting"` |
| 　`nameMatches` | string | 正则 | 元素名称 | `".*setting.*"` |
| `value` | string | 精确 | 元素值，如开关状态、输入框内容 | `"打开"` |
| 　`valueContains` | string | 包含 | 元素值 | `"开"` |
| 　`valueMatches` | string | 正则 | 元素值 | `"^(打开|关闭)$"` |
| `type` | string | 精确 | 元素类型，见「元素类型」 | `"Button"` |
| 　`typeContains` | string | 包含 | 元素类型 | `"Text"` |
| 　`typeMatches` | string | 正则 | 元素类型 | `"Button|StaticText"` |
| `selector` | string | 语法 | 简化选择器，非完整 CSS | `"Button[label='通知']"` |
| `xpath` | string | 语法 | 轻量 XPath，非完整 XPath | `"//Button[@label='通知']"` |
| `visible` | boolean | 过滤 | 是否只匹配可见元素 | `true` |
| `enabled` | boolean | 过滤 | 是否只匹配可用元素 | `true` |
| `selected` | boolean | 过滤 | 是否只匹配选中元素 | `true` |
| `focused` | boolean | 过滤 | 是否只匹配焦点元素 | `true` |

`selector` 常用写法：

| 写法 | 说明 |
| --- | --- |
| `#0/0/1` | 按结构路径 `id` 查找 |
| `Button` | 按元素类型查找 |
| `Button[label='通知']` | 标签等于「通知」的按钮 |
| `[text*='通知']` | 文本包含「通知」 |
| `[text~='.*通知.*']` | 文本正则匹配 |

`xpath` 常用写法：

| 写法 | 说明 |
| --- | --- |
| `//Button` | 所有按钮 |
| `//*` | 所有元素 |
| `//Button[@label='通知']` | 标签等于「通知」的按钮 |
| `//*[@text='通知']` | 文本等于「通知」的元素 |

## maxDepth 建议

| 场景 | 推荐 `options.maxDepth` | 说明 |
| --- | --- | --- |
| 大按钮、列表项、入口 | `1` - `3` | 速度最快 |
| 普通 App 页面 | `5` - `10` | 速度与覆盖率均衡 |
| 复杂页面、评论区、电商首页 | `10` - `20` | 覆盖率更高，耗时上升 |
| 调试完整结构 | `30` - `50` | 排查问题时使用 |

`maxDepth` 表示最多向下遍历的层数；页面实际层数更浅时会提前结束

## 元素节点结构

坐标使用屏幕物理像素，与触控、`bounds`、截图一致。`bounds.centerX`、`bounds.centerY` 可传给 `/touch/tap`，或由 `/element/click` 直接点击中心点。

```json
{
  "id": "0/0/1",
  "type": "Button",
  "label": "通知",
  "value": "",
  "identifier": "",
  "visible": true,
  "enabled": true,
  "bounds": {
    "x": 0,
    "y": 0,
    "width": 1170,
    "height": 120,
    "centerX": 585,
    "centerY": 60
  },
  "children": []
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 结构路径 ID，`children` 下标从 `0` 开始 |
| `type` | string | 元素类型 |
| `label` | string | 标签或可读文字 |
| `value` | string | 元素值 |
| `identifier` | string | 原生标识符 |
| `visible` | boolean | 是否可见 |
| `enabled` | boolean | 是否可用 |
| `selected` | boolean | 是否选中 |
| `focused` | boolean | 是否获得焦点 |
| `bounds` | object | 位置与尺寸（物理像素） |
| `bounds.x` | number | 左上角 X |
| `bounds.y` | number | 左上角 Y |
| `bounds.width` | number | 宽度 |
| `bounds.height` | number | 高度 |
| `bounds.centerX` | number | 中心点 X |
| `bounds.centerY` | number | 中心点 Y |
| `children` | array | 子节点数组 |

<a id="get-element-runtimestatus"></a>

## `GET /element/runtimeStatus`

### 接口说明

读取当前 Element 无障碍运行时状态，只做诊断，不触发重新激活或重新初始化。

### 请求参数（Query）

无请求参数

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.started` | boolean | 元素服务是否已经激活 |
| `value.available` | boolean | 元素服务当前是否可用 |
| `value.interrupted` | boolean | 是否疑似被系统中断 |
| `value.message` | string | 中文状态说明 |

### 示例

```javascript
const res = await http.get("/element/runtimeStatus");
console.log(res.value.available, res.value.message);
```

<a id="get-element-activeprobe"></a>

## `GET /element/activeProbe`

### 接口说明

读取当前元素服务的活动目标探测状态，用于诊断当前元素树来自前台 App、系统弹窗还是其他可访问目标。

### 请求参数（Query）

无请求参数

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.enabled` | boolean | 活动目标探测是否启用 |
| `value.target` | string | 当前探测到的目标类型 |
| `value.message` | string | 当前探测状态说明 |

### 示例

```javascript
const res = await http.get("/element/activeProbe");
console.log(res.value.enabled, res.value.target);
```

<a id="post-element-activeprobe"></a>

## `POST /element/activeProbe`

### 接口说明

设置活动目标探测开关。开启后，元素服务会在抓取前先判断当前可访问目标，便于处理前台 App 与系统弹窗切换。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 默认值 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `enabled` | boolean | 是 | - | 是否启用活动目标探测 | `true` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.enabled` | boolean | 当前活动目标探测是否启用 |
| `value.message` | string | 设置结果说明 |

### 示例

```javascript
const res = await http.post("/element/activeProbe", { enabled: true });
console.log(res.value.enabled);
```

<a id="post-element-tree"></a>

## `POST /element/tree`

### 接口说明

获取当前页面元素树。默认会自动识别当前屏幕上的系统弹窗：有系统弹窗时返回弹窗元素树；没有系统弹窗时返回前台 App 元素树。App 自己绘制的弹窗仍属于前台 App 元素树。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `options` | object | 否 | 抓树选项；也可将字段直接放在请求根部 | — |
| 　`options.maxDepth` | number | 否 | 最大遍历层级，默认 `50`，最小 `1` | `50` |
| 　`options.maxElements` | number | 否 | 最多返回元素数量，默认 `2000`，最小 `1` | `2000` |
| 　`options.timeBudgetMs` | number | 否 | 抓树时间预算（毫秒），默认 `3000`，最大 `60000` | `3000` |
| 　`options.visibleOnly` | boolean | 否 | 是否优先只读可见元素，建议 `true` | `true` |
| 　`options.target` | string | 否 | 抓取目标，默认 `auto`；`foreground` 强制抓前台 App | `"auto"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.tree` | array | 当前页面元素树 |

### 常见失败提示

当系统无障碍服务异常中断时，元素接口可能返回 `value.errorCode = -25215`、`value.errorName = "kAXErrorServerNotFound"`。这表示当前无法连接 AX 服务，常见表现是元素树为空或所有元素查找都失败。遇到该错误时，请先重启手机；如果是越狱设备，重启后需要重新越狱，再打开目标 App 重新抓取元素。

失败响应会包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.error` | string | 错误类型，`element accessibility unavailable` |
| `value.message` | string | 面向用户的中文错误说明 |
| `value.errorCode` | number | AX 错误码，`-25215` |
| `value.errorName` | string | AX 错误名，`kAXErrorServerNotFound` |
| `value.recoverySuggestion` | string | 建议处理方式 |

### 示例

```javascript
const res = await http.post("/element/tree", {
  options: { maxDepth: 50, visibleOnly: true }
});
console.log(res.value.tree);
```

<a id="post-element-find"></a>

## `POST /element/find`

### 接口说明

查找第一个匹配元素

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| （查询条件） | — | 条件必选 | 至少传「查询字段」中的一个；多字段为 AND | `{ text: "通知", type: "Button" }` |
| `index` | number | 否 | 多个命中时取第几个，从 `0` 开始，默认 `0` | `0` |
| `timeoutMs` | number | 否 | 自动等待超时（毫秒），默认 `0` 只查一次 | `3000` |
| `intervalMs` | number | 否 | 轮询间隔（毫秒），默认 `500` | `500` |
| `caseSensitive` | boolean | 否 | 字符串是否区分大小写，默认 `false` | `false` |
| `options` | object | 否 | 抓树选项 | — |
| 　`options.maxDepth` | number | 否 | 最大遍历层级，默认 `50` | `50` |
| 　`options.maxElements` | number | 否 | 最多参与查找的元素数，默认 `2000` | `2000` |
| 　`options.timeBudgetMs` | number | 否 | 抓树时间预算（毫秒），默认 `3000` | `3000` |
| 　`options.visibleOnly` | boolean | 否 | 是否优先只读可见元素，建议 `true` | `true` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.found` | boolean | 是否找到 |
| `value.count` | number | 匹配数量 |
| `value.returnedCount` | number | 本次返回数量，通常为 `0` 或 `1` |
| `value.scannedCount` | number | 参与匹配的节点数量 |
| `value.usedIdFastPath` | boolean | 是否使用 `id` 快速定位；仅传入 `id` 时可能为 `true` |
| `value.durationMs` | number | 耗时（毫秒） |
| `value.attempts` | number | 尝试次数 |
| `value.element` | object/null | 命中的元素；未找到为 `null` |
| `value.query` | object | 本次实际使用的查询条件 |

### 示例

```javascript
const res = await http.post("/element/find", {
  text: "通知",
  type: "Button",
  visible: true,
  timeoutMs: 3000
});
if (res.value.found) {
  console.log(res.value.element.bounds);
}
```

## `POST /element/clickRandom`

### 接口说明

查找第一个匹配元素，在 `bounds` 内随机选择安全点点击（默认避开边缘）；区域过小时退回中心点

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| （查询条件） | — | 条件必选 | 同 `POST /element/click` | `{ text: "通知", type: "Button" }` |
| `index` | number | 否 | 同 `POST /element/click` | `0` |
| `timeoutMs` | number | 否 | 同 `POST /element/click` | `3000` |
| `intervalMs` | number | 否 | 同 `POST /element/click` | `500` |
| `duration` | number | 否 | 同 `POST /element/click` | `30` |
| `caseSensitive` | boolean | 否 | 同 `POST /element/click` | `false` |
| `randomPadding` | number | 否 | 随机点距边缘最小距离（物理像素），默认 `12` | `12` |
| `options` | object | 否 | 同 `POST /element/click` | — |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.success` | boolean | 是否成功点击 |
| `value.found` | boolean | 是否找到匹配元素 |
| `value.point` | object | 本次点击坐标 |

## `POST /element/scrollFind`

### 接口说明

跨屏滚动查找元素；当前屏未找到时按 `direction` 使用缓出轨迹滚动后继续查找。

滚动后的未命中页面会立即进入下一次滚动，不固定等待；命中目标后会短间隔复查其坐标，只在坐标稳定时返回。这样既避免把惯性滚动中的旧坐标交给后续点击，也避免在每个未命中页面无效停顿。

`direction`：`down` 向下（常用）、`up` 向上、`right` 向右、`left` 向左。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| （查询条件） | — | 条件必选 | 至少传「查询字段」中的一个；多字段为 AND | `{ textContains: "京东" }` |
| `direction` | string | 否 | 滚动方向，默认 `down` | `"down"` |
| `maxScrolls` | number | 否 | 最多滚动次数，默认 `8`，最大 `100` | `8` |
| `scrollDuration` | number | 否 | 每次滑动时长（毫秒），默认 `500` | `500` |
| `scrollDelayMs` | number | 否 | 命中目标后的坐标稳定确认上限（毫秒），稳定后会提前返回；默认 `800` | `800` |
| `scrollStepRatio` | number | 否 | 每次滚动约占屏幕高度比例，默认 `0.30` | `0.30` |
| `startX` | number | 条件必选 | 自定义滑动起点 X；须与 `startY`、`endX`、`endY` 同时传入 | `585` |
| 　`startY` | number | 条件必选 | 自定义滑动起点 Y | `1800` |
| 　`endX` | number | 条件必选 | 自定义滑动终点 X | `585` |
| 　`endY` | number | 条件必选 | 自定义滑动终点 Y | `800` |
| `timeoutMs` | number | 否 | 首屏查找的自动等待（毫秒），默认 `0`；滚动后立即扫描 | `1000` |
| `intervalMs` | number | 否 | 首屏自动等待的轮询间隔（毫秒），默认 `500` | `500` |

| 字段 | 类型 | 说明 |

| `value.element` | object/null | 命中的元素 |
| `value.scrollCount` | number | 实际滚动次数；当前屏找到时为 `0` |
