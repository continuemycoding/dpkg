# 08. 元素查找

元素模块用于读取当前页面的元素树，并按条件查找、点击元素或输入文本。

`value.success`、`value.message`、`value.error` 是元素查找、点击、输入等业务结果字段，不是 HTTP 层响应格式。HTTP 层失败统一见 [公共规则](../01_公共规则.md)。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`POST /element/tree`](#post-element-tree) | 获取当前页面元素树 |
| [`POST /element/find`](#post-element-find) | 查找第一个匹配元素 |
| [`POST /element/findAll`](#post-element-findall) | 查找所有匹配元素 |
| [`POST /element/click`](#post-element-click) | 查找并点击元素中心点 |
| [`POST /element/clickRandom`](#post-element-clickrandom) | 查找并在元素区域内随机点击 |
| [`POST /element/input`](#post-element-input) | 查找输入控件并输入文本 |
| [`POST /element/waitFor`](#post-element-waitfor) | 等待元素出现或消失 |
| [`POST /element/scrollFind`](#post-element-scrollfind) | 跨屏滚动查找元素 |
| [`POST /element/scrollClick`](#post-element-scrollclick) | 跨屏滚动查找并点击 |
| [`POST /element/parent`](#post-element-parent) | 获取锚点元素的父节点 |
| [`POST /element/child`](#post-element-child) | 获取锚点元素的指定直接子节点 |
| [`POST /element/children`](#post-element-children) | 获取锚点元素的全部直接子节点 |
| [`POST /element/siblings`](#post-element-siblings) | 获取锚点元素的全部兄弟节点 |
| [`POST /element/previousSiblings`](#post-element-previoussiblings) | 获取锚点元素前面的兄弟节点 |
| [`POST /element/nextSiblings`](#post-element-nextsiblings) | 获取锚点元素后面的兄弟节点 |

## 元素类型

| 类型 | 说明 |
| --- | --- |
| `Window` | 窗口根节点 |
| `Button` | 按钮、可点击入口、列表项 |
| `StaticText` | 静态文字 |
| `TextField` | 输入框 |
| `Image` | 图片或图标 |
| `Cell` | 列表项 |
| `Other` | 普通容器或无法明确归类的元素 |

## 查询字段

下列字段用于 `POST /element/find`、`findAll`、`click`、`clickRandom`、`input`、`waitFor`、`scrollFind`、`scrollClick`，以及关系接口中的 `anchor`。多个字段同时传入时为 **AND** 关系。

| 字段 | 类型 | 匹配方式 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `id` | string | 精确 | 本次元素树的结构路径 ID，不因筛选重新编号 | `"0/0/1"` |
| `identifier` | string | 精确 | 元素提供的原生标识符 | `"loginBtn"` |
| 　`identifierContains` | string | 包含 | 元素提供的原生标识符 | `"login"` |
| 　`identifierMatches` | string | 正则 | 元素提供的原生标识符 | `".*Btn$"` |
| `text` | string | 精确 | 元素可读文字 | `"登录"` |
| 　`textContains` | string | 包含 | 元素可读文字 | `"成功"` |
| 　`textMatches` | string | 正则 | 元素可读文字；动态文案可用正则，如 `^已下载 \\d+%$` | `"^已下载 \\\\d+%$"` |
| `label` | string | 精确 | 元素标签 | `"返回"` |
| 　`labelContains` | string | 包含 | 元素标签 | `"返"` |
| 　`labelMatches` | string | 正则 | 元素标签 | `".*通知.*"` |
| `name` | string | 精确 | `identifier` 的查询别名 | `"settings"` |
| 　`nameContains` | string | 包含 | `identifierContains` 的查询别名 | `"setting"` |
| 　`nameMatches` | string | 正则 | `identifierMatches` 的查询别名 | `".*setting.*"` |
| `value` | string | 精确 | 元素值，如开关状态、输入框内容 | `"打开"` |
| 　`valueContains` | string | 包含 | 元素值 | `"开"` |
| 　`valueMatches` | string | 正则 | 元素值 | `"^(打开|关闭)$"` |
| `type` | string | 精确 | 元素类型，见「元素类型」 | `"Button"` |
| 　`typeContains` | string | 包含 | 元素类型 | `"Text"` |
| 　`typeMatches` | string | 正则 | 元素类型 | `"Button|StaticText"` |
| `selector` | string | 语法 | 简化选择器，非完整 CSS | `"Button[label='通知']"` |
| `xpath` | string | 语法 | 轻量 XPath，非完整 XPath | `"//Button[@label='通知']"` |
| `enabled` | boolean | 过滤 | 是否只匹配可用元素 | `true` |
| `selected` | boolean | 过滤 | 是否只匹配选中元素 | `true` |
| `focused` | boolean | 过滤 | 是否只匹配焦点元素 | `true` |

任一查询字段都可以单独使用，包括 `enabled`、`selected` 和 `focused` 等布尔字段。`selected: false` 或 `focused: false` 只匹配明确判定为对应假状态的元素，未知状态不匹配。

字符串查询必须是非空字符串；空字符串或 `null` 不构成查找条件。关系接口的 `anchor` 也使用相同规则。

`selector` 常用写法：

| 写法 | 说明 |
| --- | --- |
| `#0/0/1` | 按结构路径 `id` 查找 |
| `Button` | 按元素类型查找 |
| `Button[label='通知']` | 标签等于「通知」的按钮 |
| `[text*='通知']` | 文本包含「通知」 |
| `[text~='.*通知.*']` | 文本正则匹配 |

`xpath` 常用写法：

| 写法 | 说明 |
| --- | --- |
| `//Button` | 所有按钮 |
| `//*` | 所有元素 |
| `//Button[@label='通知']` | 标签等于「通知」的按钮 |
| `//*[@text='通知']` | 文本等于「通知」的元素 |

<a id="element-visibility"></a>

## 选择哪些元素

用 `options.visibility` 选择查找范围。通常保留默认值；只需要屏幕上可见的内容时，选择 `visible`。

| 值 | 返回范围 | 使用场景 |
| --- | --- | --- |
| `all`（默认） | 本次可以读取到的全部元素，不要求判断可见性 | 读取结构、按文字或标识符定位 |
| `visible` | 确认可见的元素 | 只查当前可见内容，等待内容显示 |
| `hidden` | 确认不可见的元素 | 查找仍存在但不可见的内容 |

所有元素接口默认使用 `all`，结果可能包含不可见元素。这里的“全部”仅指本次可读取的内容，不保证包含其他桌面页或尚未加载的列表项。

读取全部元素：

```javascript
const res = await http.post("/element/tree", {
  options: { visibility: "all" }
});
console.log(res.value.tree);
```

只查可见按钮：

```javascript
const res = await http.post("/element/findAll", {
  type: "Button",
  options: { visibility: "visible" }
});
console.log(res.value.elements);
```

只查不可见按钮：

```javascript
const res = await http.post("/element/findAll", {
  type: "Button",
  options: { visibility: "hidden" }
});
console.log(res.value.elements);
```

请求中的 `options.visibility` 表示“要查哪些元素”，返回的 `visibility` 表示“这个元素是否可见”：

| 状态 | 含义 |
| --- | --- |
| `visible` | 确认可见 |
| `hidden` | 确认不可见 |
| `unknown` | 未检查或无法确认；不能当作不可见 |

使用 `all` 时，返回的 `visibility` 为 `unknown`，表示本次不判断可见性。使用 `visible` 或 `hidden` 可能更慢。元素可见也不一定可以点击。

`tree` 为展示完整层级，可能附带不符合所选范围的父节点；`find`、`findAll` 只返回匹配项。请直接使用返回的 `id`，不要根据数组下标拼接，也不要跨次读取复用。

### 查询和参数规则

可见性只能通过 `options.visibility` 设置，值为小写的 `all`、`visible` 或 `hidden`，不要写在 `anchor`、`selector` 或 `xpath` 中。参数无效或位置错误时返回 HTTP 400。

查找接口还需提供查询条件。需要匹配全部元素时，可使用 `selector: "//*"`。

无法确认所选范围时，接口返回错误，不会将读取失败当作“没有匹配元素”。

### 点击、输入和滚动

`click`、`clickRandom`、`input`、`scrollClick` 只支持 `all` 和 `visible`；传入 `hidden` 返回 HTTP 400。即使使用 `all`，目标不可操作时也会失败。

普通点击或输入按 `index` 选定匹配目标；该目标无法操作时不会自动换成下一个同名元素。可使用标识符、更多查询条件或 `visible` 明确目标。

`scrollFind` 使用 `all` 时，可能不滚动就返回屏外目标；需要滚动到可见时使用 `visible`。`scrollClick` 会尝试滚动并点击，是否操作成功以 `value.success` 为准。

### 等待出现和消失

`waitFor` 在所选范围内判断 `present` / `gone`：

| 需求 | `options.visibility` | `until` |
| --- | --- | --- |
| 等待元素可以被查到 | `all` | `present` |
| 等待元素从可读取范围中移除 | `all` | `gone` |
| 等待元素变得可见 | `visible` | `present` |
| 等待元素不再可见或被移除 | `visible` | `gone` |

读取失败或结果不完整时，接口可能返回错误，不会将这些情况直接判定为元素消失。

### 关系查询

`options.visibility` 同时约束锚点和返回节点，筛选不会改变页面原有的父子、兄弟关系。

`anchorIndex` 用于选择匹配的锚点。`child.index` 按原始子节点顺序计数，不按筛选结果重新编号。指定子节点或直接父节点不符合范围时，返回未找到，不会换取其他节点。

## maxDepth 建议

| 场景 | 推荐 `options.maxDepth` | 说明 |
| --- | --- | --- |
| 大按钮、列表项、入口 | `1` - `3` | 速度最快 |
| 普通 App 页面 | `5` - `10` | 速度与覆盖率均衡 |
| 复杂页面、评论区、电商首页 | `10` - `20` | 覆盖率更高，耗时上升 |
| 完整页面结构 | 省略或 `50` | 默认值为 `50` |

`maxDepth` 表示最多向下查找的层数，可设置为 `1` - `62`；页面实际层数更浅时会提前结束。

## 结果完整性

当元素数量或查找深度达到设置的上限时，`tree` 可能只返回部分结果。可通过 `value.complete` 和 `value.truncated` 判断，并适当增大 `maxDepth` 或 `maxElements` 后重试。“完整”仅针对本次可读取的页面内容。

## 时间预算规则

所有元素接口的单次页面读取上限默认为 **5 秒**，`waitFor` 默认最多等待 **5 秒**。其他接口的 `timeoutMs` 默认为 `0`，只检查一次；需要等待目标出现时，可设置 `timeoutMs: 5000`，命中后立即返回。

对于 `find`、`findAll`、`click`、`clickRandom`、`input`、`waitFor` 和关系查询：

- `timeoutMs` 是查找或等待阶段的总时间上限，不会在每次轮询时重新计算。
- `options.timeBudgetMs` 是单次页面读取的时间上限；存在总等待时间时，单次读取还会受剩余时间约束。
- `timeoutMs: 0` 表示只检查一次，不表示请求必须立即返回；这一次检查仍受 `options.timeBudgetMs` 约束。
- `intervalMs` 只控制两次检查之间的间隔，等待时间也包含在 `timeoutMs` 内。

`tree` 使用 `options.timeBudgetMs`。查找和等待的时间包含服务端排队时间；增加超时只能延长等待，不能让页面读取更快。

点击、输入还需执行相应动作，因此 `timeoutMs` 不是整个操作的总耗时上限。`scrollFind` 和 `scrollClick` 的 `timeoutMs` 仅用于首屏查找，总耗时还受滚动次数、滚动间隔和页面读取时间影响。

客户端超时应为网络传输和操作耗时留出余量。客户端等待更久，不会自动延长服务端的时间限制。

### 取消与重试

断开客户端连接或停止所属脚本任务，可取消后续查找和等待，但不会撤销已经发生的点击或输入。取消也不保证已开始的操作立即停止。

动作请求超时或取消后，请先确认页面结果，再决定是否重试，避免重复操作。

<a id="element-errors"></a>

### 常见错误

“没有找到”通常由 `value.found: false` 表示；请求失败时，查看 `value.error` 和 `value.message`。

| HTTP 状态 | `value.error` 或情况 | 处理建议 |
| --- | --- | --- |
| `400` | 参数无效 | 检查参数位置、类型和取值 |
| `500` | `element query timeout` | 适当增加时间限制，或缩小读取范围 |
| `500` | `element visibility unavailable` | 稍后重试；不需要判断可见性时可使用 `all` |
| `500` | `element tree incomplete` | 适当增加 `maxDepth` 或 `maxElements` 后重试 |
| `423` | `session unavailable` | 根据 `value.message` 检查会话或请求取消状态 |

取消不保证返回 `423`；连接已断开时不会收到响应。

## 元素节点结构

坐标使用屏幕物理像素，与触控、`bounds`、截图一致。`bounds.centerX`、`bounds.centerY` 可传给 `/touch/tap`，或由 `/element/click` 直接点击中心点。

```json
{
  "id": "0/0/1",
  "type": "StaticText",
  "label": "通知",
  "identifier": "NOTIFICATIONS_ID",
  "visibility": "unknown",
  "enabled": true,
  "bounds": {
    "x": 0,
    "y": 0,
    "width": 1170,
    "height": 120,
    "centerX": 585,
    "centerY": 60
  },
  "children": []
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 本次读取的结构路径 ID；筛选后不重新编号，不保证跨次读取稳定 |
| `type` | string | 元素类型 |
| `label` | string（可选） | 元素有标签时返回的可读文字 |
| `value` | string（可选） | 元素有值时返回的内容或状态值 |
| `identifier` | string（可选） | 元素提供非空原生标识符时返回；不使用 `label` 或 `value` 代替 |
| `visibility` | string | `visible` / `hidden` / `unknown`；默认读取返回 `unknown`，见[范围说明](#element-visibility) |
| `enabled` | boolean | 是否可用 |
| `selected` | boolean（可选） | 是否选中；状态未知时省略 |
| `focused` | boolean（可选） | 是否有焦点；状态未知时省略，只有能唯一确认焦点时才标记 `true` |
| `bounds` | object | 位置与尺寸（物理像素） |
| `bounds.x` | number | 左上角 X |
| `bounds.y` | number | 左上角 Y |
| `bounds.width` | number | 宽度 |
| `bounds.height` | number | 高度 |
| `bounds.centerX` | number | 中心点 X |
| `bounds.centerY` | number | 中心点 Y |
| `children` | array | 子节点数组 |

<a id="post-element-tree"></a>

## `POST /element/tree`

### 接口说明

获取当前页面元素树。App 自己绘制的弹窗也属于前台 App 元素树。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `options` | object | 否 | 页面读取选项；`visibility` 必须放在 `options` 内，其他选项也建议统一放在此处 | — |
| 　`options.maxDepth` | number | 否 | 最大读取层级，默认 `50`、最大 `62`、最小 `1` | `50` |
| 　`options.maxElements` | number | 否 | 最多返回元素数量，默认 `2000`，最小 `1` | `2000` |
| 　`options.timeBudgetMs` | number | 否 | 单次页面读取的时间上限（毫秒），默认 `5000`、最大 `60000` | `5000` |
| 　`options.visibility` | string | 否 | 元素范围：`all`（默认）/ `visible` / `hidden`，见[范围说明](#element-visibility) | `"all"` |
| 　`options.target` | string | 否 | 抓取目标，仅支持 `auto` / `foreground`；默认 `auto`，`foreground` 强制抓前台 App | `"auto"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.tree` | array | 当前页面元素树 |
| `value.complete` | boolean | 返回结果是否完整 |
| `value.truncated` | boolean | 是否因 `maxDepth` 或 `maxElements` 到达上限而截断 |
| `value.truncationReason` | string / null | 截断原因：`maxDepth` / `maxElements`；未截断时为 `null` |

### 常见失败提示

页面无法读取、超时或无法判断可见性时，接口返回错误，见[常见错误](#element-errors)。失败响应包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.error` | string | 稳定错误类型 |
| `value.message` | string | 面向用户的中文错误说明 |

### 示例

```javascript
const res = await http.post("/element/tree", {
  options: { visibility: "all" }
});
console.log(res.value.complete, res.value.tree);
```

<a id="post-element-find"></a>

## `POST /element/find`

### 接口说明

查找第一个匹配元素

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| （查询条件） | — | 条件必选 | 至少传「查询字段」中的一个；多字段为 AND | `{ text: "通知", type: "Button" }` |
| `index` | number | 否 | 多个命中时取第几个，从 `0` 开始，默认 `0` | `0` |
| `timeoutMs` | number | 否 | 自动等待超时（毫秒），默认 `0` 只查一次 | `3000` |
| `intervalMs` | number | 否 | 轮询间隔（毫秒），默认 `500` | `500` |
| `caseSensitive` | boolean | 否 | 字符串是否区分大小写，默认 `false` | `false` |
| `options` | object | 否 | 页面读取选项 | — |
| 　`options.maxDepth` | number | 否 | 最大读取层级，默认 `50`、最大 `62`、最小 `1` | `50` |
| 　`options.maxElements` | number | 否 | 最多参与查找的元素数，默认 `2000` | `2000` |
| 　`options.timeBudgetMs` | number | 否 | 单次页面读取的时间上限（毫秒），默认 `5000`、最大 `60000` | `5000` |
| 　`options.visibility` | string | 否 | 元素范围：`all`（默认）/ `visible` / `hidden`，见[范围说明](#element-visibility) | `"all"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.found` | boolean | 是否找到 |
| `value.count` | number | 匹配数量 |
| `value.returnedCount` | number | 本次返回数量，通常为 `0` 或 `1` |
| `value.scannedCount` | number | 参与匹配的节点数量 |
| `value.durationMs` | number | 耗时（毫秒） |
| `value.attempts` | number | 尝试次数 |
| `value.element` | object/null | 命中的元素；未找到为 `null` |
| `value.query` | object | 本次实际使用的查询条件 |

### 示例

```javascript
const res = await http.post("/element/find", {
  options: { visibility: "visible" },
  text: "通知",
  type: "Button",
  timeoutMs: 3000
});
if (res.value.found) {
  console.log(res.value.element.bounds);
}
```

<a id="post-element-findall"></a>

## `POST /element/findAll`

### 接口说明

查找所有匹配元素

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| （查询条件） | — | 条件必选 | 至少传「查询字段」中的一个；多字段为 AND | `{ type: "Button" }` |
| `maxResults` | number | 否 | 最多返回数量，默认 `50`，最大 `2000` | `100` |
