# 08. 元素查找

元素模块用于读取当前页面的元素树，并按条件查找、点击、输入元素

> **能力提示：** 安全字段与 WebView 元素识别能力增强。

`value.success`、`value.message`、`value.error` 是元素查找、点击、输入等业务结果字段，不是 HTTP 层响应格式。HTTP 层失败统一见 [公共规则](../01_公共规则.md)。

## 元素类型

| 类型 | 说明 |
| --- | --- |
| `Window` | 窗口根节点 |
| `Button` | 按钮、可点击入口、列表项 |
| `StaticText` | 静态文字 |
| `TextField` | 输入框 |
| `Image` | 图片或图标 |
| `Cell` | 列表项 |
| `Other` | 普通容器或无法明确归类的元素 |

## 查询字段

下列字段用于 `POST /element/find`、`findAll`、`click`、`clickRandom`、`input`、`waitFor`、`scrollFind`、`scrollClick`，以及关系接口中的 `anchor`。多个字段同时传入时为 **AND** 关系。

| 字段 | 类型 | 匹配方式 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `id` | string | 精确 | 元素树结构路径 ID，路径数字从 `0` 开始 | `"0/0/1"` |
| `identifier` | string | 精确 | 元素提供的原生标识符 | `"loginBtn"` |
| 　`identifierContains` | string | 包含 | 元素提供的原生标识符 | `"login"` |
| 　`identifierMatches` | string | 正则 | 元素提供的原生标识符 | `".*Btn$"` |
| `text` | string | 精确 | 元素可读文字 | `"登录"` |
| 　`textContains` | string | 包含 | 元素可读文字 | `"成功"` |
| 　`textMatches` | string | 正则 | 元素可读文字；动态文案可用正则，如 `^已下载 \\d+%$` | `"^已下载 \\\\d+%$"` |
| `label` | string | 精确 | 元素标签 | `"返回"` |
| 　`labelContains` | string | 包含 | 元素标签 | `"返"` |
| 　`labelMatches` | string | 正则 | 元素标签 | `".*通知.*"` |
| `name` | string | 精确 | `identifier` 的查询别名 | `"settings"` |
| 　`nameContains` | string | 包含 | `identifierContains` 的查询别名 | `"setting"` |
| 　`nameMatches` | string | 正则 | `identifierMatches` 的查询别名 | `".*setting.*"` |
| `value` | string | 精确 | 元素值，如开关状态、输入框内容 | `"打开"` |
| 　`valueContains` | string | 包含 | 元素值 | `"开"` |
| 　`valueMatches` | string | 正则 | 元素值 | `"^(打开|关闭)$"` |
| `type` | string | 精确 | 元素类型，见「元素类型」 | `"Button"` |
| 　`typeContains` | string | 包含 | 元素类型 | `"Text"` |
| 　`typeMatches` | string | 正则 | 元素类型 | `"Button|StaticText"` |
| `selector` | string | 语法 | 简化选择器，非完整 CSS | `"Button[label='通知']"` |
| `xpath` | string | 语法 | 轻量 XPath，非完整 XPath | `"//Button[@label='通知']"` |
| `visible` | boolean | 过滤 | 是否只匹配可见元素 | `true` |
| `enabled` | boolean | 过滤 | 是否只匹配可用元素 | `true` |
| `selected` | boolean | 过滤 | 是否只匹配选中元素 | `true` |
| `focused` | boolean | 过滤 | 是否只匹配焦点元素 | `true` |

任一查询字段都可以单独使用，包括 `visible`、`enabled`、`selected` 和 `focused` 等布尔字段。`selected: false` 或 `focused: false` 匹配未标记为对应真状态的元素。

字符串查询必须是非空字符串；空字符串或 `null` 不构成查找条件。关系接口的 `anchor` 也使用相同规则。

`selector` 常用写法：

| 写法 | 说明 |
| --- | --- |
| `#0/0/1` | 按结构路径 `id` 查找 |
| `Button` | 按元素类型查找 |
| `Button[label='通知']` | 标签等于「通知」的按钮 |
| `[text*='通知']` | 文本包含「通知」 |
| `[text~='.*通知.*']` | 文本正则匹配 |

`xpath` 常用写法：

| 写法 | 说明 |
| --- | --- |
| `//Button` | 所有按钮 |
| `//*` | 所有元素 |
| `//Button[@label='通知']` | 标签等于「通知」的按钮 |
| `//*[@text='通知']` | 文本等于「通知」的元素 |

## maxDepth 建议

| 场景 | 推荐 `options.maxDepth` | 说明 |
| --- | --- | --- |
| 大按钮、列表项、入口 | `1` - `3` | 速度最快 |
| 普通 App 页面 | `5` - `10` | 速度与覆盖率均衡 |
| 复杂页面、评论区、电商首页 | `10` - `20` | 覆盖率更高，耗时上升 |
| 调试完整结构 | `30` - `50` | 排查问题时使用 |

`maxDepth` 表示最多向下遍历的层数；页面实际层数更浅时会提前结束

## 查找模式

所有接受 `options` 的元素接口都支持 `options.searchMode`，包括元素树、查找、点击、输入、等待、滚动查找和关系查询。

| 值 | 默认 | 适用场景 | 特点 |
| --- | --- | --- | --- |
| `"fast"` | 是 | 日常查找和高频操作 | 优先保证响应速度，建议默认使用 |
| `"slow"` | 否 | 页面上确实可见、但快速模式没有返回的目标 | 扩大可发现范围，可能增加耗时 |

- 不传 `options.searchMode` 与传入 `"fast"` 完全一致。
- 只有请求明确传入 `"slow"` 时才启用慢速查找；该设置仅对当前请求生效，不会改变后续请求。
- 建议先使用 `fast`，确认可见目标缺失后再对该请求使用 `slow`。
- 两种模式使用相同的查询字段和响应结构，并且都受 `maxDepth`、`maxElements` 与 `timeBudgetMs` 限制。
- 只接受 `"fast"` 或 `"slow"`；其他类型或值会返回参数错误。

## 时间预算规则

对于 `find`、`findAll`、`click`、`clickRandom`、`input`、`waitFor` 和关系查询：

- `timeoutMs` 是查找或等待阶段的总时间上限，不会在每次轮询时重新计算。
- `options.timeBudgetMs` 是单次页面读取的时间上限；存在总等待时间时，单次读取还会受剩余时间约束。
- `timeoutMs: 0` 表示只检查一次，不表示请求必须立即返回；这一次检查仍受 `options.timeBudgetMs` 约束。
- `intervalMs` 只控制两次检查之间的间隔，等待时间也包含在 `timeoutMs` 内。

时间参数是操作预算，不是硬实时计时器；正在完成的系统操作可能带来少量返回尾差。

`scrollFind` 和 `scrollClick` 的 `timeoutMs` 只用于首屏查找。整次跨屏操作的最大工作量还由 `maxScrolls`、`scrollDelayMs` 和 `options.timeBudgetMs` 共同决定，因此 `timeoutMs` 不是整个跨屏请求的总耗时上限。

## 元素节点结构

坐标使用屏幕物理像素，与触控、`bounds`、截图一致。`bounds.centerX`、`bounds.centerY` 可传给 `/touch/tap`，或由 `/element/click` 直接点击中心点。

```json
{
  "id": "0/0/1",
  "type": "StaticText",
  "label": "通知",
  "identifier": "NOTIFICATIONS_ID",
  "visible": true,
  "enabled": true,
  "bounds": {
    "x": 0,
    "y": 0,
    "width": 1170,
    "height": 120,
    "centerX": 585,
    "centerY": 60
  },
  "children": []
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 结构路径 ID，`children` 下标从 `0` 开始 |
| `type` | string | 元素类型 |
| `label` | string（可选） | 元素有标签时返回的可读文字 |
| `value` | string（可选） | 元素有值时返回的内容或状态值 |
| `identifier` | string（可选） | 元素提供非空原生标识符时返回；不使用 `label` 或 `value` 代替 |
| `visible` | boolean | 是否可见 |
| `enabled` | boolean | 是否可用 |
| `selected` | boolean（可选） | 元素被明确标记为选中时返回 `true` |
| `focused` | boolean（可选） | 只有能唯一确认焦点元素时，才在该元素上返回 `true` |
| `bounds` | object | 位置与尺寸（物理像素） |
| `bounds.x` | number | 左上角 X |
| `bounds.y` | number | 左上角 Y |
| `bounds.width` | number | 宽度 |
| `bounds.height` | number | 高度 |
| `bounds.centerX` | number | 中心点 X |
| `bounds.centerY` | number | 中心点 Y |
| `children` | array | 子节点数组 |

<a id="get-element-runtimestatus"></a>

## `GET /element/runtimeStatus`

### 接口说明

读取当前 Element 无障碍运行时状态，只做诊断，不触发重新激活或重新初始化。

### 请求参数（Query）

无请求参数

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.started` | boolean | 元素服务是否已经激活 |
| `value.available` | boolean | 元素服务当前是否可用 |
| `value.interrupted` | boolean | 是否疑似被系统中断 |
| `value.message` | string | 中文状态说明 |

### 示例

```javascript
const res = await http.get("/element/runtimeStatus");
console.log(res.value.available, res.value.message);
```

<a id="get-element-activeprobe"></a>

## `GET /element/activeProbe`

### 接口说明

执行一次活动目标诊断，用于比较业务前台 App 与当前可交互目标。此接口只返回本次诊断结果，不修改元素服务配置。

此接口的探测点使用当前屏幕方向下的 UIKit 点坐标；它是诊断输入，不是元素 `bounds` 或触控使用的物理像素坐标。未传坐标时由服务选择默认探测点。

### 请求参数（Query）

可通过 Query 传入以下可选参数：

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `x` | number | 否 | 探测点横坐标（UIKit 点）；必须与 `y` 一起传入 | `188` |
| `y` | number | 否 | 探测点纵坐标（UIKit 点）；必须与 `x` 一起传入 | `334` |
| `resolveProcess` | boolean | 否 | 是否补充解析目标进程信息；默认 `false` | `false` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.success` | boolean | 本次诊断是否完成 |
| `value.foreground.bundleId` | string | 当前业务前台 App 包名 |
| `value.foreground.pid` | number | 当前业务前台 App 进程 PID |
| `value.active.bundleId` | string | 当前可交互目标包名；无法确认时为空字符串 |
| `value.active.pid` | number | 当前可交互目标进程 PID |
| `value.active.sameAsForeground` | boolean | 当前可交互目标是否与业务前台 App 一致 |
| `value.active.isOverlay` | boolean | 当前可交互目标是否属于覆盖层 |
| `value.active.systemDialogCandidate` | boolean | 当前可交互目标是否可能是系统弹窗 |
| `value.durationMs` | number | 本次诊断耗时（毫秒） |

### 示例

```javascript
const res = await http.get("/element/activeProbe");
console.log(res.value.foreground, res.value.active);
```

<a id="post-element-activeprobe"></a>

## `POST /element/activeProbe`

### 接口说明

执行一次活动目标诊断。与 GET 版本返回相同类型的结果；POST 适合在 JSON Body 中传入坐标。此接口不是持久开关。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 默认值 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `x` | number | 否 | 无 | 探测点横坐标（UIKit 点）；必须与 `y` 一起传入 | `188` |
| `y` | number | 否 | 无 | 探测点纵坐标（UIKit 点）；必须与 `x` 一起传入 | `334` |
| `resolveProcess` | boolean | 否 | `false` | 是否补充解析目标进程信息 | `false` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
响应字段与 `GET /element/activeProbe` 相同。

### 示例

```javascript
const res = await http.post("/element/activeProbe", {
  x: 188,
  y: 334,
  resolveProcess: false
});
console.log(res.value.foreground, res.value.active);
```

<a id="post-element-tree"></a>

## `POST /element/tree`

### 接口说明

获取当前页面元素树。默认使用快速模式读取当前前台页面；如果屏幕上确实可见的目标没有返回，可对本次请求改用慢速模式。App 自己绘制的弹窗仍属于前台 App 元素树。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `options` | object | 否 | 抓树选项；也可将字段直接放在请求根部 | — |
| 　`options.maxDepth` | number | 否 | 最大遍历层级，默认 `50`，最小 `1` | `50` |
| 　`options.maxElements` | number | 否 | 最多返回元素数量，默认 `2000`，最小 `1` | `2000` |
| 　`options.timeBudgetMs` | number | 否 | 抓树时间预算（毫秒），默认 `3000`，最大 `60000` | `3000` |
| 　`options.visibleOnly` | boolean | 否 | 是否优先只读可见元素，建议 `true` | `true` |
| 　`options.searchMode` | string | 否 | 查找模式，支持 `fast` / `slow`，默认 `fast` | `"fast"` |
| 　`options.target` | string | 否 | 抓取目标，仅支持 `auto` / `foreground`；默认 `auto`，`foreground` 强制抓前台 App | `"auto"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.tree` | array | 当前页面元素树 |

### 常见失败提示

当元素服务暂时不可用时，常见表现是元素树为空或元素查找失败。请根据 `value.message` 操作；仍无法恢复时，可重启设备后重新打开目标 App。

失败响应的稳定用户字段为：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.error` | string | 稳定错误类型 |
| `value.message` | string | 面向用户的中文错误说明 |
| `value.recoverySuggestion` | string（可选） | 可执行的恢复建议 |

### 示例

```javascript
const res = await http.post("/element/tree", {
  options: { maxDepth: 50, visibleOnly: true }
});
console.log(res.value.tree);
```

<a id="post-element-find"></a>

## `POST /element/find`

### 接口说明

查找第一个匹配元素

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| （查询条件） | — | 条件必选 | 至少传「查询字段」中的一个；多字段为 AND | `{ text: "通知", type: "Button" }` |
| `index` | number | 否 | 多个命中时取第几个，从 `0` 开始，默认 `0` | `0` |
| `timeoutMs` | number | 否 | 自动等待超时（毫秒），默认 `0` 只查一次 | `3000` |
| `intervalMs` | number | 否 | 轮询间隔（毫秒），默认 `500` | `500` |
| `caseSensitive` | boolean | 否 | 字符串是否区分大小写，默认 `false` | `false` |
| `options` | object | 否 | 抓树选项 | — |
| 　`options.maxDepth` | number | 否 | 最大遍历层级，默认 `50` | `50` |
| 　`options.maxElements` | number | 否 | 最多参与查找的元素数，默认 `2000` | `2000` |
| 　`options.timeBudgetMs` | number | 否 | 抓树时间预算（毫秒），默认 `3000` | `3000` |
| 　`options.visibleOnly` | boolean | 否 | 是否优先只读可见元素，建议 `true` | `true` |
| 　`options.searchMode` | string | 否 | 查找模式，支持 `fast` / `slow`，默认 `fast` | `"fast"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.found` | boolean | 是否找到 |
| `value.count` | number | 匹配数量 |
| `value.returnedCount` | number | 本次返回数量，通常为 `0` 或 `1` |
| `value.scannedCount` | number | 参与匹配的节点数量 |
| `value.usedIdFastPath` | boolean | 是否使用 `id` 快速定位；仅传入 `id` 时可能为 `true` |
| `value.durationMs` | number | 耗时（毫秒） |
| `value.attempts` | number | 尝试次数 |
| `value.element` | object/null | 命中的元素；未找到为 `null` |
| `value.query` | object | 本次实际使用的查询条件 |

### 示例

```javascript
const res = await http.post("/element/find", {
  text: "通知",
  type: "Button",
  visible: true,
  timeoutMs: 3000
});
if (res.value.found) {
  console.log(res.value.element.bounds);
}
```

| `intervalMs` | number | 否 | 轮询间隔（毫秒），默认 `500` | `500` |
| `caseSensitive` | boolean | 否 | 字符串是否区分大小写，默认 `false` | `false` |
| `options` | object | 否 | 抓树选项 | — |
| 　`options.maxDepth` | number | 否 | 最大遍历层级，默认 `50` | `50` |
| 　`options.maxElements` | number | 否 | 最多参与查找的元素数，默认 `2000` | `2000` |
| 　`options.timeBudgetMs` | number | 否 | 抓树时间预算（毫秒），默认 `3000` | `3000` |
| 　`options.visibleOnly` | boolean | 否 | 是否优先只读可见元素，建议 `true` | `true` |
| 　`options.searchMode` | string | 否 | 查找模式，支持 `fast` / `slow`，默认 `fast` | `"fast"` |

### 响应字段

## `POST /element/scrollFind`
