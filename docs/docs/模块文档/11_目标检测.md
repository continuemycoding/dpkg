# 11. 目标检测

目标检测模块用于加载 YOLO NCNN 模型，对屏幕或 imageId 做检测，并按 label/classId 查找目标。调试模式会输出标注图和日志到设备本地目录。

简单说：**它像人的眼睛，看屏幕画面，认出「这是什么东西」，并告诉你位置。**

`value.ok`、`value.status`、`value.error` 是 YOLO 检测和查找的业务结果字段，不是 HTTP 层响应格式。HTTP 层失败统一见 [公共规则](../01_公共规则.md)。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`POST /yolo/load`](#post-yolo-load) | 加载 Yolo NCNN 模型 |
| [`POST /yolo/screen`](#post-yolo-screen) | 对当前屏幕或指定 native 区域执行目标检测 |
| [`POST /yolo/image`](#post-yolo-image) | 对 Image HTTP 模块的 imageId 执行目标检测 |
| [`POST /yolo/find`](#post-yolo-find) | 查找第一个目标 |
| [`POST /yolo/findAll`](#post-yolo-findall) | 查找所有目标 |
| [`POST /yolo/exists`](#post-yolo-exists) | 判断是否存在目标 |
| [`POST /yolo/release`](#post-yolo-release) | 释放指定或默认 Yolo 模型 |
| [`POST /yolo/releaseAll`](#post-yolo-releaseall) | 释放当前 Session 的全部 Yolo 模型 |
| [`GET /yolo/labels`](#get-yolo-labels) | 读取类别列表 |
| [`POST /yolo/debug/enable`](#post-yolo-debug-enable) | 开启调试产物输出 |
| [`POST /yolo/debug/disable`](#post-yolo-debug-disable) | 关闭调试产物输出 |
| [`GET /yolo/debug`](#get-yolo-debug) | 读取调试开关状态 |

## 参数位置与标准命名

所有 `POST /yolo/*` 业务参数只接受 JSON Body 根部字段，不接受 Query，也不接受二次嵌套的通用参数或模型配置对象。`GET /yolo/labels` 的 `labelsPath` 只接受 Query。

单次检测参数统一使用以下名称：

| 参数 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `modelId` | string | 模型 ID；不传时使用当前 Session 最近一次成功加载的模型 | `"model_xxx"` |
| `confidence` | number | 本次检测最低置信度，范围 `0` - `1`；不传时使用模型加载值 | `0.25` |
| `nmsThreshold` | number | 本次检测 NMS IoU 阈值，范围 `0` - `1`；不传时使用模型加载值 | `0.45` |
| `enableNMS` | boolean | 本次检测是否启用 NMS；不传时使用模型加载值 | `true` |
| `classAgnosticNMS` | boolean | 本次检测是否跨类别执行 NMS；不传时使用模型加载值 | `false` |
| `maxDetections` | number | 本次推理最多保留的检测框数量，范围 `1` - `10000`；不传时使用模型加载值 | `300` |
| `region` | object | 检测区域 | `{"x":0,"y":0,"width":1170,"height":800}` |

`region` 只接受下面两种完整对象，不能缺少字段、混用两组字段，也不能把坐标直接放在请求根部：

| 写法 | 字段 | 示例 |
| --- | --- | --- |
| 左上角 + 宽高 | `x`、`y`、`width`、`height` | `{"x":0,"y":0,"width":1170,"height":800}` |
| 左上角 + 右下角 | `left`、`top`、`right`、`bottom` | `{"left":0,"top":0,"right":1170,"bottom":800}` |

坐标必须是非负整数；XYWH 的 `width/height` 至少为 `1`。LTRB 通常要求 `right > left` 且 `bottom > top`，`0/0/0/0` 特例表示全屏或全图。

`/yolo/find`、`/yolo/findAll`、`/yolo/exists` 根据检测来源使用参数：传入 `imageId` 时不能传 `allowProtectedContent`；不传 `imageId` 时表示检测屏幕，可以传 `allowProtectedContent`。

## 检测响应结构

`/yolo/screen`、`/yolo/image`、`/yolo/find`、`/yolo/findAll` 返回统一检测结果：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.ok` | boolean | 检测或查找是否成功 |
| `value.status` | number | YOLO 业务状态码 |
| `value.error` | string | 业务错误信息，成功时为空字符串 |
| `value.data` | array | 检测框数组 |
| `value.count` | number | `data` 数组数量 |
| `value.modelId` | string | 实际使用的模型 ID |
| `value.source` | string | 检测来源；屏幕为 `screen`，imageId 为 `ykImage` |
| `value.elapsedMs` | number | 推理耗时，单位毫秒 |
| `value.width` | number | 本次推理输入区域宽度 |
| `value.height` | number | 本次推理输入区域高度 |
| `value.inputWidth` | number | 本次推理输入区域宽度，与 `width` 相同 |
| `value.inputHeight` | number | 本次推理输入区域高度，与 `height` 相同 |
| `value.offsetX` | number | 输入区域相对来源的 X 偏移 |
| `value.offsetY` | number | 输入区域相对来源的 Y 偏移 |
| `value.region` | object | 实际输入区域，含 `x/y/left/top/right/bottom/width/height/fullImage` |
| `value.coordinateSystem` | string | 坐标系，`nativeScreen` 或 `imagePixels` |
| `value.debugImagePath` | string | 调试标注图路径；未开启调试时为空 |
| `value.debugLogPath` | string | 调试日志路径；未开启调试时为空 |

`value.data[]` 包含 `x/y/width/height`、`left/top/right/bottom`、`centerX/centerY`、`classId`、`label` 和 `confidence`。

## `POST /yolo/load`

### 接口说明

加载 Yolo NCNN 模型

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `paramPath` | string | 是 | NCNN param 文件路径 | `"/var/mobile/model.param"` |
| `binPath` | string | 是 | NCNN bin 文件路径 | `"/var/mobile/model.bin"` |
| `labelsPath` | string | 否 | 类别文件路径 | `"/var/mobile/labels.txt"` |
| `modelName` | string | 否 | 模型名称，仅用于日志和排查；默认 `"yolo"` | `"yolo11n-coco"` |
| `inputName` | string | 否 | NCNN 输入节点名，默认 `"in0"` | `"in0"` |
| `outputName` | string | 否 | NCNN 输出节点名，默认 `"out0"` | `"out0"` |
| `numClasses` | number | 否 | 模型类别数量，默认 `80`；传入 `labelsPath` 时应与标签数量一致 | `80` |
| `targetSize` | number | 否 | 模型输入目标尺寸，默认 `640` | `640` |
| `maxStride` | number | 否 | 输入补边对齐 stride，默认 `32` | `32` |
| `confidence` | number | 否 | 模型默认置信度阈值，范围 `0` - `1`，默认 `0.25` | `0.25` |
| `nmsThreshold` | number | 否 | 模型默认 NMS IoU 阈值，范围 `0` - `1`，默认 `0.45` | `0.45` |
| `enableNMS` | boolean | 否 | 模型默认是否启用 NMS，默认 `true` | `true` |
| `classAgnosticNMS` | boolean | 否 | 模型默认是否跨类别执行 NMS，默认 `false` | `false` |
| `maxDetections` | number | 否 | 模型默认最多保留的检测框数量，默认 `300` | `300` |
| `numThreads` | number | 否 | NCNN 推理线程数，默认 `2` | `2` |
| `useLocalPoolAllocator` | boolean | 否 | 是否启用 NCNN 本地池分配器，默认 `false` | `false` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.modelId` | string | 模型 ID |
| `value.defaultModelId` | string | 当前 Session 默认模型 ID，与本次 `modelId` 相同 |
| `value.modelName` | string | 模型名称；未传时为空字符串 |

### 示例

```javascript
const res = await http.post("/yolo/load", {
  "paramPath": "/var/mobile/model.param",
  "binPath": "/var/mobile/model.bin",
  "labelsPath": "/var/mobile/labels.txt",
  "confidence": 0.25,
  "nmsThreshold": 0.45
});
console.log(res.value);
```

## `POST /yolo/debug/enable`

### 接口说明

开启 Yolo 调试产物输出。开启后，检测过程会生成标注图和检测文本，方便排查识别框是否准确。

如果不传 `directoryPath`，默认保存到 `/tmp/yolo`。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `directoryPath` | string | 否 | 调试产物保存目录，必须是设备本地绝对路径；不传默认 `/tmp/yolo` | `"/tmp/yolo"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.enabled` | boolean | 是否已开启调试 |
| `value.directoryPath` | string | 调试产物目录 |

### 示例

```javascript
const res = await http.post("/yolo/debug/enable", {
  directoryPath: "/tmp/yolo"
});
console.log(res.value);
```

也可以不传路径，直接使用默认目录：

```javascript
const res = await http.post("/yolo/debug/enable", {});
console.log(res.value.directoryPath); // /tmp/yolo
```
