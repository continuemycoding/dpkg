<a id="get-system-info"></a>

## `GET /system/info`

### 接口说明

一次返回系统只读概览，适合脚本启动时读取基础状态。

### 请求参数（Query）

无请求参数。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.osVersion` | string | iOS 系统版本号 |
| `value.ykVersion` | string | 脚本引擎版本号 |
| `value.disk` | object | 根目录磁盘信息 |
| `value.disk.unit` | string | 磁盘单位，固定为 `MB` |
| `value.disk.free` | number/null | 根目录剩余空间 |
| `value.disk.total` | number/null | 根目录总空间 |
| `value.memory` | object | 内存信息 |
| `value.memory.unit` | string | 内存单位，固定为 `MB` |
| `value.memory.available` | number/null | 当前可用内存 |
| `value.memory.total` | number | 当前设备总物理内存 |
| `value.memory.usage` | object | 系统内存使用详情 |
| `value.memory.currentProcess` | number/null | 当前进程物理内存 |
| `value.timeZone` | string | 当前系统时区 |
| `value.time` | string | 当前系统时间，格式 `yyyy-MM-dd HH:mm:ss` |
| `value.settings.assistiveTouch` | boolean | 辅助触控是否开启 |
| `value.settings.reduceMotion` | boolean | 减弱动态效果是否开启 |
| `value.settings.locationServices` | boolean | 定位服务是否开启 |

### 示例

```javascript
const res = await http.get("/system/info");
console.log(res.value.osVersion);
console.log(res.value.time);
```

<a id="post-system-shell"></a>

## `POST /system/shell`

### 接口说明

启动一个独立的 Shell 执行命令。每次请求都会创建新进程，不保留上一次请求的工作目录、环境变量、Shell 变量或函数。需要连续终端上下文时，应使用下面的持久 Shell 接口。

同步执行会合并捕获 `stdout` 和 `stderr`，不删除首尾空白或换行。`output` 中的换行来自命令本身，接口不会额外添加。对于 `/bin/sh` 因管道输入产生的“可执行路径 + 累计行号”诊断前缀，接口会移除该实现细节，只保留真实错误内容，例如 `node2: not found\n`。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `command` | string | 是 | 要执行的 Shell 命令 | `"ls /var/mobile"` |
| `wait` | boolean | 否 | 是否等待命令执行结束，默认 `false` | `true` |
| `timeoutMs` | number | 否 | 等待超时，单位毫秒；只在 `wait=true` 时有意义，最大 `600000` | `3000` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.pid` | number/null | 子进程 PID |
| `value.exitCode` | number/null | 退出码；异步启动尚未结束时为 `null` |
| `value.output` | string | 原始合并输出的文本表示；异步启动时为空字符串 |
| `value.timedOut` | boolean | 是否因 `timeoutMs` 超时而终止 |
| `value.completed` | boolean | 是否已等待到命令结束 |
| `value.durationMs` | number | 本次接口内部执行耗时，单位毫秒 |

### 示例

```javascript
const output = await http.post("/system/shell", {
  command: "printf 'out\\n'; printf 'err\\n' >&2; exit 7",
  wait: true,
  timeoutMs: 3000
});
console.log(output.value.output);   // 保留原始换行
console.log(output.value.exitCode); // 7
```

<a id="post-system-shell-session"></a>

## `POST /system/shell/session`

### 接口说明

为当前 `X-YK-Session-Id` 创建一个长驻 `/bin/sh` 进程。重复调用不会创建第二个进程，而是返回当前持久 Shell 的状态。

持久 Shell 与 HTTP Session 一一绑定。删除、过期或批量清空 HTTP Session 时，引擎会自动关闭对应 Shell 和它的进程组。

### 请求参数（JSON Body）

无请求参数。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.active` | boolean | 持久 Shell 是否正在运行 |
| `value.pid` | number/null | Shell 进程 PID |
| `value.createdAt` | number/null | 创建时间，Unix 秒时间戳 |

### 示例

```javascript
const shell = await http.post("/system/shell/session", {});
console.log(shell.value.pid);
```

<a id="post-system-shell-session-execute"></a>

## `POST /system/shell/session/execute`

### 接口说明

在当前持久 Shell 中执行一条完整命令并等待命令结束。同一 HTTP Session 内的多次调用使用同一个真实 Shell 进程，因此会保留：

- `cd` 修改后的工作目录
- `export` 设置的环境变量
- 未导出的 Shell 变量
- Shell 函数和 Shell 选项

输出规则与一次性同步执行相同：`stdout`、`stderr` 按实际写入顺序合并，不裁剪空白，不额外添加换行。Shell 错误会移除内部可执行路径和累计行号前缀，只保留真实错误内容。

该接口不是 PTY，不适用于 `vim`、`top`、`passwd` 等需要持续交互或终端控制序列的程序。每次请求应提交语法完整的命令。若执行超时，引擎会终止整个持久 Shell 进程组并返回 `active=false`，后续使用前需要重新创建。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `command` | string | 是 | 要执行的完整 Shell 命令 | `"cd /var/mobile"` |
| `timeoutMs` | number | 否 | 等待超时，单位毫秒；不传表示不限制，最大 `600000` | `3000` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.pid` | number/null | 持久 Shell 的 PID |
| `value.exitCode` | number/null | 本条命令的退出码；Shell 提前退出时为 `null` |
| `value.output` | string | 原始合并输出的文本表示 |
| `value.timedOut` | boolean | 是否执行超时 |
| `value.active` | boolean | 命令结束后持久 Shell 是否仍可继续使用 |
| `value.durationMs` | number | 本条命令执行耗时，单位毫秒 |
| `value.error` | string | 仅在 Shell 提前退出时出现 |

### 连续执行示例

```javascript
await http.post("/system/shell/session", {});

await http.post("/system/shell/session/execute", {
  command: "cd /var/mobile && export DEMO_TOKEN=yk"
});

const pwd = await http.post("/system/shell/session/execute", {
  command: "pwd"
});
console.log(pwd.value.output);

const env = await http.post("/system/shell/session/execute", {
  command: "printf '%s' \"$DEMO_TOKEN\""
});
console.log(env.value.output); // yk
```

## `DELETE /system/shell/session`

### 接口说明

关闭当前 `X-YK-Session-Id` 对应的持久 Shell 及其进程组。重复关闭是安全的。

### 请求参数

无请求参数。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.closed` | boolean | 本次是否找到了可关闭的持久 Shell |
| `value.pid` | number/null | 被关闭的 Shell PID |
| `value.active` | boolean | 固定为 `false` |

### 示例

```javascript
const closed = await http.delete("/system/shell/session");
console.log(closed.value.closed);
```
