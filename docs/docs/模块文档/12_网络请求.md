# 12. 网络请求

网络请求模块用于在脚本中发起 HTTP/HTTPS 请求，也支持下载、上传、Cookie、代理，以及 FTP/FTPS/SFTP 文件传输。

同一个 SessionID 下支持并发请求。批量下载、批量检查接口、并行上传时，建议在脚本侧控制并发数量，避免把目标服务器或手机网络打满。

`value.ok` 和 `value.error` 描述的是被代理的远端网络请求或传输任务结果，不是 YK HTTP 层响应格式。YK HTTP 层失败统一见 [公共规则](../01_公共规则.md)。

## 通用响应结构

普通请求类接口通常返回下面这些字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.ok` | boolean | 远端响应是否成功 |
| `value.statusCode` | number | 远端响应状态码 |
| `value.error` | string | 网络层错误信息，成功时为空 |
| `value.elapsedMs` | number | 本次请求耗时 |
| `value.headers` | object | 响应头，单值形式 |
| `value.headersMulti` | object | 响应头，多值形式 |
| `value.bodySize` | number | 响应体字节数 |
| `value.bodyEncoding` | string | `utf8` 或 `base64` |
| `value.body` | string | UTF-8 响应体 |
| `value.bodyBase64` | string | 非 UTF-8 响应体的 Base64 数据 |

## 通用请求参数

以下参数可用于 `/network/get`、`/network/postJSON`、`/network/postForm`、`/network/request`、`/network/download`、`/network/upload` 的大部分场景。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `headers` | object | 请求头 |
| `timeout` | number | 总超时，单位秒 |
| `connectTimeout` | number | 连接超时，单位秒 |
| `verifySsl` | boolean | 是否校验证书，默认跟随模块配置 |
| `followRedirects` | boolean | 是否跟随重定向 |
| `maxRedirects` | number | 最大重定向次数 |
| `retryCount` | number | 失败重试次数，范围 `0-10` |
| `maxBodySize` | number | 最大响应体字节数 |
| `useCookieJar` | boolean | 是否使用 CookieJar |
| `cookie` | string | 直接传入 Cookie 请求头 |
| `basicAuth` | object | HTTP BasicAuth，例如 `{"username":"u","password":"p"}` |
| `proxy` | object|string|boolean | 请求级代理；传 `false` 或 `"direct"` 表示直连 |

<a id="post-network-get"></a>

## `POST /network/get`

### 接口说明

发起 GET 请求并返回响应。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `url` | string | 是 | 请求 URL | `"https://example.com/api"` |
| `params` | object|string | 否 | URL query 参数 | `{"page":1}` |
| `headers` | object | 否 | 请求头 | `{"Accept":"application/json"}` |
| `timeout` | number | 否 | 超时秒数 | `15` |

### 响应字段

参考[通用响应结构](#通用响应结构)。

### 调用示例

```javascript
const res = await http.post("/network/get", {
  url: "https://example.com/api",
  params: { page: 1 },
  timeout: 15
});

if (res.value.ok) {
  console.log(res.value.body);
}
```

<a id="post-network-request"></a>

## `POST /network/request`

### 接口说明

通用请求接口，适合自定义 method、query、body、代理、认证、重定向和重试。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `url` | string | 是 | 请求 URL | `"https://example.com/api"` |
| `method` | string | 否 | 请求方法，默认 `GET` | `"PUT"` |
| `params` | object|string | 否 | URL query 参数 | `{"q":"test"}` |
| `json` | object|array | 否 | JSON 请求体 | `{"a":1}` |
| `form` | object|string | 否 | 表单请求体 | `{"a":1}` |
| `body` | string | 否 | 原始字符串请求体 | `"hello"` |
| `bodyBase64` | string | 否 | Base64 原始请求体 | `"aGVsbG8="` |
| `data` | string|object|array | 否 | 自动请求体。字符串按 raw，对象/数组默认按 JSON。 | `{"a":1}` |
| `bodyKind` | string | 否 | 配合 `data` 使用：`raw`、`json`、`form`、`none` | `"json"` |
| `basicAuth` | object | 否 | BasicAuth | `{"username":"u","password":"p"}` |
| `proxy` | object|string|boolean | 否 | 请求级代理 | `{"type":"http","host":"127.0.0.1","port":8888}` |

注意：`json`、`form`、`body`、`bodyBase64`、`data` 同一次请求只能传一个。

### 响应字段

参考[通用响应结构](#通用响应结构)。

### 调用示例

```javascript
const res = await http.post("/network/request", {
  url: "https://example.com/api",
  method: "POST",
  json: { hello: "world" },
  headers: { "Accept": "application/json" },
  timeout: 15
});

console.log(res.value.body);
```

<a id="post-network-download"></a>

## `POST /network/download`

### 接口说明

下载 HTTP/HTTPS/FTP/FTPS/SFTP 资源到手机本地路径。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `url` | string | 是 | 下载 URL | `"https://example.com/a.zip"` |
| `savePath` | string | 是 | 保存到手机本地路径 | `"/tmp/a.zip"` |
| `resume` | boolean | 否 | 是否断点续传 | `true` |
| `proxy` | object|string|boolean | 否 | 请求级代理 | `{"type":"http","host":"127.0.0.1","port":8888}` |
| `ftp` | object | 否 | FTP/FTPS/SFTP 认证配置 | `{"username":"demo","password":"123456"}` |
| `timeout` | number | 否 | 超时秒数 | `30` |

### FTP 配置字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `username` | string | 用户名 |
| `password` | string | 密码 |
| `useEPSV` | boolean | 是否使用 EPSV |
| `createMissingDirs` | boolean | 上传时是否自动创建目录 |
| `skipPeerVerify` | boolean | FTPS 是否跳过证书校验 |
| `sshPublicKeyPath` | string | SFTP 公钥路径 |
| `sshPrivateKeyPath` | string | SFTP 私钥路径 |
| `sshKeyPassphrase` | string | SFTP 私钥口令 |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.ok` | boolean | 是否成功 |
| `value.statusCode` | number | 远端状态码 |
| `value.savePath` | string | 保存路径 |
| `value.resourceSize` | number | 资源总大小，未知时可能为 `-1` |
| `value.startPos` | number | 本次下载起始位置 |
| `value.sizeDownload` | number | 本次下载字节数 |
| `value.speedDownload` | number | 下载速度 |

### 调用示例

```javascript
const res = await http.post("/network/download", {
  url: "https://example.com/a.zip",
  savePath: "/tmp/a.zip",
  timeout: 30
});

console.log(res.value.ok, res.value.savePath);
```

<a id="post-network-upload"></a>

## `POST /network/upload`

### 接口说明

上传手机本地文件。HTTP/HTTPS 使用 multipart；FTP/FTPS/SFTP 上传单个文件。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `url` | string | 是 | 上传 URL | `"https://example.com/upload"` |
| `filePath` | string | 否 | 单文件路径 | `"/tmp/a.txt"` |
| `field` | string | 否 | multipart 字段名，默认 `file` | `"file"` |
| `mime` | string | 否 | 文件 MIME，默认 `application/octet-stream` | `"text/plain"` |
| `files` | array | 否 | 多文件 multipart 上传 | `[{"path":"/tmp/a.txt","field":"file"}]` |
| `fields` | object | 否 | multipart 普通字段 | `{"source":"script"}` |
| `ftp` | object | 否 | FTP/FTPS/SFTP 认证配置 | `{"username":"demo","password":"123456"}` |
| `proxy` | object|string|boolean | 否 | 请求级代理 | `{"type":"http","host":"127.0.0.1","port":8888}` |
| `timeout` | number | 否 | 超时秒数 | `30` |

`filePath` 和 `files` 至少传一个。FTP/FTPS/SFTP 上传只使用 `filePath`。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.ok` | boolean | 是否成功 |
| `value.statusCode` | number | 远端状态码 |
| `value.resourceSize` | number | 本地文件大小 |
| `value.sizeUpload` | number | 上传字节数 |
| `value.speedUpload` | number | 上传速度 |
| `value.body` | string | 远端响应体 |

### 调用示例

```javascript
const res = await http.post("/network/upload", {
  url: "https://example.com/upload",
  filePath: "/tmp/a.txt",
  field: "file",
  fields: {
    source: "script"
  },
  timeout: 30
});

console.log(res.value.ok, res.value.sizeUpload);
```

## 常见错误

| 情况 | 说明 |
| --- | --- |
| `url` 为空 | 请求、上传、下载必须提供 URL |
| `json/form/body/bodyBase64/data` 同时传多个 | 通用请求体字段互斥，只能选择一种 |
| `savePath` 为空 | 下载必须指定手机本地保存路径 |
| `filePath/files` 都没传 | 上传必须指定本地文件 |
| 代理配置不完整 | 代理至少需要 `type`、`host`、`port` |
| FTP/FTPS/SFTP 认证失败 | 请检查 `ftp.username`、`ftp.password`、证书或 SSH key 配置 |
