# 16. 动态 UI

动态 UI 用于在设备上实时显示提示、创建窗口、组合控件、更新界面和读取用户交互。调用方只需要提供 JSON，DynamicUI 负责渲染和上报事件。

DynamicUI 只处理界面。例如按钮被点击后，DynamicUI 会上报“哪个按钮、什么事件、什么动作”，后续处理由调用方决定。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`POST /ui/toast`](#post-ui-toast) | 显示一条全局临时提示 |
| [`POST /ui/review/show`](#post-ui-review-show) | 按编号打开内置控件验收页 |
| [`POST /ui/dynamic`](#post-ui-dynamic) | 创建组合页面或发送窗口指令 |
| [`POST /ui/events/read`](#post-ui-events-read) | 读取指定窗口的交互事件 |
| `POST /ui/control/*` | 显示或更新单个通用控件 |
| `POST /ui/{控件slug}/*` | 显示、更新或读取指定控件 |
| `POST /ui/window/close` | 关闭指定动态 UI 窗口 |

## `POST /ui/toast`

### 接口说明

在设备上显示一条短暂的文本提示。Toast 不接收点击，也不会创建可持续操作的窗口。

适合的场景包括：“保存成功”、“开始执行”、“操作失败”和“已复制”。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `message` | string | 是 | 要显示的文本，不能为空 | `"操作成功"` |
| `durationMs` | number | 否 | 显示时长，单位毫秒，范围 `0..60000`；`0` 或不传使用默认时长 | `1200` |
| `x` | number | 否 | 自定义位置的 x 坐标，必须和 `y` 一起传 | `180` |
| `y` | number | 否 | 自定义位置的 y 坐标，必须和 `x` 一起传 | `600` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 显示成功时为 `true` |

### 最小示例

```javascript
const res = await http.post("/ui/toast", {
  message: "操作成功"
});

console.log(res.value); // true
```

### 自定义时长

```javascript
await http.post("/ui/toast", {
  message: "3 秒后消失",
  durationMs: 3000
});
```

### 自定义位置

```javascript
await http.post("/ui/toast", {
  message: "指定位置的提示",
  durationMs: 1200,
  x: 180,
  y: 600
});
```

注意：只传 `x` 或只传 `y` 会返回参数错误。不需要自定义位置时，两个参数都不要传。

## 初学者先记住这三个概念

| 概念 | 通俗解释 | 示例 |
| --- | --- | --- |
| `presentationId` | 窗口的名字。显示、更新、读事件和关闭时都使用同一个值 | `"demo.button.window"` |
| `id` | 窗口内某个控件的名字。一个窗口内不能重复 | `"demo.button"` |
| `type` | 控件的类型。使用专用 `/show` 接口时不需要自己传 | `"button"` |

例如，调用 `/ui/button/show` 时，接口已经知道要显示 `button`，小白用户只需要填窗口 ID、控件 ID 和按钮文字。

### 单控件成功响应

本章后面 28 个控件的专用 `/show` 接口都使用相同响应结构：

```json
{
  "value": {
    "ok": true,
    "presentationId": "demo.button.window",
    "id": "demo.button",
    "type": "button",
    "eventsEndpoint": "/ui/button/events"
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `value.ok` | 是否显示成功 |
| `value.presentationId` | 实际使用的窗口 ID |
| `value.id` | 控件 ID |
| `value.type` | DynamicUI 内部控件类型 |
| `value.eventsEndpoint` | 该控件的事件读取接口 |

## `POST /ui/review/show`

### 接口说明

按编号或 `slug` 打开系统内置的控件验收页。如果你还不知道某个控件长什么样，先调这个接口最直观。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `index` | number | 否 | 控件编号，范围 `1..28`；不传时默认为 `1` | `3` |
| `number` | number | 否 | `index` 的别名，同样表示控件编号 | `3` |
| `slug` | string | 否 | 控件的专用路径名；传入后优先使用 | `"button"` |
| `presentationId` | string | 否 | 自定义验收窗口 ID | `"review.button"` |

### 按编号打开按钮验收页

```javascript
const res = await http.post("/ui/review/show", {
  index: 3
});

console.log(res.value.title);    // 按钮
console.log(res.value.nextIndex); // 4
```

### 按 `slug` 打开滑杆验收页

```javascript
await http.post("/ui/review/show", {
  slug: "slider"
});
```

## 专用控件的共同规则

### `/show` 必填字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `presentationId` | string | 窗口 ID，必须是非空字符串 |
| `id` | string | 控件 ID，必须是非空字符串 |

### 常用外观字段

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `stylePack` | 内置外观包 | `"曜石蓝"` |
| `backgroundColor` | 背景颜色 | `"#FFFFFF"` |
| `textColor` | 文字颜色 | `"#111827"` |
| `tintColor` | 控件主色 | `"#0A84FF"` |
| `cornerRadius` | 圆角半径 | `12` |
| `borderWidth` | 边框宽度 | `1` |
| `borderColor` | 边框颜色 | `"#D6E6F7"` |
| `minHeight` | 最小高度 | `44` |
| `preferredSize` | 建议窗口尺寸 | `{ width: 360, height: 240 }` |

### 通用后续操作

下面的路径中，将 `{slug}` 替换为 `button`、`slider` 等实际名称：

| 接口 | 用途 |
| --- | --- |
| `POST /ui/{slug}/attributes` | 更新控件外观或其他属性 |
| `POST /ui/{slug}/enabled` | 启用或禁用控件 |
| `POST /ui/{slug}/visible` | 显示或隐藏控件 |
| `POST /ui/{slug}/call` | 调用控件方法 |
| `POST /ui/{slug}/events` | 读取控件事件 |
| `GET /ui/{slug}/docs` | 读取该控件当前的接口说明 |

禁用某个按钮的例子：

```javascript
await http.post("/ui/button/enabled", {
  presentationId: "demo.button.window",
  id: "demo.button",
  enabled: false
});
```

隐藏同一个按钮：

```javascript
await http.post("/ui/button/visible", {
  presentationId: "demo.button.window",
  id: "demo.button",
  visible: false
});
```

不确定某个控件支持哪些入口时，可以直接读取它的当前接口说明：

```javascript
const docs = await http.get("/ui/button/docs");

console.log(docs.value.endpoints);
console.log(docs.value.fields);
```

## 28 个控件示例

下面每个示例都可以单独调用。为了避免不同示例互相覆盖，每个示例使用不同的 `presentationId`。

### 1. `view` 容器

`view` 是最基础的容器，用于把多个子控件放在一起。它自己通常不接收输入。

```javascript
await http.post("/ui/view/show", {
  presentationId: "demo.view.window",
  id: "demo.view",
  stylePack: "曜石蓝",
  preferredSize: { width: 340, height: 220 },
  layout: {
    axis: "vertical",
    spacing: 12,
    padding: { top: 16, left: 16, bottom: 16, right: 16 }
  },
  backgroundColor: "#FFFFFF",
  cornerRadius: 16,
  children: [
    {
      id: "demo.view.title",
      type: "label",
      text: "容器标题",
      style: "form.title"
    },
    {
      id: "demo.view.body",
      type: "label",
      text: "这两行文字都是 view 的子控件。"
    }
  ]
});
```

看到的效果：一个白色圆角容器，内部从上到下显示标题和说明。

替换子控件时使用 `POST /ui/view/children`。

### 2. `label` 文本

`label` 只负责显示文字，适合标题、说明、状态和结果。

```javascript
await http.post("/ui/label/show", {
  presentationId: "demo.label.window",
  id: "demo.label",
  text: "欢迎使用 DynamicUI",
  stylePack: "曜石蓝",
  fontSize: 20,
  fontWeight: "semibold",
  textColor: "#111827",
  textAlignment: "center",
  preferredSize: { width: 340, height: 150 }
});
```

修改文字：

```javascript
await http.post("/ui/label/text", {
  presentationId: "demo.label.window",
  id: "demo.label",
  text: "文字已更新"
});
```

### 3. `button` 按钮

`button` 用于让用户主动触发一个事件。`events.tap` 的值是调用方自定义的动作名。

```javascript
await http.post("/ui/button/show", {
  presentationId: "demo.button.window",
  id: "demo.button",
  text: "开始执行",
  stylePack: "曜石蓝",
  style: "button.primary",
  minHeight: 46,
  cornerRadius: 12,
  events: {
    tap: "demo.run"
  },
  preferredSize: { width: 340, height: 170 }
});
```

用户点击后，事件中会包含 `id: "demo.button"`、`event: "tap"` 和 `action: "demo.run"`。

修改按钮文字使用 `POST /ui/button/text`。

### 4. `textField` 单行输入

`textField` 适合输入关键词、名称、数字或其他单行内容。

```javascript
await http.post("/ui/text-field/show", {
  presentationId: "demo.textField.window",
  id: "demo.textField",
  placeholder: "请输入关键词",
  value: "",
  keyboardType: "text",
  minHeight: 44,
  borderWidth: 1,
  borderColor: "#D6E6F7",
  cornerRadius: 10,
  events: {
    input: "demo.keyword.input",
    editingDidEnd: "demo.keyword.done"
  },
  preferredSize: { width: 340, height: 180 }
});
```

`input` 会在内容变化时触发；`editingDidEnd` 会在输入结束时触发。

修改输入内容使用 `POST /ui/text-field/text`。

### 5. `textView` 多行输入

`textView` 适合备注、长文本和多行内容。记得给它一个足够的高度。

```javascript
await http.post("/ui/text-view/show", {
  presentationId: "demo.textView.window",
  id: "demo.textView",
  placeholder: "请输入备注",
  value: "第一行\n第二行",
  size: { height: 130 },
  borderWidth: 1,
  borderColor: "#D6E6F7",
  cornerRadius: 10,
  events: {
    input: "demo.note.input",
    editingDidEnd: "demo.note.done"
  },
  preferredSize: { width: 340, height: 240 }
});
```

修改内容使用 `POST /ui/text-view/text`。

### 6. `imageView` 图片

`imageView` 用于显示项目图片、Base64 图片或网络图片。`contentMode: "fit"` 会保持图片比例并尽量完整显示。

```javascript
await http.post("/ui/image/show", {
  presentationId: "demo.image.window",
  id: "demo.image",
  imageUrl: "https://remotepro.cn/favicon.ico",
  contentMode: "fit",
  size: { width: 120, height: 120 },
  backgroundColor: "#F4F9FF",
  cornerRadius: 16,
  preferredSize: { width: 340, height: 240 }
});
```

网络图片需要使用完整的 `http://` 或 `https://` 地址。

### 7. `switch` 开关

`switch` 只有开和关两种状态，`value` 使用布尔值。

```javascript
await http.post("/ui/switch/show", {
  presentationId: "demo.switch.window",
  id: "demo.switch",
  value: true,
  onTintColor: "#20C4A8",
  events: {
    valueChanged: "demo.enabled.changed"
  },
  preferredSize: { width: 340, height: 160 }
});
```

修改开关状态：

```javascript
await http.post("/ui/switch/value", {
  presentationId: "demo.switch.window",
  id: "demo.switch",
  value: false
});
```

### 8. `slider` 滑杆

`slider` 适合在一个连续范围内选值，例如音量、速度或强度。

```javascript
await http.post("/ui/slider/show", {
  presentationId: "demo.slider.window",
  id: "demo.slider",
  value: 40,
  minimumValue: 0,
  maximumValue: 100,
  tintColor: "#0A84FF",
  thumbTintColor: "#FFFFFF",
  events: {
    valueChanged: "demo.volume.changed"
  },
  preferredSize: { width: 340, height: 170 }
});
```

将滑杆设为 `75`：

```javascript
await http.post("/ui/slider/value", {
  presentationId: "demo.slider.window",
  id: "demo.slider",
  value: 75
});
```

### 9. `stepper` 步进器

`stepper` 通过加号和减号按固定步长改变数值，适合数量、次数和重试数。

```javascript
await http.post("/ui/stepper/show", {
  presentationId: "demo.stepper.window",
  id: "demo.stepper",
  value: 2,
  minimumValue: 0,
  maximumValue: 10,
  stepValue: 1,
  events: {
    valueChanged: "demo.count.changed"
  },
  preferredSize: { width: 340, height: 170 }
});
```

`value` 必须位于最小值和最大值之间。

### 10. `segmentedControl` 分段选择

`segmentedControl` 适合少量互斥选项。`value` 是从 `0` 开始的选中下标。

```javascript
await http.post("/ui/segmented-control/show", {
  presentationId: "demo.segment.window",
  id: "demo.segment",
  items: ["全部", "进行中", "已完成"],
  value: 0,
  selectedTintColor: "#0A84FF",
  events: {
    valueChanged: "demo.segment.changed"
  },
  preferredSize: { width: 340, height: 180 }
});
```

选中第二项：

```javascript
await http.post("/ui/segmented-control/value", {
  presentationId: "demo.segment.window",
  id: "demo.segment",
  value: 1
});
```

### 11. `progressView` 进度条

`progressView` 用于展示进度，`value` 的范围是 `0..1`。`0.65` 表示 65%。

```javascript
await http.post("/ui/progress/show", {
  presentationId: "demo.progress.window",
  id: "demo.progress",
  value: 0.65,
  progressTintColor: "#0A84FF",
  trackTintColor: "#E4E7EC",
  attributes: {
    showsProgressLabel: true,
    progressLabelFormat: "{percent}%"
  },
  preferredSize: { width: 340, height: 170 }
});
```

将进度更新为 90%：

```javascript
await http.post("/ui/progress/value", {
  presentationId: "demo.progress.window",
  id: "demo.progress",
  value: 0.9
});
```

### 12. `activityIndicatorView` 加载指示器

`activityIndicatorView` 表示“正在处理，但暂时不知道具体进度”。

```javascript
await http.post("/ui/activity-indicator/show", {
  presentationId: "demo.loading.window",
  id: "demo.loading",
  animating: true,
  tintColor: "#0A84FF",
  size: { width: 48, height: 48 },
  preferredSize: { width: 300, height: 160 }
});
```

`animating: true` 表示开始转动。处理完成后可以隐藏该控件：

```javascript
await http.post("/ui/activity-indicator/visible", {
  presentationId: "demo.loading.window",
  id: "demo.loading",
  visible: false
});
```

### 13. `datePicker` 日期选择

`datePicker` 用于选择日期、时间或倒计时。`mode` 支持 `date`、`time`、`dateAndTime` 和 `countDown`。

```javascript
await http.post("/ui/date-picker/show", {
  presentationId: "demo.date.window",
  id: "demo.date",
  mode: "dateAndTime",
  events: {
    valueChanged: "demo.date.changed"
  },
  preferredSize: { width: 360, height: 300 }
});
```

用户改变日期后，从事件的 `value` 读取当前值。

### 14. `pickerView` 滚轮选择

`pickerView` 适合在一列选项中上下滚动选择。

```javascript
await http.post("/ui/picker/show", {
  presentationId: "demo.picker.window",
  id: "demo.picker",
  items: ["低", "中", "高"],
  value: "中",
  events: {
    select: "demo.quality.changed"
  },
  preferredSize: { width: 340, height: 260 }
});
```

替换所有选项使用 `POST /ui/picker/items`；更换当前选中值使用 `POST /ui/picker/value`。

### 15. `pageControl` 分页圆点

`pageControl` 用圆点表示“总共有几页、当前是第几页”。`value` 是从 `0` 开始的页码。

```javascript
await http.post("/ui/page-control/show", {
  presentationId: "demo.page.window",
  id: "demo.page",
  numberOfPages: 4,
  value: 1,
  currentPageIndicatorTintColor: "#0A84FF",
  pageIndicatorTintColor: "#D1D5DB",
  events: {
    valueChanged: "demo.page.changed"
  },
  preferredSize: { width: 320, height: 150 }
});
```

这个示例表示共 4 页，当前是第 2 页。

### 16. `scrollView` 滚动容器

`scrollView` 在内容超过窗口高度时允许用户上下滚动。

```javascript
await http.post("/ui/scroll-view/show", {
  presentationId: "demo.scroll.window",
  id: "demo.scroll",
  preferredSize: { width: 340, height: 300 },
  layout: {
    axis: "vertical",
    spacing: 12,
    padding: { top: 16, left: 16, bottom: 16, right: 16 }
  },
  showsVerticalScrollIndicator: true,
  children: [
    { id: "demo.scroll.1", type: "label", text: "第 1 行" },
    { id: "demo.scroll.2", type: "label", text: "第 2 行" },
    { id: "demo.scroll.3", type: "label", text: "第 3 行" },
    { id: "demo.scroll.4", type: "label", text: "第 4 行" },
    { id: "demo.scroll.5", type: "label", text: "第 5 行" },
    { id: "demo.scroll.6", type: "label", text: "第 6 行" },
    { id: "demo.scroll.7", type: "label", text: "第 7 行" },
    { id: "demo.scroll.8", type: "label", text: "第 8 行" }
  ]
});
```

如果要做按页滚动，可以使用 `pagingEnabled: true` 并监听 `pageChanged`。

### 17. `stackView` 线性布局

`stackView` 会按水平或垂直方向自动排列子控件。

```javascript
await http.post("/ui/stack-view/show", {
  presentationId: "demo.stack.window",
  id: "demo.stack",
  preferredSize: { width: 340, height: 180 },
  layout: {
    axis: "horizontal",
    spacing: 10,
    alignment: "center",
    distribution: "fillEqually"
  },
  children: [
    {
      id: "demo.stack.cancel",
      type: "button",
      text: "取消",
      events: { tap: "demo.cancel" }
    },
    {
      id: "demo.stack.confirm",
      type: "button",
      text: "确定",
      style: "button.primary",
      events: { tap: "demo.confirm" }
    }
  ]
});
```

`axis: "horizontal"` 表示横向排列；改为 `vertical` 就会从上到下排列。

### 18. `tableView` 列表

`tableView` 适合显示纵向列表。用户点击某行时，事件会带上行下标和该行数据。

```javascript
await http.post("/ui/table/show", {
  presentationId: "demo.table.window",
  id: "demo.table",
  items: ["任务 A", "任务 B", "任务 C", "任务 D"],
```

## `POST /ui/events/read`

### 接口说明

读取指定动态 UI 窗口中的用户交互。按钮点击、输入变化、开关切换和列表选择都会产生事件。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 默认值 |
| --- | --- | --- | --- | --- |
| `presentationId` | string | 是 | 要读取的窗口 ID | 无 |
| `afterSequence` | number | 否 | 只返回序号大于该值的事件 | `0` |
| `clear` | boolean | 否 | 返回后是否删除已读事件 | `false` |

### 最小示例

先显示一个按钮：

```javascript
await http.post("/ui/button/show", {
  presentationId: "demo.events.window",
  id: "demo.events.button",
  text: "点击我",
  events: {
    tap: "demo.button.clicked"
  }
});
```

用户点击后读取事件：

```javascript
const res = await http.post("/ui/events/read", {
  presentationId: "demo.events.window",
  afterSequence: 0,
  clear: false
});

console.log(res.value.events);
```

### 事件字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `sequence` | number | 窗口运行时产生的递增序号 |
| `eventId` | string | 事件唯一 ID |
| `presentationId` | string | 产生事件的窗口 ID |
| `id` | string | 产生事件的控件 ID |
| `event` | string | 交互名，例如 `tap` 或 `valueChanged` |
| `action` | string | 控件 `events` 中声明的动作名 |
| `value` | any | 交互后的控件值 |
| `parameters` | object | 附加信息，列表事件会包含下标和数据项 |
| `timestamp` | number | 事件时间戳 |

### 常用交互名

| 交互名 | 常见控件 | 触发时机 |
| --- | --- | --- |
| `tap` | `button`、`tableView`、`collectionView`、`select` | 用户点击 |
| `input` | `textField`、`textView`、`searchBar` | 输入内容正在变化 |
| `editingDidEnd` | 输入控件 | 用户结束输入 |
| `valueChanged` | `switch`、`slider`、`stepper`、`pageControl` | 控件值变化 |
| `select` | `pickerView` | 用户选中新选项 |
| `pageChanged` | 分页 `scrollView` | 当前页变化 |

### 避免重复读取

每次读取后保存 `nextSequence`，下次传给 `afterSequence`：

```javascript
const nextSequence = 0;
const res = await http.post("/ui/events/read", {
  presentationId: "demo.events.window",
  afterSequence: nextSequence,
  clear: false
});

console.log(res.value.nextSequence);
console.log(res.value.events);
```

## `POST /ui/dynamic`

### 接口说明

`/ui/dynamic` 是组合页面和窗口指令的通用入口。如果一个页面需要多个控件，使用 `action: "show"` 并在 `document.children` 中按顺序写入子控件。

### 常用 `action`

`action` 严格区分大小写。

| `action` | 用途 | 必要字段 |
| --- | --- | --- |
| `show` | 显示或重建窗口 | `document` |
| `set` | 更新控件文本、值或属性 | `presentationId`、`id` |
| `update` | 更新控件属性 | `presentationId`、`id`、`attributes` |
| `get` | 读取控件当前描述 | `presentationId`、`id` |
| `call` | 调用控件方法 | `presentationId`、`id`、`method` |
| `push` | 打开二级页面 | `presentationId`、`document` |
| `pop` | 返回上一页 | `presentationId` |
| `status` | 读取全部窗口状态 | 无 |
| `metrics` | 读取渲染指标和视图树 | `presentationId` |
| `catalog` | 读取当前控件能力目录 | 无 |
| `close` | 关闭指定窗口 | `presentationId` |
| `closeAll` | 关闭全部动态 UI 窗口 | 无 |

### 示例：显示一个完整面板

```javascript
const res = await http.post("/ui/dynamic", {
  action: "show",
  presentationId: "demo.dashboard.window",
  documentName: "dashboard",
  title: "任务面板",
  style: "center",
  preferredSize: { width: 360, height: 540 },
  document: {
    id: "dashboard.root",
    type: "scrollView",
    stylePack: "曜石蓝",
    layout: {
      axis: "vertical",
      spacing: 14,
      padding: { top: 18, left: 18, bottom: 18, right: 18 }
    },
    children: [
      {
        id: "dashboard.title",
        type: "label",
        text: "DynamicUI 任务面板",
        style: "form.title"
      },
      {
        id: "dashboard.status",
        type: "label",
        text: "等待开始",
        attributes: { textColor: "#5B6472" }
      },
      {
        id: "dashboard.keyword",
        type: "textField",
        placeholder: "输入关键词",
        events: {
          input: "dashboard.keyword.input",
          editingDidEnd: "dashboard.keyword.done"
        }
      },
      {
        id: "dashboard.level",
        type: "slider",
        value: 35,
        minimumValue: 0,
        maximumValue: 100,
        events: { valueChanged: "dashboard.level.changed" }
      },
      {
        id: "dashboard.progress",
        type: "progressView",
        value: 0.35
      },
      {
        id: "dashboard.run",
        type: "button",
        text: "开始",
        style: "button.primary",
        events: { tap: "dashboard.run" }
      }
    ]
  }
});

console.log(res.value.ok);
```

## 常见错误

| 场景 | 原因 | 解决方法 |
| --- | --- | --- |
| 窗口没有显示 | `presentationId` 或 `id` 是空字符串 | 为两个字段填写稳定名称 |
| 专用路径返回类型错误 | 例如调用 `/ui/button/show` 却传了其他 `type` | 专用 `/show` 入口不要自己传 `type` |
| 更新时找不到控件 | 更新使用的 `presentationId` 或 `id` 与显示时不一致 | 复制显示请求中的原值 |
| 读不到按钮事件 | 按钮没有 `events.tap`，或读取了其他窗口 | 检查 `events` 和 `presentationId` |
| 反复读到同一事件 | 每次都传 `afterSequence: 0` | 保存上次响应中的 `nextSequence` |
| 无法返回上一页 | 当前已经是根页面 | 使用 `/ui/window/close` 关闭窗口 |
| Toast 位置参数错误 | 只传了 `x` 或 `y` | 同时传入两个坐标，或都不传 |
| 图片或网页无法加载 | 地址不完整 | 使用包含 `http://` 或 `https://` 的完整地址 |

HTTP 失败使用非 2xx 状态码，错误信息位于 `value.error` 和 `value.message`。

## 验证清单

1. 首先调用 `/ui/toast`，确认设备端能显示提示。
2. 通过 `/ui/review/show` 从 1 到 28 逐个查看内置控件。
3. 每个专用 `/show` 示例都能返回 `value.ok: true`。
4. 每个控件的 `presentationId` 和 `id` 都稳定且非空。
5. 需要交互的控件都能读到正确的 `id`、`event`、`action` 和 `value`。
6. 组合页面的 `show`、`set`、`update`、`push`、`pop` 和 `close` 指令行为一致。
7. 文档和示例不包含开发电脑用户名、本机绝对路径或本机专属地址。
