# 10. 文字识别

文字识别模块用于识别屏幕或图片中的文字，并支持按文字查找、判断是否存在、输出调试标注图和取消当前识别流程。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`POST /ocr/screen`](#post-ocr-screen) | 识别当前屏幕文字 |
| [`POST /ocr/image`](#post-ocr-image) | 识别指定图片文字 |
| [`POST /ocr/find`](#post-ocr-find) | 查找第一个匹配文字 |
| [`POST /ocr/findAll`](#post-ocr-findall) | 查找所有匹配文字 |
| [`POST /ocr/exists`](#post-ocr-exists) | 判断文字是否存在 |
| [`POST /ocr/debug/enable`](#post-ocr-debug-enable) | 开启调试产物输出 |
| [`POST /ocr/debug/disable`](#post-ocr-debug-disable) | 关闭调试产物输出 |
| [`GET /ocr/debug`](#get-ocr-debug) | 读取调试开关状态 |
| [`POST /ocr/cancel`](#post-ocr-cancel) | 取消当前识别流程 |

## 识别引擎

| `engine` | 说明 | 推荐场景 |
| --- | --- | --- |
| `PaddleOCR` | 本地 PaddleOCR 文字识别 | 图文混排、截图图片、希望本地模型拆分更细的文字块 |
| `AppleOCR` | 系统文字识别 | 系统界面、清晰中文/英文、希望识别整句文本 |

不传 `engine` 时默认使用 `PaddleOCR`。只有明确需要系统 Vision OCR 时，再传 `engine: "AppleOCR"`。

## 识别模型

`model` 用于选择指定引擎下的具体模型版本；不传时使用对应引擎默认模型。

| `engine` | `model` | 数值 | 说明 |
| --- | --- | --- | --- |
| `PaddleOCR` | `ppocrv5` | `201` | PP-OCRv5 本地模型，本地 PaddleOCR 默认模型 |
| `AppleOCR` | `apple-vision-revision-1` | `101` | Apple Vision OCR revision 1 |
| `AppleOCR` | `apple-vision-revision-2` | `102` | Apple Vision OCR revision 2 |
| `AppleOCR` | `apple-vision-revision-3` | `103` | Apple Vision OCR revision 3 |

Apple Vision OCR revision 的最低 iOS 版本和能力差异如下：

| `model` | 最低 iOS 版本 | 能力说明 |
| --- | --- | --- |
| `apple-vision-revision-1` | iOS 13 | 第一版系统 OCR，只能识别英文；不支持中文，如果拿它识别中文，会直接识别不到中文。 |
| `apple-vision-revision-2` | iOS 14 | 第二版开始支持中文，默认就能识别中文，不需要额外传 `language`。 |
| `apple-vision-revision-3` | iOS 16 | 第三版是在 v2 基础上的增强版：支持 v2 已有语言并增加更多语言；对旋转文字、手写文字的识别更好；系统还支持自动判断文字语言。默认就能识别中文，不需要额外传 `language`。 |

Apple Vision OCR 的 revision 不会按系统能力自动降级。显式传入当前系统不支持的 `model` 时，接口会直接返回失败，并在 `value.error` 中提示当前设备不支持你设置的版本，以及当前设备仅支持的版本。比如 iOS 15 传 `apple-vision-revision-3` 会失败；iOS 13 传 revision 2 或 3 也会失败。

如果需要识别中文，不要在 iOS 13 等只能使用 revision 1 的系统上使用 `AppleOCR`；revision 1 不支持中文，建议改用 `PaddleOCR`，或升级到支持 revision 2/3 的系统后再使用 `AppleOCR`。不传 `model` 时仍会使用当前系统支持的默认 Apple Vision revision。

## 通用识别参数

下列参数可用于 `/ocr/screen`、`/ocr/image`、`/ocr/find`、`/ocr/findAll`、`/ocr/exists`。
所有 OCR 业务参数只接受 JSON Body 根部字段，不接受 Query，也不接受二次嵌套的通用参数对象。

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `engine` | string | 否 | 识别引擎，支持 `PaddleOCR`、`AppleOCR`；不传默认 `PaddleOCR` | `"PaddleOCR"` |
| `model` | string/number | 否 | 识别模型；PaddleOCR 支持 `ppocrv5`，AppleOCR 支持 `apple-vision-revision-1/2/3` | `"ppocrv5"` |
| `confidence` | number | 否 | 最低置信度，范围 `0` - `1`，默认 `0` | `0.3` |
| `language` | string | 否 | 语言提示。一般可不传，默认会识别当前 revision 支持的语言；只有需要明确提示某种语言时再传，例如 `en-US`；Apple revision 1 不支持中文 | `"en-US"` |
| `region` | object | 否 | 只识别指定区域 | `{"x":0,"y":0,"width":1170,"height":800}` |
| `allowProtectedContent` | boolean | 否 | 屏幕来源接口是否允许识别受保护/加密内容。默认 `false`；仅 `/ocr/screen` 以及不传 `imageId` 的 `/ocr/find`、`/ocr/findAll`、`/ocr/exists` 生效。 | `false` |

`region` 支持两种写法：

| 写法 | 字段 | 示例 |
| --- | --- | --- |
| 左上角 + 宽高 | `x`、`y`、`width`、`height` | `{"x":0,"y":0,"width":1170,"height":800}` |
| 左上角 + 右下角 | `left`、`top`、`right`、`bottom` | `{"left":0,"top":0,"right":1170,"bottom":800}` |

`region` 必须完整使用其中一组字段，不能缺少字段、混用两组字段，也不能把坐标直接放在请求根部。

## 文本匹配参数

下列参数用于 `/ocr/find`、`/ocr/findAll`、`/ocr/exists`。

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `text` | string | 是 | 要查找的目标文字 | `"登录"` |
| `match` | string | 否 | 匹配方式，默认 `contains` | `"contains"` |

`match` 支持：

| `match` | 说明 |
| --- | --- |
| `exact` | 完全相等 |
| `contains` | 包含目标文字 |
| `prefix` | 以目标文字开头 |
| `suffix` | 以目标文字结尾 |

`/ocr/find`、`/ocr/findAll`、`/ocr/exists` 的 `orientation` 与 `allowProtectedContent` 按识别来源互斥：传入 `imageId` 时可传 `orientation`、不能传 `allowProtectedContent`；不传 `imageId` 时可传 `allowProtectedContent`、不能传 `orientation`。

## OCR 响应结构

OCR 接口遵循统一 HTTP 响应规范，顶层只有 `value`；下面的 OCR 结果字段都位于 `value` 内。

```json
{
  "value": {
    "ok": true,
    "status": 1,
    "engine": "PaddleOCR",
    "model": "ppocrv5",
    "backend": "ncnn",
    "cached": false,
    "count": 2,
    "recognitionElapsedMilliseconds": 153.3,
    "error": "",
    "data": [
      {
        "label": "OCR",
        "confidence": 0.99,
        "x": 287,
        "y": 100,
        "width": 288,
        "height": 99,
        "centerX": 431,
        "centerY": 150
      }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.ok` | boolean | 本次识别是否成功 |
| `value.status` | number | 识别状态码，`1` 表示成功 |
| `value.engine` | string | 实际使用的识别引擎 |
| `value.model` | string | 实际使用的识别模型 |
| `value.backend` | string | 实际使用的底层后端，例如 `ncnn` 或 `vision` |
| `value.cached` | boolean | 是否命中本轮识别缓存 |
| `value.count` | number | 返回文字块数量 |
| `value.recognitionElapsedMilliseconds` | number | 调试模式下返回，识别耗时，单位毫秒 |
| `value.cacheHitElapsedMilliseconds` | number | 调试模式且命中缓存时返回，缓存返回耗时，单位毫秒 |
| `value.error` | string | 失败说明，成功时通常为空 |
| `value.data` | array | 文字块数组 |
| `value.data[].label` | string | 识别出的文字 |
| `value.data[].confidence` | number | 置信度 |
| `value.data[].x` | number | 左上角 X |
| `value.data[].y` | number | 左上角 Y |
| `value.data[].width` | number | 宽度 |
| `value.data[].height` | number | 高度 |
| `value.data[].centerX` | number | 中心点 X |
| `value.data[].centerY` | number | 中心点 Y |

坐标使用屏幕或图片物理像素。识别屏幕时，`centerX`、`centerY` 可以用于触控点击。

<a id="post-ocr-screen"></a>

## `POST /ocr/screen`

### 接口说明

识别当前屏幕上的文字。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `engine` | string | 否 | 识别引擎，支持 `PaddleOCR`、`AppleOCR`；不传默认 `PaddleOCR` | `"PaddleOCR"` |
| `model` | string/number | 否 | 识别模型；不传时 PaddleOCR 默认 `ppocrv5` | `"ppocrv5"` |
| `confidence` | number | 否 | 最低置信度，范围 `0` - `1` | `0` |
| `language` | string | 否 | 语言提示，详见通用识别参数；Apple revision 1 不支持中文 | `"en-US"` |
| `region` | object | 否 | 只识别屏幕指定区域 | `{"x":0,"y":0,"width":1170,"height":800}` |
| `allowProtectedContent` | boolean | 否 | 是否允许截图并识别受保护/加密内容。默认 `false`。 | `false` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | object | OCR 结果结构 |

### 示例

```javascript
const res = await http.post("/ocr/screen", {
  confidence: 0
});
console.log(res.value.data);
```

允许识别受保护内容：

```javascript
const res = await http.post("/ocr/screen", {
  allowProtectedContent: true
});
```

## `POST /ocr/image`

### 接口说明

识别 Image 模块中指定 `imageId` 的文字。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `imageId` | string | 是 | Image 模块返回的图片 ID | `"A1B2C3"` |
| `engine` | string | 否 | 识别引擎，支持 `PaddleOCR`、`AppleOCR`；不传默认 `PaddleOCR` | `"PaddleOCR"` |
| `model` | string/number | 否 | 识别模型；不传时 PaddleOCR 默认 `ppocrv5` | `"ppocrv5"` |
| `confidence` | number | 否 | 最低置信度，范围 `0` - `1` | `0` |
| `language` | string | 否 | 语言提示，详见通用识别参数；Apple revision 1 不支持中文 | `"en-US"` |
| `orientation` | string | 否 | 文字识别方向，支持 `up`、`down`、`left`、`right`；文字是正的用`up`，文字倒了用`down`，需要旋转90°用`left`和`right` | `"up"` |
| `region` | object | 否 | 只识别图片指定区域 | `{"x":0,"y":0,"width":300,"height":200}` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | object | OCR 结果结构 |

### 示例

```javascript
const img = await http.post("/image/capture", {});
const res = await http.post("/ocr/image", {
  imageId: img.value.imageId,
  confidence: 0
});
console.log(res.value.data);
```

<a id="post-ocr-find"></a>

## `POST /ocr/find`

### 接口说明

查找第一个匹配文字。不传 `imageId` 时识别当前屏幕；传 `imageId` 时识别指定图片。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `text` | string | 是 | 要查找的目标文字 | `"登录"` |
| `imageId` | string | 否 | 指定图片 ID；不传则识别屏幕 | `"A1B2C3"` |
| `match` | string | 否 | 匹配方式，默认 `contains` | `"contains"` |
| `engine` | string | 否 | 识别引擎，支持 `PaddleOCR`、`AppleOCR`；不传默认 `PaddleOCR` | `"PaddleOCR"` |
| `model` | string/number | 否 | 识别模型；不传时 PaddleOCR 默认 `ppocrv5` | `"ppocrv5"` |
| `confidence` | number | 否 | 最低置信度，范围 `0` - `1` | `0` |
| `language` | string | 否 | 语言提示，详见通用识别参数；Apple revision 1 不支持中文 | `"en-US"` |
| `orientation` | string | 否 | 仅传入 `imageId` 时生效，支持 `up`、`down`、`left`、`right` | `"up"` |
| `region` | object | 否 | 只识别指定区域 | `{"x":0,"y":0,"width":1170,"height":800}` |
| `allowProtectedContent` | boolean | 否 | 不传 `imageId` 时，是否允许截图并识别受保护/加密内容。默认 `false`。 | `false` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | object | OCR 结果结构；`data` 最多包含一个文字块 |

### 示例

```javascript
const res = await http.post("/ocr/find", {
  text: "登录",
  match: "contains",
  confidence: 0
});

const item = res.value.data[0];
if (item) {
  await http.post("/touch/tap", { x: item.centerX, y: item.centerY });
}
```

| `model` | string/number | 否 | 识别模型；不传时 PaddleOCR 默认 `ppocrv5` | `"ppocrv5"` |
| `confidence` | number | 否 | 最低置信度，范围 `0` - `1` | `0` |

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.exists` | boolean | 是否存在 |
| `value.item` | object/null | 第一个命中文字块 |

```javascript

```

<a id="post-ocr-debug-enable"></a>

## `POST /ocr/debug/enable`

### 接口说明

开启 OCR 调试产物输出。开启后，识别过程会在指定目录生成标注图和校验文本，方便排查识别框是否准确。

如果不传 `directoryPath`，默认保存到 `/tmp/ocr`。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `directoryPath` | string | 否 | 调试产物保存目录，必须是设备本地绝对路径；不传默认 `/tmp/ocr` | `"/tmp/ocr"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.enabled` | boolean | 是否已开启 |
| `value.directoryPath` | string | 调试产物目录 |

### 示例

```javascript
const res = await http.post("/ocr/debug/enable", {
  directoryPath: "/tmp/ocr"
});
console.log(res.value);
```

也可以不传目录，直接使用默认目录：

```javascript
const res = await http.post("/ocr/debug/enable", {});
console.log(res.value.directoryPath); // /tmp/ocr
```
