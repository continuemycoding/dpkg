# 13. 文件操作

文件模块用于读写设备本地文件、按行编辑 UTF-8 文本、计算文件哈希、创建目录、删除和复制文件。

路径由调用方决定，写入删除必须谨慎。建议脚本优先使用自己的工作目录，删除、覆盖写入、复制目录前先用 `/file/exists` 和 `/file/list` 确认目标路径。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`GET /file/exists`](#get-file-exists) | 判断路径是否存在 |
| [`GET /file/list`](#get-file-list) | 列出目录内容 |
| [`GET /file/size`](#get-file-size) | 读取文件大小 |
| [`GET /file/read`](#get-file-read) | 读取文件内容 |
| [`POST /file/write`](#post-file-write) | 覆盖写入文件 |
| [`POST /file/append`](#post-file-append) | 追加写入文件 |
| [`GET /file/lineCount`](#get-file-linecount) | 统计文本行数 |
| [`GET /file/line`](#get-file-line) | 读取指定行 |
| [`POST /file/line/set`](#post-file-line-set) | 修改指定行 |
| [`POST /file/line/insert`](#post-file-line-insert) | 插入单行 |
| [`POST /file/line/remove`](#post-file-line-remove) | 删除指定行 |

## 通用说明

| 项目 | 说明 |
| --- | --- |
| 路径格式 | `path`、`sourcePath`、`destinationPath` 必须是设备本地绝对路径 |
| 文本编码 | 文本读写使用 `utf8` |
| 二进制写入 | JSON 写入可使用 `base64`；也可用 `application/octet-stream` 原始请求体直接传二进制 |
| 行号规则 | `lineNumber` 从 `1` 开始 |
| 删除操作 | `/file/remove` 会删除文件或目录，请确认路径正确 |

<a id="get-file-exists"></a>

## `GET /file/exists`

### 接口说明

判断路径是否存在，并返回路径类型。

### 请求参数（Query）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `path` | string | 是 | 要检查的路径 | `"/tmp/a.txt"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | string/boolean | 文件返回 `"file"`，目录返回 `"directory"`，不存在返回 `false` |

### 示例

```javascript
const path = encodeURIComponent("/tmp/a.txt");
const res = await http.get(`/file/exists?path=${path}`);
console.log(res.value);
```

## `GET /file/read`

### 接口说明

读取文件内容。文本文件建议使用 `utf8`，图片、压缩包等二进制文件请使用 `base64`。

### 请求参数（Query）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `path` | string | 是 | 文件路径 | `"/tmp/a.txt"` |
| `encoding` | string | 否 | 返回编码，支持 `utf8`、`base64`，默认 `utf8` | `"utf8"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.data` | string | 文件内容 |
| `value.encoding` | string | 本次返回编码 |
| `value.size` | number | 原始文件字节数 |

### 示例

```javascript
const path = encodeURIComponent("/tmp/a.txt");
const res = await http.get(`/file/read?path=${path}&encoding=utf8`);
console.log(res.value.data);
```

<a id="post-file-write"></a>

## `POST /file/write`

### 接口说明

覆盖写入文件。路径不存在时会创建文件；已有内容会被替换。

接口支持两种写入方式：

- JSON Body：适合文本或已经转成 base64 的内容。
- 原始二进制 Body：适合调用端直接持有文件字节、`Buffer`、`ArrayBuffer` 或 `Blob` 的场景，避免 base64 编解码和体积膨胀。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `path` | string | 是 | 文件路径 | `"/tmp/a.txt"` |
| `data` | string | 是 | 写入内容；`encoding=base64` 时传 base64 字符串 | `"hello"` |
| `encoding` | string | 否 | 写入编码，支持 `utf8`、`base64`，默认 `utf8` | `"utf8"` |

### 请求参数（原始二进制 Body）

| 参数 | 位置 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `path` | Query | string | 是 | 文件路径 | `"/tmp/a.bin"` |
| `Content-Type` | Header | string | 是 | 固定传 `application/octet-stream` | `"application/octet-stream"` |
| 请求体 | Body | binary | 是 | 要写入的原始文件字节 | `@./a.bin` |

使用原始二进制 Body 时，不需要传 `data` 和 `encoding`。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 是否写入成功 |

### 示例

```javascript
const res = await http.post("/file/write", {
  path: "/tmp/a.txt",
  data: "hello",
  encoding: "utf8"
});
console.log(res.value);
```

```bash
curl -sS -X POST "$BASE/file/write?path=/tmp/a.bin" \
  -H "X-YK-Session-Id: $SESSION_ID" \
  -H "Content-Type: application/octet-stream" \
  --data-binary "@./a.bin"
```

| `path` | string | 是 | 文件路径 | `"/tmp/a.txt"` |
| `data` | string | 是 | 追加内容；`encoding=base64` 时传 base64 字符串 | `"\nworld"` |
| `encoding` | string | 否 | 写入编码，支持 `utf8`、`base64`，默认 `utf8` | `"utf8"` |

### 响应字段
