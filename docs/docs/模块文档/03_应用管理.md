# 03. 应用管理

应用管理模块用于读取当前前台 App、启动和关闭 App、查看已安装列表、查询路径、PID、内存占用，以及安装、卸载和清理 App 数据。`bundleId` 是 App 的唯一包名（例如设置 `com.apple.Preferences`）。安装、卸载、清理数据属于高风险操作，调用前请确认 `bundleId` 或文件路径是预期目标。

安装、卸载、清理类接口里的 `value.success` 和 `value.message` 是业务结果字段，不是 HTTP 层响应格式。HTTP 层失败统一见 [公共规则](../01_公共规则.md)。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`GET /app/info`](#get-app-info) | 一次返回当前前台 App、PID 和内存概览 |
| [`POST /app/run`](#post-app-run) | 启动指定 App |
| [`POST /app/close`](#post-app-close) | 关闭指定 App 或全部后台 App |
| [`GET /app/list`](#get-app-list) | 获取设备已安装 App 列表 |
| [`POST /app/install`](#post-app-install) | 安装设备本地 IPA 或 DEB 文件 |
| [`POST /app/uninstall`](#post-app-uninstall) | 卸载指定 App 或 DEB 包 |
| [`POST /app/clearSandbox`](#post-app-clearsandbox) | 清理指定 App 的沙盒数据 |
| [`POST /app/clearKeychain`](#post-app-clearkeychain) | 清理指定 App 的钥匙串数据 |
| [`GET /app/path`](#get-app-path) | 查询 App 数据容器、安装包或共享容器路径 |
| [`GET /app/frontBid`](#get-app-frontbid) | 获取当前前台 App 的 bundleId |
| [`GET /app/frontInfo`](#get-app-frontinfo) | 获取当前前台 App 的包名和进程信息 |
| [`GET /app/pid`](#get-app-pid) | 获取指定 App 当前进程 PID |
| [`GET /app/usedMemory`](#get-app-usedmemory) | 获取指定 App 或进程的内存占用 |
| [`POST /app/openUrl`](#post-app-openurl) | 打开 URL 或系统协议 |

<a id="get-app-info"></a>

## `GET /app/info`

### 接口说明

一次返回当前前台 App、PID 和内存概览。

### 请求参数（Query）

无请求参数

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | object | 接口返回的核心数据。具体结构见本接口说明。 |
| `value.frontBid` | string | 当前前台 App 的 bundleId |
| `value.pid` | number | 当前前台 App 的进程 PID；未获取到时可能为 `0` |
| `value.usedMemory` | number | 当前前台 App 的内存占用 |
| `value.unit` | string | 内存单位，固定为 `MB` |

### 示例

```javascript
const res = await http.get("/app/info");
console.log(res.value.frontBid);
console.log(res.value.usedMemory, res.value.unit);
```

<a id="post-app-run"></a>

## `POST /app/run`

### 接口说明

启动指定 App。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `bundleId` | string | 是 | 要启动的 App 包名 | `"com.apple.Preferences"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | `true` 表示启动请求执行成功，`false` 表示启动失败 |

### 示例

```javascript
const res = await http.post("/app/run", {
  bundleId: "com.apple.Preferences"
});

console.log(res.value);
```

<a id="post-app-close"></a>

## `POST /app/close`

### 接口说明

关闭指定 App。`bundleId` 传 `"*"` 时表示关闭全部后台 App。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `bundleId` | string | 是 | 要关闭的 App 包名；关闭全部后台 App 时传 `"*"` | `"com.apple.Preferences"` |
| `flag` | number | 否 | 关闭方式，取值 `0` 或 `1`，默认 `1` | `1` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | `true` 表示关闭命令已执行 |

### 示例

```javascript
await http.post("/app/close", {
  bundleId: "com.apple.Preferences",
  flag: 1
});
```

<a id="get-app-path"></a>

## `GET /app/path`

### 接口说明

获取指定 App 的数据容器、安装包或共享容器路径。`type` 取值：`1` 数据容器，`2` 安装包，`3` 共享容器。

### 请求参数（Query）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `bundleId` | string | 是 | 目标 App 包名 | `"com.apple.Preferences"` |
| `type` | number | 是 | 路径类型：`1` 数据容器，`2` 安装包，`3` 共享容器 | `2` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | string | 查询到的路径；不存在时可能为空字符串 |

### 示例

```javascript
const res = await http.get("/app/path?bundleId=com.apple.Preferences&type=2");
console.log(res.value);
```

<a id="get-app-usedmemory"></a>

## `GET /app/usedMemory`

### 接口说明

获取指定 App 或进程的物理内存占用，单位 MB。`bundleId` 和 `pid` 二选一；两个都传时优先使用 `bundleId`。

### 请求参数（Query）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `bundleId` | string | 否 | 目标 App 包名 | `"com.apple.Preferences"` |
| `pid` | number | 否 | 目标进程 PID | `1234` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | number | 内存占用 MB |

### 示例

```javascript
const res = await http.get("/app/usedMemory?bundleId=com.apple.Preferences");
console.log(res.value, "MB");
```

<a id="post-app-openurl"></a>

## `POST /app/openUrl`

### 接口说明

打开 URL 或系统协议。常用于打开网页、系统设置页或 App Scheme。`url` 必须包含协议。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `url` | string | 是 | 要打开的 URL，必须包含协议 | `"https://www.baidu.com"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | `true` 表示打开请求执行成功 |

### 示例

```javascript
const res = await http.post("/app/openUrl", {
  url: "https://www.baidu.com"
});

console.log(res.value);
```
