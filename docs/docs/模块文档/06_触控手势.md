# 06. 触控手势

触控手势模块用于在设备屏幕上执行点击、双击、长按、滑动、捏合和复杂多指手势。坐标全部使用屏幕物理像素，和元素坐标、截图坐标保持一致。

对外推荐使用成品动作接口和 `POST /touch/sequence`。复杂拖拽、双指同步、按住再移动这类场景，都建议放进一次 `sequence` 请求里完成，而不是拆成多次网络请求。

调用方只需要提供本页列出的坐标、时长、轨迹和手指编号。请求中包含未声明字段时，会返回参数错误。

`value.ok` 表示触控序列是否执行成功。HTTP 层失败统一见 [公共规则](../01_公共规则.md)。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`POST /touch/tap`](#post-touch-tap) | 单指点击 |
| [`POST /touch/doubleTap`](#post-touch-doubletap) | 单指双击 |
| [`POST /touch/longPress`](#post-touch-longpress) | 单指长按 |
| [`POST /touch/swipe`](#post-touch-swipe) | 单指滑动或拖拽 |
| [`POST /touch/pinch`](#post-touch-pinch) | 双指捏合或张开 |
| [`POST /touch/sequence`](#post-touch-sequence) | 一次请求执行完整多指手势序列 |
| [`POST /touch/showTouches`](#post-touch-showtouches) | 开启或关闭触摸可视化反馈 |
| [`POST /touch/home`](#post-touch-home) | 模拟 Home 键 |

## 坐标与时长

| 项目 | 说明 |
| --- | --- |
| 坐标单位 | 屏幕物理像素 |
| `duration` 单位 | 毫秒 |
| 有效坐标范围 | `0 <= x <= 屏幕宽`，`0 <= y <= 屏幕高` |
| 默认 `tap.duration` | `30` 毫秒 |
| 默认 `longPress.duration` | `2000` 毫秒 |
| 默认 `pinch.duration` | `500` 毫秒 |
| 时长范围 | `1` - `60000` 毫秒 |

<a id="post-touch-tap"></a>

## `POST /touch/tap`

### 接口说明

在指定坐标执行单指点击。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `x` | number | 是 | 点击坐标 X | `300` |
| `y` | number | 是 | 点击坐标 Y | `800` |
| `duration` | number | 否 | 按下到抬起的持续时间，单位毫秒，默认 `30` | `50` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 成功时为 `true` |

### 示例

```javascript
const res = await http.post("/touch/tap", {
  x: 300,
  y: 800,
  duration: 30
});

console.log(res.value);
```

<a id="post-touch-sequence"></a>

## `POST /touch/sequence`

### 接口说明

一次请求执行完整多指手势序列。适合以下场景：

- 拖拽：按下 -> 等待 -> 移动 -> 抬起
- 双指同步：两根手指同一步按下、同一步移动、同一步抬起
- 复杂组合：长按后拖动、双指分离、双指汇合

支持三种写法：

1. 简化单指写法：`down / move / up`
2. 多指同步写法：`parallel`
3. 完整高级写法：`events`

每个 `step` 按顺序执行；如果需要停顿，用 `waitAfterMs`。如果多步都要复用同样的 `finger`、`waitAfterMs`，建议写到 `defaults` 里。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `steps` | array | 是 | 手势步骤数组，不能为空，最多 `512` 步 | `[{...}]` |
| `defaults.finger` | number | 否 | 默认手指编号，范围 `1` - `30` | `1` |
| `defaults.waitAfterMs` | number | 否 | 默认步进停顿时间，单位毫秒 | `16` |
| `steps[].waitAfterMs` | number | 否 | 当前步骤执行完成后的等待时间，单位毫秒；不传时可继承 `defaults.waitAfterMs` | `120` |
| `steps[].down` | object 或 boolean | 条件可选 | 简化写法，表示当前步骤执行按下；推荐写对象；`true` 只适合 `up` | `{"x":300,"y":1200}` |
| `steps[].move` | object | 条件可选 | 简化写法，表示当前步骤执行移动 | `{"x":300,"y":900}` |
| `steps[].up` | object 或 boolean | 条件可选 | 简化写法，表示当前步骤执行抬起；可写 `true` | `true` |
| `steps[].finger` | number | 否 | 当前步骤简写动作使用的手指编号；不传时可继承 `defaults.finger` | `1` |
| `steps[].parallel` | array | 条件可选 | 多指同步写法，同一步里执行多个动作，最多 `16` 个 | `[{...}]` |
| `steps[].parallel[].finger` | number | 否 | 当前同步动作的手指编号；不传时可继承 `defaults.finger` | `2` |
| `steps[].parallel[].down` | object 或 boolean | 条件可选 | 当前同步动作的按下简写 | `{"x":350,"y":900}` |
| `steps[].parallel[].move` | object | 条件可选 | 当前同步动作的移动简写 | `{"x":300,"y":850}` |
| `steps[].parallel[].up` | object 或 boolean | 条件可选 | 当前同步动作的抬起简写 | `true` |
| `steps[].events` | array | 条件可选 | 完整高级写法；适合需要完全手动描述事件结构的场景，最多 `16` 个事件 | `[{...}]` |
| `steps[].events[].type` | string | 条件必选 | 事件类型：`down`、`move`、`up` | `"down"` |
| `steps[].events[].finger` | number | 否 | 手指编号；不传时可继承 `defaults.finger` | `1` |
| `steps[].events[].x` | number | 条件必选 | `down`、`move` 必填；`up` 可省略 | `300` |
| `steps[].events[].y` | number | 条件必选 | `down`、`move` 必填；`up` 可省略 | `800` |

同一个 `step` 里，`down / move / up`、`parallel`、`events` 三种格式只能选一种，不能混用。

`finger` 用于关联同一根手指的 `down`、`move` 和 `up`。多指手势应为每根手指使用不同编号。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.ok` | boolean | 是否执行成功 |
| `value.stepCount` | number | 实际执行的步骤数 |
| `value.eventCount` | number | 实际执行的事件数 |

### 示例：单指拖拽

```javascript
const res = await http.post("/touch/sequence", {
  defaults: {
    finger: 1,
    waitAfterMs: 16
  },
  steps: [
    {
      down: { x: 400, y: 1200 },
      waitAfterMs: 120
    },
    {
      move: { x: 400, y: 900 }
    },
    {
      move: { x: 400, y: 700 }
    },
    {
      up: true
    }
  ]
});

console.log(res.value);
```

### 示例：双指同步

```javascript
const res = await http.post("/touch/sequence", {
  steps: [
    {
      parallel: [
        { finger: 1, down: { x: 350, y: 900 } },
        { finger: 2, down: { x: 750, y: 900 } }
      ],
      waitAfterMs: 16
    },
    {
      parallel: [
        { finger: 1, move: { x: 300, y: 850 } },
        { finger: 2, move: { x: 800, y: 950 } }
      ],
      waitAfterMs: 16
    },
    {
      parallel: [
        { finger: 1, up: true },
        { finger: 2, up: true }
      ]
    }
  ]
});

console.log(res.value.ok);
```

### 示例：完整高级写法

```javascript
const res = await http.post("/touch/sequence", {
  defaults: {
    waitAfterMs: 16
  },
  steps: [
    {
      events: [
        { type: "down", finger: 1, x: 400, y: 1100 },
        { type: "down", finger: 2, x: 700, y: 1100 }
      ]
    },
    {
      events: [
        { type: "move", finger: 1, x: 360, y: 1000 },
        { type: "move", finger: 2, x: 740, y: 1000 }
      ]
    },
    {
      events: [
        { type: "up", finger: 1 },
        { type: "up", finger: 2 }
      ]
    }
  ]
});

console.log(res.value.eventCount);
```

## 附录：什么时候用 `sequence`

推荐直接用 `sequence` 的情况：

- 想把完整拖拽放进一次请求里
- 需要双指或多指同步
- 需要“按住一会再移动”
- 不想把一个手势拆成很多次 HTTP 请求

继续用成品动作接口的情况：

- 单击、双击、长按
- 普通单指滑动
- 普通双指捏合
