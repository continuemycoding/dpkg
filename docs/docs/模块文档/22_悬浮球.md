# 22. 悬浮球

悬浮球模块用于在手机屏幕上显示或隐藏 Session 控制小球，并设置小球的尺寸、透明度、图标、颜色和状态环样式。

设备同一时间只显示一个悬浮球。多个 Session 可以同时存在，但不会分别创建多个小球。调用显示接口时，会显示或更新指定 Session 的悬浮球。

通过 MCP 调用本文接口时，请求参数和响应字段与 HTTP 调用一致。普通 HTTP/MCP Session 创建后默认不显示悬浮球；需要显示时，由 PC 端显式传入 `localControl: true`、`localControl` 配置对象，或调用显示接口。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`POST /session/create`](#post-session-create) | 创建 Session 时显示悬浮球 |
| [`POST /session/control/show`](#post-session-control-show) | 显示悬浮球或更新当前样式 |
| [`POST /session/control/hide`](#post-session-control-hide) | 隐藏悬浮球 |

---

<a id="post-session-create"></a>

## `POST /session/create`

### 接口说明

创建普通 HTTP/MCP Session 时，可以通过 `localControl` 参数控制是否立即显示悬浮球。未传 `localControl` 时默认不显示；Session 的其他创建参数和响应字段见 [服务与任务](01_服务与任务.md#post-session-create)。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `localControl` | boolean/object | 否 | 是否在创建 Session 后显示悬浮球，默认 `false`；传 `true` 或对象时显式显示 | `true` |
| `localControl.enabled` | boolean | 否 | 对象写法中的显示开关，默认 `true` | `true` |
| `localControl.positionY` | number | 否 | 纵向停靠位置，表示悬浮球顶部距离屏幕顶部的 UIKit point；超出可用范围时自动限制到屏幕内 | `260` |
| `localControl.style` | object | 否 | 悬浮球样式，字段见 [样式参数](#style-parameters) | `{ "opacity": 0.6 }` |

### 响应字段

启用悬浮球后，响应除 Session 状态对象外，还会返回 `value.localControl`。字段与 [`POST /session/control/show`](#post-session-control-show) 的 `value` 相同。

### 示例

```javascript
const res = await http.post("/session/create", {
  name: "visible-task",
  localControl: {
    enabled: true,
    positionY: 260,
    style: {
      opacity: 0.6,
      symbolName: "play.fill",
      ring: {
        runningColor: "#00E5FF"
      }
    }
  }
});

const sessionId = res.value.sessionId;
console.log(res.value.localControl.shown);
```

创建 Session 时不显示悬浮球：

```javascript
const res = await http.post("/session/create", {
  name: "background-task",
  localControl: false
});

console.log(res.value.sessionId);
```

<a id="post-session-control-show"></a>

## `POST /session/control/show`

### 接口说明

显示指定 Session 的悬浮球。设备已经显示悬浮球时，不会创建第二个小球，而是更新当前小球。

同一 Session 已经显示悬浮球时，不传 `style` 会保留当前样式；传入 `style` 会更新样式。

### 请求参数（Query、Header 或 JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `sessionId` | string | 是 | 要显示悬浮球的 SessionID。可以放在 query、请求头 `X-YK-Session-Id`，也可以放在 JSON body | `"sess_xxx"` |
| `positionY` | number | 否 | 纵向停靠位置，表示悬浮球顶部距离屏幕顶部的 UIKit point；超出可用范围时自动限制到屏幕内 | `260` |
| `style` | object | 否 | 悬浮球样式，字段见 [样式参数](#style-parameters) | `{ "opacity": 0.6 }` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.shown` | boolean | 悬浮球是否已显示 |
| `value.sessionId` | string | 当前 SessionID |
| `value.name` | string | Session 名称 |
| `value.state` | string | 当前状态，常见为 `running`、`paused`、`stopped` |
| `value.positionY` | number | 实际生效的纵向停靠位置，单位为 UIKit point |
| `value.style` | object | 当前实际生效的样式 |

### `value.style` 字段

请求参数可能会按允许范围调整，`value.style` 返回最终实际生效值。例如只传 `iconSize: 35` 时，实际 `bubbleSize` 会自动调整为 `47`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.style.bubbleSize` | number | 实际悬浮球直径 |
| `value.style.opacity` | number | 实际生效的收起状态整体透明度 |
| `value.style.iconSize` | number | 实际中心图标尺寸 |
| `value.style.iconSource` | string | 图标来源：`default`、`text`、`symbol`、`base64`、`path` |
| `value.style.hasCustomIcon` | boolean | 是否使用自定义中心图标 |
| `value.style.iconText` | string | `iconText` 生效时返回文本；其他图标类型通常为空字符串 |
| `value.style.backgroundColor` | string | 实际背景色，统一返回 `#AARRGGBB` |
| `value.style.borderColor` | string | 实际边框色，统一返回 `#AARRGGBB` |
| `value.style.iconColor` | string | 实际图标色，统一返回 `#AARRGGBB` |
| `value.style.ring.width` | number | 实际状态环线宽 |
| `value.style.ring.inset` | number | 实际状态环内缩 |
| `value.style.ring.strokeEnd` | number | 实际弧线长度比例 |
| `value.style.ring.duration` | number | 实际旋转动画耗时 |
| `value.style.ring.runningColor` | string | 运行态状态环颜色 |
| `value.style.ring.pausedColor` | string | 暂停态状态环颜色 |
| `value.style.ring.stoppedColor` | string | 停止态状态环颜色 |
| `value.style.ring.errorColor` | string | 异常态状态环颜色 |

### 示例

```javascript
const res = await http.post("/session/control/show", {
  positionY: 260,
  style: {
    opacity: 0.6
  }
}, {
  headers: { "X-YK-Session-Id": sessionId }
});

console.log(res.value.shown);
console.log(res.value.positionY);
console.log(res.value.style.opacity);
```

## `POST /session/control/hide`

### 接口说明

隐藏指定 Session 的悬浮球。隐藏只影响屏幕显示，不会删除 Session，也不会停止正在运行的任务。

### 请求参数（Query、Header 或 JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `sessionId` | string | 是 | 要隐藏悬浮球的 SessionID。可以放在 query、请求头 `X-YK-Session-Id`，也可以放在 JSON body | `"sess_xxx"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.hidden` | boolean | 是否已隐藏 |
| `value.sessionId` | string | 被隐藏悬浮球的 SessionID |

### 示例

```javascript
const res = await http.post("/session/control/hide", {}, {
  headers: { "X-YK-Session-Id": sessionId }
});

console.log(res.value.hidden);
```

---

## 位置规则

悬浮球只支持设置**纵向停靠位置**，也就是屏幕上的上下位置。调用 `POST /session/control/show` 时传入 `positionY`，或者创建 Session 时传入 `localControl.positionY`，即可设置悬浮球顶部的纵向位置。

用户也可以直接拖动小球调整高度。松手后，小球的横向位置会自动吸附到左侧或右侧屏幕边缘，不能停留在任意横向位置。

接口不提供 `positionX`，不能通过 API 设置横向位置。`positionY` 超出屏幕可用范围时会自动调整，最终位置以响应中的 `value.positionY` 为准。

<a id="style-parameters"></a>

## 样式参数

`style` 可以在创建 Session 时放入 `localControl.style`，也可以直接传给 `POST /session/control/show`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `style.bubbleSize` | number | 悬浮球直径，单位为 UIKit point，限制为 `28` 到 `88`，默认 `40` |
| `style.opacity` | number | 收起状态的整体透明度，限制为 `0.1` 到 `1.0`，超出范围按边界值生效，默认 `1.0` |
| `style.iconSize` | number | 中心图标尺寸，限制为 `8` 到 `bubbleSize - 6`；不传时按 `bubbleSize * 0.54` 自动计算，最小 `12`；只传 `iconSize` 时，悬浮球可自动放大到 `iconSize + 12` |
| `style.iconText` | string | 中心文字或 Emoji，例如 `"🐱"`、`"▶"`、`"AI"` |
| `style.symbolName` | string | iOS SF Symbol 名称，例如 `"bolt.fill"`、`"play.fill"` |
| `style.iconBase64` | string | 中心图标图片 Base64，支持普通 Base64 或 `data:image/png;base64,...` |
| `style.iconPath` | string | 设备本地图片路径，支持绝对路径或 `file://` |
| `style.backgroundColor` | string/array/object | 悬浮球背景色，默认黑色 |
| `style.borderColor` | string/array/object | 悬浮球边框色，默认半透明白色 |
| `style.iconColor` | string/array/object | 默认图标、`iconText` 和 `symbolName` 的颜色；不改变图片本身颜色 |
| `style.ring.runningColor` | string/array/object | 运行态状态环颜色，默认绿色 |
| `style.ring.pausedColor` | string/array/object | 暂停态状态环颜色，默认橙色 |
| `style.ring.stoppedColor` | string/array/object | 停止态状态环颜色，默认灰色 |
| `style.ring.errorColor` | string/array/object | 异常态状态环颜色，默认红色 |
| `style.ring.width` | number | 状态环线宽，限制为 `1` 到 `8`；不传时按悬浮球尺寸自动计算 |
| `style.ring.inset` | number | 状态环距离悬浮球边缘的内缩，限制为 `0` 到 `12`，默认 `3` |
| `style.ring.strokeEnd` | number | 状态环弧线长度比例，限制为 `0.05` 到 `1`，默认 `0.72` |
| `style.ring.duration` | number | 运行态转一圈动画耗时，单位秒，限制为 `0.25` 到 `5`，默认 `1.15` |

中心图标优先级为：图片数据或图片路径 > SF Symbol > Emoji/短文本 > 默认图标。

`opacity` 只改变收起状态悬浮球的背景、图标、边框和状态环。展开后的操作按钮保持完全不透明，点击和拖动区域不变。颜色字段自身的 alpha 会与 `opacity` 共同生效。

### 颜色格式

| 格式 | 示例 | 说明 |
| --- | --- | --- |
| `#RGB` / `#RGBA` | `#0F0`、`#8FFF` | 短十六进制，会自动展开 |
| `#RRGGBB` | `#00E5FF` | 不带透明度，alpha 默认为 `1` |
| `#AARRGGBB` | `#66FFFFFF` | 8 位十六进制按 `AARRGGBB` 解析，前两位是透明度 |
| 数组 | `[0, 229, 255, 0.8]` | RGB 按 `0-255`，alpha 可传 `0-1` 或 `0-255` |
| 对象 | `{ "r": 0, "g": 229, "b": 255, "a": 0.8 }` | 也支持 `{ "red", "green", "blue", "alpha" }` 和 `{ "hex": "#00E5FF" }` |

### 示例：Emoji/短文本图标

```javascript
await http.post("/session/control/show", {
  style: {
    opacity: 0.6,
    iconText: "🐱",
    iconSize: 35,
    backgroundColor: "#000000",
    borderColor: "#66FFFFFF",
    ring: {
      runningColor: "#00E5FF",
      pausedColor: "#FFB31F",
      width: 3,
      duration: 0.8
    }
  }
}, {
  headers: { "X-YK-Session-Id": sessionId }
});
```

### 示例：SF Symbol 图标

```javascript
await http.post("/session/control/show", {
  style: {
    symbolName: "bolt.fill",
    iconSize: 35,
    iconColor: "#FFFF00",
    backgroundColor: "#000000",
    ring: {
      runningColor: "#FF9500",
      width: 3,
      duration: 0.8
    }
  }
}, {
  headers: { "X-YK-Session-Id": sessionId }
});
```

### 示例：设备本地图片路径

`iconPath` 必须指向手机设备上的文件。下面示例先将图片写入设备，再作为悬浮球图标使用：

```javascript
const remoteIconPath = "/tmp/yk_local_control_icon.png";

await http.post("/file/write", {
  path: remoteIconPath,
  data: "iVBORw0KGgoAAAANSUhEUgAA...",
  encoding: "base64"
}, {
  headers: { "X-YK-Session-Id": sessionId }
});

await http.post("/session/control/show", {
  style: {
    iconPath: remoteIconPath,
    iconSize: 35
  }
}, {
  headers: { "X-YK-Session-Id": sessionId }
});
```
