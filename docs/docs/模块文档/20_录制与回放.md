# 20. 录制与回放

录制与回放模块用于通过 HTTP 远程控制一次操作录制，并把录制结果保存为可回放的记录。

远程录制适合自动化工具在设备上创建操作流程：先发起录制，再开始倒计时，随后根据需要暂停、继续、完成和保存。远程录制不会依赖 App 内的本地按钮流程；调用方只需要关注接口状态和保存后的 `recordId`。

本模块是设备级任务接口，不需要先调用 `POST /session/create`，也不需要在请求头携带 `X-YK-Session-Id`。接口返回的 `taskId` 只表示当前录制或回放任务，不是 HTTP SessionID。

通过“远程调试”页面显示的公网地址调用时，本模块虽然不需要 SessionID，但每个业务请求仍必须携带 `X-YK-Remote-Authorization`。公网地址使用页面当前显示的动态远程端口，不使用设备固定端口 `65322`。

文档只说明公开调用方式和稳定返回字段。响应中如果出现额外字段，不建议业务脚本依赖。

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`GET /record/records`](#get-record-v1-records) | 获取录制列表 |
| [`GET /record/tasks/current`](#get-record-v1-tasks-current) | 查询当前录制或回放状态 |
| [`POST /record/tasks`](#post-record-v1-tasks) | 创建一段新的远程录制 |
| [`POST /record/tasks/current/start`](#post-record-v1-tasks-current-start) | 开始 3、2、1、开始倒计时 |
| [`POST /record/tasks/current/pause`](#post-record-v1-tasks-current-pause) | 暂停当前录制 |
| [`POST /record/tasks/current/resume`](#post-record-v1-tasks-current-resume) | 继续当前录制 |
| [`POST /record/tasks/current/finish`](#post-record-v1-tasks-current-finish) | 完成当前录制，进入待保存状态 |
| [`POST /record/tasks/current/save`](#post-record-v1-tasks-current-save) | 保存已完成的录制 |
| [`POST /record/tasks/current/cancel`](#post-record-v1-tasks-current-cancel) | 取消当前录制或回放 |
| [`POST /record/records/{recordId}/run`](#post-record-v1-records-recordid-run) | 准备回放指定录制 |
| [`DELETE /record/records/{recordId}`](#delete-record-v1-records-recordid) | 删除指定录制 |

## 通用说明

| 项目 | 说明 |
| --- | --- |
| 是否需要 SessionID | 不需要，不要携带 `X-YK-Session-Id` |
| 录制格式 | 文本流程记录，对外统一按 `txt` 展示 |
| 默认保留数量 | 设备侧默认保留最近 50 条录制 |
| 推荐流程 | 创建录制 → 开始倒计时 → 完成 → 保存 → 使用 `recordId` 回放 |
| 暂停/继续 | 只影响录制采集过程，不会丢弃已经录到的动作 |
| 取消 | 放弃当前未保存录制，或停止当前回放 |
| 音量键快捷操作 | 只支持真机 App 内的实体音量 `+/-` 快捷键，不提供 HTTP 音量快捷接口 |

## 状态值

| 状态 | 说明 |
| --- | --- |
| `idle` | 当前没有录制或回放 |
| `ready` | 已创建录制，等待开始倒计时 |
| `countdown` | 倒计时中 |
| `recording` | 录制中 |
| `paused` | 录制已暂停 |
| `finished` | 录制已完成，等待保存 |
| `cancelled` | 已取消 |
| `playbackReady` | 回放已准备，等待开始 |
| `playbackRunning` | 回放中 |
| `playbackPaused` | 回放已暂停 |
| `playbackFinished` | 回放已结束 |

<a id="current-task-fields"></a>

## 当前状态字段

当前录制或回放接口通常返回一个状态对象。业务脚本建议只依赖下面这些字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.taskId` | string | 当前录制或回放的临时 ID |
| `value.name` | string | 当前录制或回放名称 |
| `value.language` | string | 记录类型，当前为 `txt` |
| `value.state` | string | 当前状态 |
| `value.active` | boolean | 是否仍处于活动流程中 |
| `value.countdown` | number | 倒计时数字；非倒计时时通常为 `0` |
| `value.pendingSave` | boolean | 是否已经完成但尚未保存 |
| `value.startedAt` | string | 开始时间 |
| `value.finishedAt` | string | 完成时间 |
| `value.playback` | object | 回放进度；仅回放流程中有意义 |
| `value.playbackRecordId` | string | 当前回放的录制 ID |
| `value.playbackRepeatCount` | number | 回放次数，`0` 表示无限循环 |

<a id="get-record-v1-records"></a>

## `GET /record/records`

### 接口说明

获取已保存的录制列表，默认按更新时间倒序返回。

### 请求参数（Query）

| 参数 | 类型 | 是否必选 | 默认值 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `limit` | number | 否 | `50` | 返回数量，最大 `500`。 | `20` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.records` | array | 录制列表 |
| `value.count` | number | 本次返回数量 |

<a id="record-item-fields"></a>

### `value.records[]` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 录制 ID，后续回放和删除都使用它 |
| `name` | string | 录制名称 |
| `language` | string | 记录类型，当前为 `txt` |
| `size` | number | 文件大小，单位字节 |
| `durationMs` | number | 录制动作总时长，单位毫秒 |
| `eventCount` | number | 录制动作数量 |
| `updatedAt` | string | 更新时间 |

### 示例

```javascript
const res = await http.get("/record/records?limit=20");

console.log(res.value.records);
```

<a id="get-record-v1-tasks-current"></a>

## `GET /record/tasks/current`

### 接口说明

查询当前录制或回放状态。没有活动流程时，返回值可能为空。

### 请求参数

无请求参数。

### 响应字段

参考 [当前状态字段](#current-task-fields)。

### 示例

```javascript
const res = await http.get("/record/tasks/current");

if (res.value) {
  console.log("正在录制");
}
```

<a id="post-record-v1-tasks"></a>

## `POST /record/tasks`

### 接口说明

创建一段新的远程录制。创建后还不会立即记录动作，需要再调用开始接口进入倒计时。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 默认值 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `name` | string | 否 | 自动生成 | 录制名称。为空时保存阶段会使用默认名称。 | `"登录流程"` |

### 响应字段

参考 [当前状态字段](#current-task-fields)。成功后 `state` 通常为 `ready`。

### 示例

```javascript
const res = await http.post("/record/tasks", {
  name: "登录流程"
});

console.log(res.value.taskId);
```

<a id="post-record-v1-tasks-current-start"></a>

## `POST /record/tasks/current/start`

### 接口说明

开始当前录制的倒计时。倒计时结束后才会正式记录操作。

### 请求参数

无业务参数。POST 时建议发送空 JSON 对象 `{}`。

### 响应字段

参考 [当前状态字段](#current-task-fields)。调用后 `state` 通常为 `countdown`。

### 示例

```javascript
await http.post("/record/tasks/current/start", {});
```

<a id="post-record-v1-tasks-current-finish"></a>

## `POST /record/tasks/current/finish`

### 接口说明

完成当前录制，并进入待保存状态。完成本身不会自动生成可回放记录，需要继续调用保存接口。

### 请求参数

无业务参数。POST 时建议发送空 JSON 对象 `{}`。

### 响应字段

参考 [当前状态字段](#current-task-fields)。成功后 `pendingSave` 通常为 `true`。

### 示例

```javascript
const res = await http.post("/record/tasks/current/finish", {});

if (res.value.pendingSave) {
  console.log("可以保存");
}
```

<a id="post-record-v1-tasks-current-save"></a>

## `POST /record/tasks/current/save`

### 接口说明

保存已完成的录制。保存成功后会返回录制信息，后续使用 `record.id` 回放。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 默认值 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `name` | string | 否 | 自动生成 | 最终保存名称。为空时使用默认时间名称。 | `"登录流程"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.saved` | boolean | 是否保存成功 |
| `value.record` | object | 保存后的录制信息 |

`value.record` 字段参考 [`value.records[]` 字段](#record-item-fields)。

### 示例

```javascript
const res = await http.post("/record/tasks/current/save", {
  name: "登录流程"
});

console.log(res.value.record.id);
```

### 响应字段

参考 [当前状态字段](#current-task-fields)。

### 示例

```javascript

```

<a id="post-record-v1-records-recordid-run"></a>

## `POST /record/records/{recordId}/run`

### 接口说明

回放指定录制。远程请求默认会直接开始执行；App 本地请求传 `isLocal: true` 时会先进入回放准备状态，等待用户在真机上确认。

### 路径参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `recordId` | string | 是 | 录制 ID。 | `"登录流程"` |

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 默认值 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `repeatCount` | number | 否 | `1` | 回放次数。传 `0` 表示无限循环。 | `3` |
| `isLocal` | boolean | 否 | `false` | 是否走 App 本地确认流程。远程自动化不要传或传 `false`。 | `false` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.accepted` | boolean | 是否已接受回放请求 |
| `value.prepared` | boolean | 是否处于本地待确认准备态 |
| `value.started` | boolean | 是否已经开始远端回放 |
| `value.recordId` | string | 录制 ID |
| `value.repeatCount` | number | 回放次数 |
| `value.task` | object | 当前回放状态 |

### 示例

```javascript
const recordId = encodeURIComponent("登录流程");
await http.post(`/record/records/${recordId}/run`, {
  repeatCount: 3
});
```

<a id="delete-record-v1-records-recordid"></a>

## `DELETE /record/records/{recordId}`

### 接口说明

删除指定录制。删除后无法通过该 `recordId` 回放。

### 路径参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `recordId` | string | 是 | 录制 ID。 | `"登录流程"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.deleted` | boolean | 是否删除成功 |
| `value.recordId` | string | 被删除的录制 ID |

### 示例

```javascript
const recordId = encodeURIComponent("登录流程");
await http.delete(`/record/records/${recordId}`);
```

## 完整远程录制示例

```javascript
await http.post("/record/tasks", {
  name: "登录流程"
});

await http.post("/record/tasks/current/start", {});

// 倒计时结束后，在设备上执行需要记录的操作。
// 如果需要暂停：
// await http.post("/record/tasks/current/pause", {});
// await http.post("/record/tasks/current/resume", {});

await http.post("/record/tasks/current/finish", {});

const saved = await http.post("/record/tasks/current/save", {
  name: "登录流程"
});

await http.post(`/record/records/${encodeURIComponent(saved.value.record.id)}/run`, {
  repeatCount: 1
});
```

## 常见错误

| 场景 | 说明 |
| --- | --- |
| 没有当前录制就调用开始、暂停或完成 | 返回当前空状态或参数错误，先创建录制 |
| 完成前调用保存 | 返回失败说明，先调用完成接口 |
| `recordId` 不存在 | 回放或删除会返回失败说明 |
| 回放次数传负数 | 按接口校验结果处理；建议只传 `0` 或正整数 |
| 录制列表为空 | 说明还没有保存过录制，先完成一次录制并保存 |
