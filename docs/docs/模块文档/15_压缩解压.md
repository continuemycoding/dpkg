# 15. 压缩解压

压缩解压模块用于识别、查看、压缩和解压手机本地的归档文件。当前主要面向 ZIP/RAR 读取和 ZIP 创建场景。

## 使用约定

| 规则 | 说明 |
| --- | --- |
| 本地路径 | `archivePath`、`sourcePath`、`destinationPath` 都必须是手机本地绝对路径 |
| 条目路径 | `entryPaths` 是压缩包内部相对路径，不能包含 `..`，不能是绝对路径 |
| 覆盖策略 | 解压接口默认 `overwrite=true`，如传 `false`，目标文件已存在时会返回失败 |
| 密码 | `password` 可选，读取或解压加密归档时传入 |

## 接口列表

| 接口 | 用途 |
| --- | --- |
| [`POST /archive/format`](#post-archive-format) | 识别归档格式 |
| [`POST /archive/isEncrypted`](#post-archive-isencrypted) | 判断归档是否加密 |
| [`POST /archive/info`](#post-archive-info) | 读取归档摘要 |
| [`POST /archive/list`](#post-archive-list) | 列出归档条目 |
| [`POST /archive/extractEntries`](#post-archive-extractentries) | 解压指定条目 |
| [`POST /archive/compress`](#post-archive-compress) | 创建 ZIP 归档 |
| [`POST /archive/extract`](#post-archive-extract) | 完整解压归档 |

<a id="post-archive-format"></a>

## `POST /archive/format`

### 接口说明

识别手机本地归档文件格式。无法识别或文件不存在时，`value` 返回 `null`。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `archivePath` | string | 是 | 归档文件路径 | `"/var/mobile/test.zip"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | string \| null | `zip`、`rar` 或 `null` |

### 调用示例

```javascript
const res = await http.post("/archive/format", {
  archivePath: "/var/mobile/test.zip"
});

console.log(res.value); // zip
```

<a id="post-archive-info"></a>

## `POST /archive/info`

### 接口说明

读取归档摘要，不解压文件。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `archivePath` | string | 是 | 归档文件路径 | `"/var/mobile/test.zip"` |
| `password` | string | 否 | 归档密码 | `"123456"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value.format` | string | 归档格式，例如 `zip` |
| `value.entryCount` | number | 条目数量 |
| `value.isEncrypted` | boolean | 是否加密 |
| `value.totalCompressedSize` | number | 压缩后总字节数 |
| `value.totalUncompressedSize` | number | 解压后总字节数 |

### 调用示例

```javascript
const res = await http.post("/archive/info", {
  archivePath: "/var/mobile/test.zip"
});

console.log(res.value.entryCount);
```

<a id="post-archive-list"></a>

## `POST /archive/list`

### 接口说明

列出归档内部的条目元数据，不解压文件。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `archivePath` | string | 是 | 归档文件路径 | `"/var/mobile/test.zip"` |
| `password` | string | 否 | 归档密码 | `"123456"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | array | 条目数组 |
| `value[].path` | string | 条目在归档内的完整相对路径 |
| `value[].name` | string | 条目名称 |
| `value[].relativePath` | string | 条目所在相对目录 |
| `value[].isDirectory` | boolean | 是否目录 |
| `value[].isEncrypted` | boolean | 是否加密 |
| `value[].compressedSize` | number | 压缩后字节数 |
| `value[].uncompressedSize` | number | 解压后字节数 |

### 调用示例

```javascript
const res = await http.post("/archive/list", {
  archivePath: "/var/mobile/test.zip"
});

console.log(res.value);
```

<a id="post-archive-extractentries"></a>

## `POST /archive/extractEntries`

### 接口说明

只解压指定条目到目标目录。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `archivePath` | string | 是 | 归档文件路径 | `"/var/mobile/test.zip"` |
| `destinationPath` | string | 是 | 解压目标目录 | `"/var/mobile/out"` |
| `entryPaths` | string[] | 是 | 要解压的归档内部相对路径列表 | `["hello.txt","dir/a.txt"]` |
| `overwrite` | boolean | 否 | 是否覆盖已存在文件，默认 `true` | `true` |
| `password` | string | 否 | 归档密码 | `"123456"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 解压成功时为 `true` |

### 调用示例

```javascript
const res = await http.post("/archive/extractEntries", {
  archivePath: "/var/mobile/test.zip",
  destinationPath: "/var/mobile/out",
  entryPaths: ["hello.txt", "dir/a.txt"],
  overwrite: true
});

console.log(res.value);
```

<a id="post-archive-compress"></a>

## `POST /archive/compress`

### 接口说明

将手机本地文件或目录压缩为 ZIP。

### 请求参数

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |

| `keepParentDirectory` | boolean | 否 | 是否保留顶层目录名，默认 `false` | `false` |
| `password` | string | 否 | 压缩密码 | `"123456"` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 压缩成功时为 `true` |

### 调用示例

```javascript
const res = await http.post("/archive/compress", {
  sourcePath: "/var/mobile/source",
  archivePath: "/var/mobile/test.zip",
  keepParentDirectory: false
});

console.log(res.value);
```

## 常见错误

| 情况 | 说明 |
| --- | --- |
| 路径不是绝对路径 | `archivePath`、`sourcePath`、`destinationPath` 必须以 `/` 开头 |
| `entryPaths` 包含 `..` 或绝对路径 | 为避免解压到目标目录外部，条目路径会被拒绝 |
| 密码错误 | 加密归档读取或解压会失败 |
| 目标文件已存在且 `overwrite=false` | 接口会返回失败，请改成 `overwrite=true` 或换目录 |
