# 07. 键盘输入

键盘输入模块用于模拟键盘按键、向当前焦点输入框输入文本、清空文本、读写剪贴板，以及管理系统文本替换短语。

使用输入类接口前，请先通过元素点击或触摸点击让目标输入框获得焦点。

读取类接口都是 `GET`，会改变输入状态、剪贴板或短语内容的接口通常是 `POST`。

<a id="post-keyboard-press"></a>

## `POST /keyboard/press`

### 接口说明

模拟一次键盘按键按下并释放，常用于发送回车、删除、空格等按键。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `key` | string | 否 | 推荐使用的可读按键名；传了 `key` 时不需要传 `page` 和 `usage`，支持范围见本文末尾附录 | `"enter"` |
| `page` | number | 否 | 按键分组编号；未传 `key` 时必填，常用 `7` 表示键盘，`12` 表示系统/媒体键 | `7` |
| `usage` | number | 否 | 按键编号；未传 `key` 时必填，具体编号见本文末尾附录 | `40` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 是否执行成功 |

### 示例

```javascript
const res = await http.post("/keyboard/press", {
  key: "enter"
});
console.log(res.value);
```

<a id="post-keyboard-inputtext"></a>

## `POST /keyboard/inputText`

### 接口说明

向当前焦点输入框输入文本，支持中文、英文、数字和常见符号。不传 `delayMs` 或传 `0` 时整段一次性输入，不设置字符间延迟；传正数时按指定间隔逐字符输入。

### 请求参数（JSON Body）

| 参数 | 类型 | 是否必选 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `text` | string | 是 | 要输入的文本，不能为空 | `"hello"` |
| `delayMs` | number | 否 | 字符间隔，单位毫秒。传正数时按该间隔逐字符输入；不传或传 `0` 时整段一次性输入，不设置字符间延迟 | `50` |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | boolean | 是否执行成功 |

### 示例

```javascript
const res = await http.post("/keyboard/inputText", {
  text: "hello",
  delayMs: 50
});
console.log(res.value);
```

## 附录：按键 `key`、`page`、`usage` 速查表

普通脚本优先传 `key`，没有对应字符串名称时再使用 `page` + `usage`。输入前先通过元素点击或触摸点击让目标输入框获得焦点。

单键示例：

```javascript
await http.post("/keyboard/press", { key: "enter" });
```

原始 HID 示例：

```javascript
await http.post("/keyboard/press", {
  page: 7,
  usage: 40
});
```

下面的编号表可以直接用于 `page` 和 `usage` 参数。普通键盘按键使用 `page: 7`，系统/媒体控制按键使用 `page: 12`。

### `key` 字符串规则

| 用法 | 说明 | 示例 |
| --- | --- | --- |
| 单个数字 | 支持 `0` - `9` | `{ key: "1" }` |
| 单个小写字母 | 支持 `a` - `z` | `{ key: "a" }` |
| 单个大写字母 | 支持 `A` - `Z`，会自动组合 Shift | `{ key: "A" }` |
| 单个 ASCII 符号 | 支持 `` `~-_=+[]{}\|;:'",<.>/?!@#$%^&*() ``，需要 Shift 的符号会自动组合 Shift | `{ key: "?" }` |
| 其他字符 | `¥`、`￥`、`€`、`£`、中文、emoji 等使用 `/keyboard/inputText` | `{ text: "¥￥€£" }` |
| 命名按键 | 支持 `enter`、`space`、`delete`、`leftCommand` 等，见下方表格 | `{ key: "delete" }` |
| 功能键 | 支持 `F1` - `F24` | `{ key: "F1" }` |

命名按键使用表格中的写法。输入空格时使用 `{ key: "space" }`。

`/keyboard/inputText` 用于输入完整字符串，适合中文、英文、数字、符号、emoji、带重音字符等连续文本；`/keyboard/press`、`/keyboard/down`、`/keyboard/up` 更适合发送回车、删除、方向键、组合键和系统键。

### page 分组说明

| page 十进制 | page 十六进制 | 中文说明 | 常见用途 |
| ---: | ---: | --- | --- |
| `7` | `0x07` | 键盘/小键盘按键页 | 字母、数字、回车、删除、方向键、修饰键、F1-F24 |
| `12` | `0x0C` | 系统/媒体控制页 | Home/Menu、电源、静音、音量、亮度、截图、搜索 |

### 组合键

组合键按“修饰键按下 → 目标键按下并释放 → 修饰键抬起”的顺序发送。

| 目标动作 | key 顺序 |
| --- | --- |
| 全选 | `leftControl` + `a` |
| 复制 | `leftControl` + `c` |
| 剪切 | `leftControl` + `x` |
| 粘贴 | `leftControl` + `v` |
| 撤销 | `leftControl` + `z` |
| 重做 | `leftControl` + `leftShift` + `z` |
| 查找 | `leftControl` + `f` |

全选示例：

```javascript
await http.post("/keyboard/down", { key: "leftControl" });
await http.post("/keyboard/press", { key: "a" });
await http.post("/keyboard/up", { key: "leftControl" });
```

`leftControl + a` 是全选。
